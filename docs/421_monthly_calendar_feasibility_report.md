# 421. 월간 캘린더 버튼 구현가능성 리포트

> **작성일**: 2025-12-22
> **요청**: PC 관리자 대시보드의 "오늘" 버튼을 "월간" 버튼으로 변경하고, 클릭 시 월간 캘린더 표시

---

## 1. 현재 상태 분석

### 1.1 현재 "오늘" 버튼 위치
- **파일**: `frontend/src/components/admin/dashboard/WeeklyCalendar.tsx`
- **위치**: 헤더 우측 (공지 등록 버튼 옆)
- **기능**: 현재 주로 이동 + 오늘 날짜 선택

```tsx
// 현재 코드 (WeeklyCalendar.tsx:174-180)
<button
  onClick={handleGoToday}
  className="px-4 py-2 bg-toss-blue text-white text-sm font-semibold rounded-full ..."
>
  오늘
</button>
```

### 1.2 현재 캘린더 구조
- **WeeklyCalendar**: 주간 7일 표시 (일~토)
- **CalendarDayCell**: 개별 날짜 셀 (공지 미리보기, 순환수업 마커 포함)
- **AdminDashboard**: 선택된 날짜의 수업 목록 표시

---

## 2. 구현 옵션 분석

### Option A: 모달 방식 월간 캘린더
```
[월간 버튼 클릭] → [월간 캘린더 모달 팝업] → [날짜 선택] → [모달 닫힘 + 주간 캘린더 해당 날짜로 이동]
```

| 장점 | 단점 |
|------|------|
| 기존 레이아웃 변경 없음 | 추가 클릭 필요 |
| 빠른 구현 (1-2시간) | 모달이 시야 차단 |
| 토스 스타일 유지 | |

### Option B: 토글 방식 (주간 ↔ 월간 전환)
```
[월간 버튼 클릭] → [WeeklyCalendar가 MonthlyCalendar로 변경] → [날짜 선택] → [자동으로 주간 뷰로 전환]
```

| 장점 | 단점 |
|------|------|
| 더 자연스러운 UX | 구현 복잡도 높음 (3-4시간) |
| 같은 영역 내 전환 | 레이아웃 변경 필요 |
| 월간 뷰에서 정보 확인 가능 | |

### Option C: 확장 방식 (WeeklyCalendar 높이 확장)
```
[월간 버튼 클릭] → [WeeklyCalendar 영역이 월간으로 확장] → [날짜 선택] → [축소]
```

| 장점 | 단점 |
|------|------|
| 부드러운 애니메이션 | 레이아웃 재계산 필요 |
| 기존 컴포넌트 재활용 | 공지 영역 배치 문제 |

## 3. 월간 캘린더 디자인 고려사항

### 3.1 표시할 정보
| 항목 | 주간 캘린더 현재 | 월간 캘린더 제안 |
|------|-----------------|-----------------|
| 요일 | 일~토 | 일~토 (헤더) |
| 날짜 | 7일 | 35일 (5~6주) |
| 오늘 마커 | O | O |
| 선택 마커 | O | O |
| 순환수업 마커 | O (보라색 점) | O (보라색 점) |
| 중요 공지 미리보기 | O (텍스트) | △ (점만) |
| 수업 개수 | X | △ (선택사항) |

### 3.2 디자인 스타일
- **토스 스타일**: 둥근 모서리, 부드러운 색상, 넉넉한 여백
- **셀 크기**: 최소 40px × 40px (터치 영역)
- **선택 상태**: 파란색 배경 (bg-toss-blue)

## 6. 결론: 구현 가능

**추천**: Option A (모달 방식) 또는 Option B (토글 방식)

- **Option A 추천 이유**: 기존 레이아웃 유지, 빠른 구현, 토스 앱에서도 유사한 패턴 사용
- **Option B 추천 이유**: 더 매끄러운 UX, 월간 뷰에서 정보 확인 가능

## 7. 사용자 결정 사항

### 7.1 표시 방식: 드롭다운 확장
- 주간 캘린더 아래로 월간 캘린더가 슬라이드 다운
- 월간 버튼 클릭 시 부드럽게 확장/축소

### 7.2 날짜 선택 후 동작: 월간 닫고 주간으로
- 날짜 선택 시 월간 캘린더 자동 축소
- 주간 캘린더가 해당 날짜의 주로 이동

### 7.3 공지사항 표시: 반응형
- **모바일**: 중요 공지사항 개수를 점으로 표시 (예: ●●)
- **PC**: 중요 공지사항 일부 텍스트 표시 (예: "학부모상담..")

## 8. 확정된 구현 계획

### Phase 1: 월간 날짜 유틸리티 (30분)
- `weekUtils.ts`에 월간 날짜 계산 함수 추가
- `getMonthDays(year, month)` - 해당 월의 모든 날짜 + 앞뒤 채움

### Phase 2: MonthlyCalendar 컴포넌트 (2시간)
- 5~6주 그리드 렌더링
- 반응형 공지 표시 (모바일: 점, PC: 텍스트)
- 슬라이드 다운 애니메이션

### Phase 3: WeeklyCalendar 통합 (1시간)
- "오늘" 버튼 → "월간" 버튼 변경
- 확장/축소 상태 관리
- 날짜 선택 시 자동 축소

### 예상 총 소요: 3.5시간

## 9. 반응형 공지 표시 상세

```
┌──────────────────────────────────────┐
│        12월 2024                     │
├──────────────────────────────────────┤
│ 일   월   화   수   목   금   토     │
├──────────────────────────────────────┤
│  1    2    3    4    5    6    7     │
│       ●   ●●              학부..     │  ← PC: 텍스트 / 모바일: 점
│  8    9   10   11   12   13   14     │
│                    ●●●               │
└──────────────────────────────────────┘

모바일 (< 768px):
- 중요 공지 1개 = ●
- 중요 공지 2개 = ●●
- 중요 공지 3개+ = ●●●

PC (≥ 768px):
- 중요 공지 제목 앞 4~6글자 + ".."
- 예: "학부모상..", "시험일정.."
```
