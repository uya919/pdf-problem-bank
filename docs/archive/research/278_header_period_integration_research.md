# 반 헤더 + 기간 선택 통합 연구 리포트

> 작성일: 2025-12-11
> 목적: 불필요한 버튼 제거, 기간 선택을 헤더에 통합

---

## 1. 현재 레이아웃 분석

### 1.1 현재 구조 (2행)

```
┌─────────────────────────────────────────┐
│ 중3A반                                  │
│ 수학 · 월/수/금 17:00           [기록 →] │  ← 행 1: 반 정보
├─────────────────────────────────────────┤
│ [2회][3회][5회][월간]        12/9~12/11 │  ← 행 2: 기간 선택
└─────────────────────────────────────────┘
높이: ~96px
```

### 1.2 문제점

1. **"기록 →" 버튼 용도 불명확**
   - 대시보드에서 이미 기록 가능
   - 중복 기능

2. **2행 구조로 세로 공간 사용**
   - 반 정보 + 기간 선택 분리
   - 통합하면 더 컴팩트

## 2. 제안: 헤더에 기간 선택 통합

### 2.1 방안 A: 반 이름 옆 세그먼트

```
┌─────────────────────────────────────────┐
│ 중3A반  [2회][3회][5회][월간] 12/9~12/11│
│ 수학 · 월/수/금 17:00                   │
└─────────────────────────────────────────┘
높이: ~52px (-44px, 46% 감소)
```

**장점**: 가장 컴팩트
**단점**: 세그먼트가 좁아서 터치 어려움

### 2.2 방안 B: 반 정보 아래 세그먼트 (1카드)

```
┌─────────────────────────────────────────┐
│ 중3A반                       12/9~12/11 │
│ 수학 · 월/수/금 17:00                   │
│ [2회][3회][5회][월간]                   │
└─────────────────────────────────────────┘
높이: ~72px (-24px, 25% 감소)
```

**장점**: 세그먼트 터치 영역 충분
**단점**: 3줄 구조

### 2.3 방안 C: 반 이름 우측에 세그먼트 (권장)

```
┌─────────────────────────────────────────┐
│ 중3A반            [2회][3회][5회][월간] │
│ 수학 · 월/수/금 17:00        12/9~12/11 │
└─────────────────────────────────────────┘
높이: ~56px (-40px, 42% 감소)
```

**장점**:
- 2줄 유지
- 세그먼트 우측 배치로 터치 편함
- 날짜 범위가 과목 정보 옆에 자연스럽게 배치
- "기록" 버튼 완전 제거

## 3. 권장안 상세 (방안 C)

### 3.1 레이아웃

```
┌─────────────────────────────────────────┐
│  중3A반        [2회][3회][5회][월간]    │  ← 행 1
│  수학 · 월/수/금 17:00      12/9~12/11  │  ← 행 2
└─────────────────────────────────────────┘
```

### 3.2 HTML 구조

```html
<div class="px-4 py-3 bg-white rounded-2xl border">
  <!-- 행 1: 반 이름 + 세그먼트 -->
  <div class="flex items-center justify-between">
    <h2 class="text-base font-bold">중3A반</h2>
    <div class="segment-control">
      <button class="active">2회</button>
      <button>3회</button>
      <button>5회</button>
      <button>월간</button>
    </div>
  </div>

  <!-- 행 2: 과목/시간 + 날짜 범위 -->
  <div class="flex items-center justify-between mt-1">
    <span class="text-xs text-gray-500">수학 · 월/수/금 17:00</span>
    <span class="text-xs text-gray-400">12/9~12/11</span>
  </div>
</div>
```

### 3.3 세그먼트 축소 버전

공간 확보를 위해 세그먼트 더 컴팩트하게:

```css
.segment-control-mini {
  padding: 2px;
  border-radius: 6px;
}
.segment-btn-mini {
  padding: 4px 8px;
  font-size: 12px;
  min-width: 36px;
}
```

## 5. 세부 스펙

### 5.1 세그먼트 미니 버전

| 항목 | 기존 | 미니 |
|------|------|------|
| 높이 | 32px | **28px** |
| 패딩 | 6px 10px | **4px 8px** |
| 폰트 | 13px | **12px** |
| 최소 너비 | 44px | **36px** |
| 전체 너비 | ~200px | **~160px** |

### 5.2 행 간격

```
행 1: 반 이름 (16px) + 세그먼트 (28px)  → 28px (높은 쪽)
간격: mt-1 (4px)
행 2: 과목/시간 (12px) + 날짜 (12px)    → 12px
패딩: py-3 (12px * 2 = 24px)
────────────────────────────────────────
총합: 28 + 4 + 12 + 24 = 68px (여유 포함)
```

## 9. 결론

### 핵심 변경

1. **"기록 →" 버튼 삭제**
   - 중복 기능 제거
   - 공간 확보

2. **세그먼트를 헤더로 이동**
   - 반 이름 우측에 배치
   - 날짜 범위는 과목 정보 우측에

3. **2행 → 2행 (하지만 1카드)**
   - 구분선 제거
   - 더 일체감 있는 디자인

### 높이 절감: **96px → 56px (-42%)**

### 토스 원칙

> **"하나의 카드에 하나의 정보 단위"**
> - 반 정보 + 기간 선택 = 하나의 맥락
> - 분리할 이유 없음
