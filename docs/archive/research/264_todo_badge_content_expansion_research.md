## 2. 콘텐츠 확장 옵션

### Option A: 단위 복원

**현재 → 변경:**
```
[✓ 출결 2] → [✓ 출결 2건]
[📄 진도 1] → [📄 진도 1건]
[📝 숙제 5] → [📝 숙제 5명]
```

**장점:**
- 의미 명확 (건 vs 명 구분)
- 구현 간단

**단점:**
- 공간 활용 효과 미미 (+3자)

**평점: ★★☆☆☆**

---

### Option B: 서브타이틀 추가 (2줄 뱃지)

**형태:**
```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ ✓ 출결 2건   │ │ 📄 진도 1건  │ │ 📝 숙제 5명  │
│ 중1C, 중2B   │ │ 중3A반       │ │ 5명 학생     │
└──────────────┘ └──────────────┘ └──────────────┘
```

**장점:**
- 정보 밀도 높음
- 맥락 제공 (어떤 반?)

**단점:**
- 뱃지 높이 증가
- 복잡해 보일 수 있음

**평점: ★★★☆☆**

---

### Option C: 인라인 서브타이틀

**형태:**
```
[✓ 출결 2건 · 중1C, 중2B] [📄 진도 1건 · 중3A] [📝 숙제 5명]
```

**장점:**
- 1줄 유지
- 정보 풍부

**단점:**
- 너무 길어서 3개가 안 들어감
- 가독성 저하

**평점: ★☆☆☆☆**

---

### Option D: 카드 형태 (권장 후보)

**형태:**
```
┌─────────────────────────────────────────────────┐
│ ✓ 출결 2건        📄 진도 1건        📝 숙제 5명  │
│ 중1C반, 중2B반      중3A반           5명의 학생   │
└─────────────────────────────────────────────────┘
```

**장점:**
- 풍부한 정보
- 전체 너비 활용
- 시각적 균형

**단점:**
- 뱃지 형태가 아닌 카드 형태

**평점: ★★★★☆**

---

### Option E: 긴급도 표시 추가

**형태:**
```
[✓ 출결 2건 긴급] [📄 진도 1건] [📝 숙제 5명 마감임박]
```

또는 색상으로:
```
[✓ 출결 2건]      → 빨간 배경 (긴급)
[📄 진도 1건]     → 파란 배경 (일반)
[📝 숙제 5명]     → 주황 배경 (주의)
```

**장점:**
- 우선순위 파악 쉬움
- 행동 유도

**단점:**
- 텍스트 추가 시 길이 증가

**평점: ★★★☆☆**

---

### Option F: 토스 스타일 리스트 (권장)

**토스 할일/알림 패턴:**
```
┌─────────────────────────────────────────────────┐
│ 할일 3                                          │
├─────────────────────────────────────────────────┤
│ ✓  출결 미입력 2건                              │
│    중1C반, 중2B반                          →    │
├─────────────────────────────────────────────────┤
│ 📄 진도 미기록 1건                              │
│    중3A반                                  →    │
├─────────────────────────────────────────────────┤
│ 📝 숙제 확인 필요 5명                           │
│    5명의 학생                              →    │
└─────────────────────────────────────────────────┘
```

**장점:**
- 정보 최대화
- 토스 앱과 동일한 패턴
- 터치 영역 충분
- 화살표로 액션 유도

**단점:**
- 공간 많이 차지
- 뱃지 간결함 상실

**평점: ★★★★★**

---

### Option G: 하이브리드 (뱃지 요약 + 확장)

**기본 상태:**
```
[출결 2건] [진도 1건] [숙제 5명]  ← 뱃지 (탭하면 확장)
```

**탭 후 확장:**
```
┌─────────────────────────────────────────────────┐
│ ✓ 출결 미입력 2건                               │
│   중1C반, 중2B반                           [처리]│
└─────────────────────────────────────────────────┘
```

**장점:**
- 간결함 + 상세 정보 둘 다
- Progressive disclosure

**단점:**
- 구현 복잡
- 2단계 인터랙션

**평점: ★★★★☆**

## 3. 토스 앱 심층 분석

### 토스 알림 센터

```
┌─────────────────────────────────────────┐
│ 오늘                                    │
├─────────────────────────────────────────┤
│ 🔔 토스뱅크                             │
│    이자가 입금되었어요                   │
│    +1,234원  ·  2시간 전                │
├─────────────────────────────────────────┤
│ 💳 토스페이                             │
│    결제가 완료되었어요                   │
│    -15,000원  ·  어제                   │
└─────────────────────────────────────────┘
```

**패턴:**
- 아이콘 + 카테고리 (1줄)
- 상세 내용 (2줄)
- 금액/시간 메타 정보 (3줄)

### 토스 홈 퀵액션

```
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│  💸  │ │  💳  │ │  📊  │ │  🎁  │
│ 송금  │ │ 결제  │ │ 주식  │ │ 혜택  │
└──────┘ └──────┘ └──────┘ └──────┘
```

**패턴:**
- 아이콘 (큰 크기)
- 라벨 (2글자)
- 숫자 없음 (퀵액션이라)

## 5. 최종 권장: Option D 변형 (그리드 카드)

### 디자인

```
┌─────────────────────────────────────────────────┐
│                    할일 3                        │
├───────────────┬───────────────┬─────────────────┤
│      ✓        │      📄       │       📝        │
│    출결 2건    │    진도 1건   │     숙제 5명    │
│  중1C, 중2B   │    중3A반     │    확인 필요    │
└───────────────┴───────────────┴─────────────────┘
```

### 장점

| 항목 | 효과 |
|------|------|
| 여백 해결 | 전체 너비 활용 |
| 정보량 | 서브타이틀 표시 |
| 탭 영역 | 각 칸이 큰 터치 영역 |
| 토스 철학 | 그리드 = 토스 퀵액션 패턴 |

### 스펙

| 항목 | 값 |
|------|-----|
| 그리드 | 3열 균등 |
| 아이콘 | 20px, 중앙 |
| 제목 | 14px, 볼드 |
| 서브타이틀 | 12px, gray-500 |
| 셀 패딩 | 12px |
| 셀 높이 | auto |

1. 여백을 유의미한 정보로 채움

3. 토스 퀵액션 그리드 패턴
