# 282. 학생 페이지 UX 연구 리포트

> 작성일: 2025-12-12
> 관점: 학원 강사의 학생 관리 니즈

---

## 1. 연구 목표

**핵심 질문**: 강사가 학생 페이지에서 무엇을 확인하고 싶어할까?

### 1.1 강사의 일상 시나리오

| 시점 | 강사의 질문 | 필요한 정보 |
|------|------------|------------|
| **수업 전** | "오늘 이 학생 뭐 했더라?" | 최근 진도, 숙제 제출 여부 |
| **수업 중** | "이 학생 약점이 뭐지?" | 시험 성적 추이, 오답 패턴 |
| **수업 후** | "학부모한테 뭐라고 말하지?" | 출결, 성적, 태도 종합 |
| **상담 시** | "이 학생 전체 상황은?" | 모든 데이터 한눈에 |

## 2. UX 철학 적용

### 2.1 토스 디자인 원칙 적용

| 원칙 | 학생 페이지 적용 |
|------|-----------------|
| **1탭 = 1액션** | 학생 선택 → 즉시 핵심 정보 표시 |
| **점진적 공개** | 요약 → 상세 (필요할 때 펼치기) |
| **컨텍스트 우선** | 지금 필요한 정보가 먼저 |
| **인지 부하 최소화** | 숫자보다 시각화 (그래프, 뱃지) |

### 2.2 정보 계층 구조

```
Level 1: 한눈에 파악 (3초)
├── 학생 이름, 학년
├── 상태 뱃지 (출석률, 성적 추이)
└── 긴급 알림 (미제출 숙제, 연속 결석)

Level 2: 빠른 확인 (10초)
├── 최근 3회 수업 요약
├── 최근 시험 점수
└── 숙제 제출률

Level 3: 상세 분석 (30초+)
├── 전체 성적 그래프
├── 출결 캘린더
├── 학습 노트 히스토리
└── 학부모 연락 기록
```

## 4. 핵심 정보 영역 상세

### 4.1 학생 카드 (목록용)

```
┌────────────────────────────────────────┐
│  김민수                    중3 · 중3A반 │
│                                        │
│  ┌──────┐ ┌──────┐ ┌──────┐           │
│  │출석   │ │성적   │ │숙제   │           │
│  │ 95%  │ │ 82점 │ │ 90%  │           │
│  │  ↑   │ │  →   │ │  ↓   │           │
│  └──────┘ └──────┘ └──────┘           │
│                                        │
│  ⚠️ 숙제 미제출 2건 · 다음 수업 내일    │
└────────────────────────────────────────┘
```

#### 지표 설명

| 지표 | 계산 방식 | 색상 규칙 |
|------|----------|----------|
| **출석률** | 최근 10회 기준 | 95%↑ 초록, 80%↑ 주황, 80%↓ 빨강 |
| **평균 성적** | 최근 5회 시험 평균 | 90↑ 초록, 70↑ 주황, 70↓ 빨강 |
| **숙제 제출률** | 최근 10회 기준 | 90%↑ 초록, 70%↑ 주황, 70%↓ 빨강 |
| **추이 화살표** | 이전 대비 | ↑ 상승, → 유지, ↓ 하락 |

### 4.2 알림 뱃지

| 상황 | 뱃지 | 색상 |
|------|------|------|
| 숙제 미제출 | ⚠️ 숙제 미제출 N건 | 주황 |
| 연속 결석 | 🚨 연속 결석 N회 | 빨강 |
| 성적 급락 | 📉 성적 급락 | 빨강 |
| 성적 급상승 | 🎉 성적 급상승 | 초록 |
| 개근 | 🏆 이번 달 개근 | 파랑 |

### 4.3 성적 그래프

```typescript
interface ScoreData {
  date: string;      // "12/11"
  score: number;     // 85
  type: 'daily' | 'weekly' | 'monthly';
  range: string;     // "이차방정식 p.42-50"
}
```

**시각화 옵션**:
- 라인 차트 (추이 파악)
- 점수대별 색상 (90↑ 초록, 70↑ 주황, 70↓ 빨강)
- 호버 시 상세 정보

### 4.4 최근 수업 타임라인

```
12/11 (수) - 오늘
├─ 출석: ✓ 출석
├─ 진도: 3단원. 이차방정식 응용 (p.46-50)
├─ 숙제: p.51-53 [미제출 ⚠️]
└─ 시험: Daily 85점 (평균 82)

12/9 (월)
├─ 출석: ✓ 출석
├─ 진도: 3단원. 이차방정식 풀이 (p.42-45)
├─ 숙제: p.46-48 [제출 ✓]
└─ 시험: -
```

## 5. 인터랙션 설계

### 5.1 학생 목록 → 상세 전환

| 방식 | 장점 | 단점 |
|------|------|------|
| **A. 풀페이지 전환** | 집중도 높음 | 목록 복귀 번거로움 |
| **B. 바텀시트** | 빠른 확인 | 정보량 제한 |
| **C. 슬라이드 패널** | PC에서 효율적 | 모바일 어색 |

**추천: A + B 조합**
- 카드 탭 → 바텀시트 (요약)
- 바텀시트에서 "상세보기" → 풀페이지

### 5.2 연락하기 플로우

## 6. 데이터 구조

### 6.1 학생 기본 정보

```typescript
interface Student {
  id: string;
  name: string;
  grade: string;              // "중3"
  classes: ClassEnrollment[]; // 수강 반 목록
  contacts: Contact[];        // 연락처 목록
  createdAt: Date;
}

interface ClassEnrollment {
  classId: string;
  className: string;          // "중3A반"
  schedule: string;           // "월/수/금 17:00"
  startDate: Date;
  endDate?: Date;
}

interface Contact {
  type: 'self' | 'parent' | 'other';
  label: string;              // "본인", "어머니"
  phone: string;
}
```

### 6.2 학생 통계 (계산된 값)

```typescript
interface StudentStats {
  studentId: string;

  // 출결
  attendanceRate: number;     // 0-100
  attendanceTrend: 'up' | 'same' | 'down';
  consecutiveAbsences: number;

  // 성적
  averageScore: number;
  scoreTrend: 'up' | 'same' | 'down';
  recentScores: ScoreRecord[];

  // 숙제
  homeworkRate: number;       // 0-100
  homeworkTrend: 'up' | 'same' | 'down';
  pendingHomework: number;    // 미제출 숙제 수

  // 알림
  alerts: Alert[];
}

interface Alert {
  type: 'homework' | 'absence' | 'score_drop' | 'score_up' | 'perfect_attendance';
  message: string;
  severity: 'info' | 'warning' | 'critical';
  createdAt: Date;
}
```

## 8. 반응형 고려

### 8.1 모바일 (375px)

- 학생 카드: 세로 스택
- 상세 페이지: 풀스크린
- 그래프: 가로 스크롤

### 8.2 태블릿 (768px)

- 학생 카드: 2열 그리드
- 상세 페이지: 모달 또는 사이드 패널

### 8.3 PC (1024px+)

- 학생 카드: 3열 그리드
- 상세 페이지: 좌측 목록 + 우측 상세 (마스터-디테일)

## 10. 결론

### 핵심 설계 원칙

1. **한눈에 파악**: 학생 카드에서 3가지 핵심 지표 즉시 확인
2. **컨텍스트 우선**: 알림 뱃지로 주의가 필요한 학생 강조
3. **점진적 공개**: 목록 → 요약 → 상세 단계적 정보 제공
4. **액션 연결**: 정보 확인 → 연락/메모 자연스러운 흐름
