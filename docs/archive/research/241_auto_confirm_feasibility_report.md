# 자동 확정 기능 구현 가능성 분석 리포트

**작성일**: 2025-12-09
**요청**: 그룹핑 시 자동 확정(export) 기능

---

## 1. 현재 흐름

```
[현재]
그룹 생성 → 문제번호 입력 → 확정 버튼 클릭 → 이미지 내보내기
    ↓           ↓              ↓
  groups.json   session     export API → problems/*.png, *.json
```

**3단계 수동 프로세스**:
1. 블록 선택 → 그룹 생성
2. 문제번호/정보 입력
3. "확정" 버튼 클릭 → export

---

## 2. 제안된 흐름

```
[자동 확정]
그룹 생성 → (자동) → 이미지 내보내기
    ↓
  groups.json + session + problems/
```

**1단계 자동 프로세스**:
1. 블록 선택 → 그룹 생성 → **자동 export**

---

## 3. 구현 가능성

### 기술적으로 가능 ✅

```typescript
// 현재 그룹 생성 후 호출
const handleCreateGroup = async () => {
  const group = createGroup(selectedBlocks);
  saveGroup(group);

  // 자동 확정 추가
  await exportGroup(group);  // ← 이 한 줄 추가
};
```

**구현 난이도**: 낮음 (API 호출 1줄 추가)

---

## 4. 우려되는 점 ⚠️

### 4.1 문제번호 미입력 상태로 내보내기

| 시나리오 | 결과 |
|----------|------|
| 현재 | 그룹 생성 → 번호 입력 → 확정 → "1번" 저장 |
| 자동 | 그룹 생성 → **즉시 확정** → "p9_L1" 저장 (번호 없음) |

**문제**: 문제번호를 입력하기 전에 export되면 번호 없이 저장됨

**해결안**:
- (A) 번호 입력 시 자동 재export
- (B) 번호 없으면 export하지 않음
- (C) 번호 입력을 강제 (모달)

---

### 4.2 그룹 수정 중 중복 export

```
시나리오:
1. 그룹 생성 → export (1회)
2. 블록 추가 → export (2회)
3. 블록 제거 → export (3회)
4. 번호 입력 → export (4회)
```

**문제**: 수정할 때마다 불필요한 export 발생

**해결안**:
- (A) 디바운스 (마지막 수정 후 2초 대기)
- (B) 명시적 "저장" 버튼 유지
- (C) 변경 감지 후 배치 export

---

### 4.3 성능 문제

| 작업 | 시간 |
|------|------|
| 그룹 생성 | ~10ms |
| 이미지 크롭 + 저장 | ~200-500ms |
| 크로스페이지 합성 | ~500-1000ms |

**문제**: 매번 export하면 UI가 느려짐

**해결안**:
- (A) 백그라운드 export (비동기)
- (B) 워커 스레드 사용
- (C) 배치 처리

---

### 4.4 되돌리기(Undo) 복잡성

| 현재 | 자동 확정 |
|------|----------|
| 확정 전 삭제 → 파일 없음 | 삭제 → 파일 남아있음 |
| 실수 수정 용이 | 파일 정리 필요 |

**문제**: 잘못된 그룹 생성 시 이미지 파일도 삭제해야 함

**해결안**:
- (A) 그룹 삭제 시 자동으로 파일도 삭제
- (B) 임시 폴더에 저장 후 최종 확정 시 이동

---

### 4.5 문제-해설 연결 타이밍

```
현재 흐름:
1. 문제 그룹 생성
2. 해설 그룹 생성
3. 연결 (드래그)
4. 확정 → 연결 정보 포함하여 저장

자동 확정 흐름:
1. 문제 그룹 생성 → 즉시 export (연결 정보 없음)
2. 해설 그룹 생성 → 즉시 export
3. 연결 → 이미 export된 파일에 연결 정보 없음 ❌
```

**문제**: 연결 정보가 export에 포함되지 않음

**해결안**:
- (A) 연결 시 재export
- (B) 연결 정보는 별도 파일로 관리 (현재 session.links)

## 5. 권장 접근법

### Option A: 반자동 확정 (권장)

```
그룹 생성 → 문제번호 입력 필수 모달 → 자동 확정
```

**장점**:
- 번호 미입력 문제 해결
- 사용자 의도 명확
- 기존 UX와 유사

**구현**:
```typescript
const handleCreateGroup = async () => {
  const group = createGroup(selectedBlocks);

  // 문제번호 입력 모달 표시
  const problemNumber = await showProblemNumberModal();

  if (problemNumber) {
    group.problemInfo = { problemNumber };
    await exportGroup(group);
  }
};
```

---

### Option B: 지연 자동 확정

```
그룹 생성 → 5초 대기 → 변경 없으면 자동 확정
```

**장점**:
- 수정 시간 확보
- 불필요한 export 방지

**단점**:
- 대기 시간이 애매함
- 사용자가 언제 확정되는지 모름

---

### Option C: 일괄 확정 버튼

```
그룹 여러 개 생성 → "전체 확정" 버튼 → 한 번에 export
```

**장점**:
- 작업 효율성
- 사용자 제어권 유지

**현재 구현 상태**: 부분적으로 존재 (bulk-export API)
