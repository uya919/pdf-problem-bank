# Hyeyum 강사 대시보드 - 토스 관점 UX 연구 리포트

> 토스가 학원 강사용 백오피스를 만들었다면 어떻게 설계했을까?

---

## 1. 현황 분석

### 1.1 hyeyum 프로젝트 현재 구조

```
역할 (Roles)
├── director (원장) - 전체 권한
├── teacher (강사) - 담당 수업 관련 권한
└── assistant (조교) - 제한된 권한
```

### 1.2 현재 네비게이션 구조

| 메뉴 | 경로 | 강사 접근 | 설명 |
|------|------|----------|------|
| 대시보드 | /dashboard | O | 캘린더 + 오늘 수업 |
| 학생 | /students | O | 학생 목록/상세 |
| 반 | /classes | O | 수업 관리 |
| 출결 | /attendance | O | 출결 체크 |
| 회의 | /meetings | 권한 | 회의 관리 |
| 시간표 | /timetable-studio-v2 | 권한 | 시간표 편집 |
| 상담 | /consultations | 권한 | 상담 관리 |
| 더보기 | /more | O | 공지사항, 휴원일 등 |

### 1.3 강사의 주요 업무 (사용자 정의)

#### View (확인 업무)
1. 공지사항 확인
2. 학원 일정 확인
3. 지난 진도 확인
4. 숙제 확인

#### Record (기록 업무)
1. 수업 진도 기록
2. 숙제 기록
3. Daily-test 점수 기록
4. Monthly-test 점수 기록
5. 중간/기말 시험 성적 기록
6. 학생별 특이사항 기록

## 2. 토스 UX 원칙 적용

### 2.1 토스의 5가지 UX 원칙

| 원칙 | 설명 | 강사앱 적용 |
|------|------|------------|
| **Tap & Scroll** | 복잡한 조작 없이 탭과 스크롤만으로 | 한 손 엄지로 수업 기록 |
| **Easy to Answer** | 쉬운 질문만 던지기 | "출석했나요? Y/N" |
| **Value First** | 가치 먼저, 비용 나중 | 오늘 할 일 먼저 보여주기 |
| **No Loading** | 로딩 느낌 없애기 | Optimistic UI, 캐싱 |
| **Casual Concept** | 친숙한 단어 사용 | "진도 기록" vs "Progress Record" |

### 2.2 Simplicity 원칙

> "토스는 화면 하나에 한 가지만"

```
현재 대시보드: 캘린더 + 공지사항 + 상담 + 회의 + 수업카드
          → 정보 과부하

토스 방식: 오늘의 수업 → 탭하면 → 진도 기록
          → 단계별 프로그레시브 디스클로저
```

## 3. 토스가 설계한 강사 대시보드

### 3.1 정보 우선순위 (Value First)

토스는 **"지금 당장 필요한 것"**을 최상단에 배치합니다.

```
Priority 1: 지금 해야 할 것 (Action Required)
├── 다음 수업 (5분 후 시작)
├── 미완료 출결 (3건)
└── 미제출 숙제 확인 (5명)

Priority 2: 오늘 일정 (Today's Schedule)
├── 수업 타임라인
├── 회의 일정
└── 공지사항

Priority 3: 최근 활동 (Recent)
├── 지난 수업 진도
├── 시험 점수 현황
└── 학생 특이사항
```

### 3.2 대시보드 구조 (Progressive Disclosure)

#### Level 1: 홈 화면 (최소 정보)
```
┌─────────────────────────────┐
│  혜윰학원          김선생님  │
├─────────────────────────────┤
│                             │
│  ⏰ 다음 수업 5분 후         │
│  ┌───────────────────────┐  │
│  │ 중3A반 수학            │  │
│  │ 17:00-19:00 | 학생 8명 │  │
│  │                 [시작]  │  │
│  └───────────────────────┘  │
│                             │
│  📋 오늘 할 일              │
│  ├ 출결 미입력 3건          │
│  ├ 숙제 확인 5명            │
│  └ 진도 기록 2건            │
│                             │
│  📅 오늘 일정               │
│  17:00 중3A반               │
│  19:00 중2B반               │
│                             │
├─────────────────────────────┤
│  🏠    👥    📚    ✓✓    ⋯  │
│  홈    학생   반    출결  더보기│
└─────────────────────────────┘
```

#### Level 2: 수업 상세 (탭 시)
```
┌─────────────────────────────┐
│  ← 중3A반 수학               │
├─────────────────────────────┤
│  ┌─────────────────────────┐│
│  │ 📖 진도 기록       [+]  ││
│  │ 최근: 베이직쎈 p.42-45  ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │ 📝 숙제 관리       [+]  ││
│  │ 미제출: 3명              ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │ ✓ 출결 체크             ││
│  │ 8명 중 6명 입력          ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │ 📊 시험 점수            ││
│  │ Daily-test 미입력        ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```

#### Level 3: 진도 기록 (상세)
```
┌─────────────────────────────┐
│  ← 진도 기록                 │
├─────────────────────────────┤
│                             │
│  📅 12월 10일 (화)           │
│                             │
│  교재 ────────────────────  │
│  [ 베이직쎈              ▼] │
│                             │
```

## 4. 네비게이션 재설계

### 4.1 현재 vs 토스 방식

| 현재 | 토스 방식 | 이유 |
|------|----------|------|
| 7개 메뉴 | 4+1 메뉴 | 인지 부하 감소 |
| 기능 중심 | 업무 중심 | 강사 워크플로우 |
| 평면적 | 계층적 | Progressive Disclosure |

### 4.2 토스 방식 네비게이션

#### 하단 네비게이션 (4+1)
```
┌─────────────────────────────────────────┐
│   홈     수업     학생     기록    더보기 │
│   🏠     📚      👥      ✏️      ⋯    │
└─────────────────────────────────────────┘
```

| 탭 | 포함 기능 | 설명 |
|----|----------|------|
| **홈** | 대시보드, 공지사항, 일정 | 오늘의 요약 |
| **수업** | 반 목록, 시간표 | 담당 수업 관리 |
| **학생** | 학생 목록, 상세 | 학생 정보 |
| **기록** | 출결, 진도, 숙제, 시험 | **핵심 업무** |
| **더보기** | 설정, 회의, 상담 | 부가 기능 |

### 4.3 "기록" 탭 상세 구조

```
기록 탭
├── 📋 오늘의 기록
│   ├── 출결 (미완료 3건)
│   ├── 진도 (미완료 2건)
│   └── 숙제 (확인 필요 5명)
│
├── 📊 시험 점수
│   ├── Daily-test
│   ├── Monthly-test
│   └── 중간/기말
│
└── 📝 학생 노트
    └── 특이사항 기록
```

## 6. 워크플로우 최적화

### 6.1 강사의 하루 (Typical Day)

```
[출근] → [공지 확인] → [오늘 일정 확인]
   ↓
[수업 시작] → [출결 체크] → [수업 진행] → [진도 기록]
   ↓
[숙제 확인] → [시험 점수 입력] → [특이사항 기록]
   ↓
[퇴근]
```

### 6.2 토스 방식 최적화

#### Before (현재)
```
진도 기록하려면:
홈 → 반 메뉴 → 반 선택 → 탭 전환 → 진도 탭 → + 버튼 → 입력
= 6단계
```

#### After (토스 방식)
```
홈 → 수업 카드 탭 → 진도 기록
= 2단계

또는

기록 탭 → 오늘의 기록 → 진도
= 2단계
```

### 6.3 Quick Actions (빠른 기록)

```
┌─────────────────────────────┐
│  + 빠른 기록                 │
├─────────────────────────────┤
│  [출결]  [진도]  [숙제]  [시험]│
└─────────────────────────────┘
```

수업 카드 또는 홈에서 바로 기록 가능

## 7. 구현 권장사항

### 7.1 단기 개선 (Quick Wins)

1. **대시보드 간소화**
   - 공지사항: 접기/펼치기
   - 수업 카드: 핵심 정보만 (시간, 반명, 학생수)
   - "오늘 할 일" 위젯 추가

2. **수업 카드 액션**
   ```tsx
   <ClassCard>
     <QuickActions>
       <Button>출결</Button>
       <Button>진도</Button>
       <Button>숙제</Button>
     </QuickActions>
   </ClassCard>
   ```

3. **네비게이션 통합**
   - 출결 + 진도 + 숙제 + 시험 → "기록" 탭으로 통합

### 7.2 중기 개선

1. **기록 전용 탭 신설**
   - `/records` 경로 추가
   - 오늘 기준 미완료 항목 우선 표시

2. **수업 컨텍스트 유지**
   - 수업 선택 후 출결→진도→숙제 연속 기록
   - 수업 종료 시 "기록 완료" 플로우

3. **학생 노트 강화**
   - 수업 중 빠른 메모
   - 학생 상세에서 타임라인 표시

### 7.3 장기 개선

1. **AI 어시스턴트**
   - "3반 진도 기록해줘" 음성/텍스트 명령
   - 반복 패턴 자동 제안

2. **대시보드 개인화**
   - 위젯 순서 커스터마이징
   - 자주 쓰는 기능 핀 고정

## 8. 결론

### 토스가 설계했다면...

| 현재 | 토스 방식 |
|------|----------|
| 7개 메뉴 | 4+1 메뉴 |
| 기능 나열 | 업무 흐름 중심 |
| 정보 과밀 | Progressive Disclosure |
| 여러 색상 | 단색 (파랑 + 그레이) |
| 이모지 아이콘 | 라인 SVG 아이콘 |

### 핵심 변화

1. **"기록" 탭 신설**: 강사의 핵심 업무 통합
2. **수업 → 기록 연결**: 2단계 내 완료
3. **오늘 할 일 위젯**: Value First 적용
4. **Quick Actions**: 수업 카드에서 바로 기록

## 부록: 현재 hyeyum 구조 요약

### 파일 구조
```
src/
├── app/(dashboard)/
│   ├── dashboard/      # 메인 대시보드
│   ├── students/       # 학생 관리
│   ├── classes/        # 반 관리
│   ├── attendance/     # 출결
│   ├── consultations/  # 상담 (권한)
│   ├── meetings/       # 회의 (권한)
│   └── more/           # 더보기
│
├── components/
│   ├── layout/
│   │   ├── Header/     # 상단 헤더 (Desktop nav)
│   │   └── MobileNav/  # 하단 네비게이션
│   └── features/       # 기능별 컴포넌트
│
└── lib/utils/
    └── permissions.ts  # 권한 관리
```

### 주요 훅
- `useTeacherClassesByDate()`: 날짜별 담당 수업
- `useProgress()`: 진도 관리
- `useHomework()`: 숙제 관리
- `useAttendance()`: 출결 관리
