| 항목 | 현재 | 요청 |

## 2. 타임라인 제거 분석

### 2.1 제거 이유

```
현재 정보 중복:
┌────────────────────────────────┐
│  히어로 캐러셀 (오늘 수업)      │ ← 수업 정보 O
│  15:00 중1C → 17:00 중3A → ... │
└────────────────────────────────┘
         ...
┌────────────────────────────────┐
│  타임라인 (오늘 일정)          │ ← 같은 정보 반복
│  15:00 중1C  17:00 중3A  ...  │
└────────────────────────────────┘
```

**결론**: 히어로 캐러셀이 이미 오늘 수업을 보여주므로 타임라인은 **중복**

### 2.2 토스 철학 적용

> **"필요한 것만, 필요할 때"**

타임라인 제거 = 불필요한 정보 제거 = 철학 부합 ✅

## 3. 공지 + 할일 항상 표시 분석

### 3.1 접힘 vs 항상 표시

| 방식 | 장점 | 단점 |
|------|------|------|
| 접힘 (현재) | 공간 절약 | 한 번 더 탭 필요 |
| 항상 표시 | 즉시 확인 | 스크롤 증가 |

### 3.2 토스 철학 적용

> **"즉시성 - 핵심 정보는 숨기지 않는다"**

공지와 할일은 선생님이 **즉시 확인해야 할 핵심 정보**
→ 항상 표시가 철학에 더 부합 ✅

### 3.3 레이아웃 옵션

#### Option A: 세로 배치 (권장)

```
┌─────────────────────────────────────┐
│  🔔 공지사항 (2)                    │
│  • 김민수 결석 - 어머니 연락        │
│  • 12/11 전체 회의                  │
├─────────────────────────────────────┤
│  📋 오늘 할 일                      │
│  [출결 2건] [진도 1건] [숙제 5명]   │ ← 뱃지 형태
└─────────────────────────────────────┘
```

**장점:**
- 각 섹션 명확 구분
- 공지는 텍스트, 할일은 뱃지로 차별화
- 스크롤 최소화

---

#### Option B: 카드 분리

```
┌──────────────────┐ ┌──────────────────┐
│  🔔 공지 (2)     │ │  📋 할일 (3)    │
│  김민수 결석     │ │  출결 2건       │
│  전체 회의      │ │  진도 1건       │
└──────────────────┘ └──────────────────┘
```

**장점:**
- 시각적 분리
- 한눈에 둘 다 보임

**단점:**
- 공간 더 필요
- 모바일에서 좁음

---

#### Option C: 인라인 뱃지 + 상세 (권장 조합)

```
┌─────────────────────────────────────┐
│  🔔 2  ·  📋 3                      │ ← 상단 요약
├─────────────────────────────────────┤
│  • 김민수(중3A) 결석 - 병원         │
│  • 12/11(수) 전체 회의              │
├─────────────────────────────────────┤
│  [출결 2건] [진도 1건] [숙제 5명]   │ ← 할일 뱃지
└─────────────────────────────────────┘
```

**장점:**
- 숫자로 빠른 파악 (상단)
- 상세 내용도 즉시 확인
- 할일은 뱃지로 간결하게

---

### 3.4 할일 표시 방식 비교

| 방식 | 예시 | 공간 | 정보량 |
|------|------|------|--------|
| 카드 리스트 | 3개 카드 세로 | 많음 | 많음 |
| **뱃지 행** | [출결 2] [진도 1] [숙제 5] | 적음 | 적당 |
| 텍스트 | "출결 2건, 진도 1건" | 최소 | 최소 |

**권장: 뱃지 행** - 탭 가능 + 시각적 + 간결

## 4. 월간 캘린더 버튼 위치 분석

### 4.1 현재 위치 문제

```
┌─────────────────────────────┬───┐
│  📅 12월 10일 (화) ▼       │ 📆│ ← 두 개 버튼이 분리
└─────────────────────────────┴───┘
```

**문제:**
- 날짜 관련 액션이 두 군데
- 📆 버튼 역할이 직관적이지 않음
- UI가 복잡해 보임

### 4.2 드롭다운 내부로 이동

```
드롭다운 열기 전:
┌─────────────────────────────────┐
│  📅 12월 10일 (화) [오늘] ▼    │ ← 하나의 트리거
└─────────────────────────────────┘

드롭다운 열린 후:
┌─────────────────────────────────┐
│  ← 12월 2주차 →    [📆 월간]   │ ← 월간 버튼 여기!
├─────────────────────────────────┤
│  월  화  수  목  금  토  일     │
│  9  [10] 11  12  13  14  15    │
└─────────────────────────────────┘
```

### 4.3 버튼 위치 옵션

#### Option A: 주차 헤더 우측 (권장)

```
┌─────────────────────────────────────┐
│  ←  12월 2주차  →     [📆 월간]    │
├─────────────────────────────────────┤
│  월  화  수  목  금  토  일        │
│  9  [10] 11  12  13  14  15       │
└─────────────────────────────────────┘
```

**장점:**
- 네비게이션(←→)과 같은 줄
- "더 넓은 범위 보기" 의미 명확
- 공간 효율적

---

#### Option B: 드롭다운 하단

```
┌─────────────────────────────────────┐
│  ←  12월 2주차  →                  │
├─────────────────────────────────────┤
│  월  화  수  목  금  토  일        │
│  9  [10] 11  12  13  14  15       │
├─────────────────────────────────────┤
│         [📆 월간 캘린더 보기]       │
└─────────────────────────────────────┘
```

**장점:**
- 눈에 잘 띔
- 버튼이 커서 탭하기 쉬움

**단점:**
- 드롭다운이 길어짐
- 주간 선택 후 닫히는 타이밍 애매

---

#### Option C: 주간 그리드 하단 인라인

```
┌─────────────────────────────────────┐
│  ←  12월 2주차  →                  │
├─────────────────────────────────────┤
│  월  화  수  목  금  토  일        │
│  9  [10] 11  12  13  14  15       │
│                                     │
│  더 먼 날짜? [월간 보기 →]         │ ← 텍스트 링크
└─────────────────────────────────────┘
```

**장점:**
- 자연스러운 안내
- 버튼보다 부드러움

---

### 4.4 권장: Option A (주차 헤더 우측)

**이유:**
1. **논리적 위치**: 주차 네비게이션과 같은 맥락 (시간 범위 조절)
2. **공간 효율**: 추가 행 불필요
3. **즉각성**: 드롭다운 열자마자 바로 보임
4. **일관성**: ← (좁히기) | → (넓히기) | 월간 (더 넓히기)

## 6. 정보 계층 최종

```
Level 1: 날짜 선택
└─ 주간 드롭다운 (내부에 월간 버튼)

Level 2: 오늘의 핵심
└─ 히어로 카드 캐러셀 (출결/진도 액션)

Level 3: 오늘의 알림
├─ 공지사항 (2-3개, 항상 표시)
└─ 할일 뱃지 (탭 가능)
```

**제거된 것:**
- ~~타임라인~~ (히어로와 중복)
- ~~접힘/펼침 토글~~ (핵심 정보는 숨기지 않음)
- ~~월간 버튼 별도 위치~~ (드롭다운으로 통합)

## 8. 세부 디자인 결정

### 8.1 공지 표시 개수

| 개수 | 상황 |
|------|------|
| 0개 | "새로운 공지가 없습니다" 텍스트 |
| 1-3개 | 모두 표시 |
| 4개+ | 3개 + "외 N개 더보기" 링크 |

### 8.2 할일 뱃지 색상

```
[✓ 출결 2건]  → 초록 배경
[📄 진도 1건] → 파랑 배경
[📝 숙제 5명] → 주황 배경
```

### 8.3 공지/할일 통합 카드 상태

- 공지 있음 + 할일 있음 → 둘 다 표시
- 공지만 있음 → 공지만 표시
- 할일만 있음 → 할일만 표시
- 둘 다 없음 → "오늘 할 일을 모두 완료했어요! 🎉"
