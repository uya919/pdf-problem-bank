# Option C 개선안: 주간 드롭다운 + 월간 모달 연구

> 작성일: 2025-12-10
> 요청: 오늘 클릭 → 이번주 드롭다운 / 요일 클릭 → 해당 날 대시보드 / 월간 선택 버튼 별도
> 추가 고려: 오늘 할일 간소화 또는 공지로 대체

---

## 1. 제안 개요

### 1.1 현재 vs 개선안

| 항목 | 현재 Option C | 개선안 |
|------|---------------|--------|
| 날짜 클릭 | 바텀시트 모달 (월간) | **주간 드롭다운** (빠른 접근) |
| 월간 선택 | 없음 | **별도 버튼** (📅 아이콘) |
| 날짜 변경 | 모달에서 선택 → 확인 | **즉시 전환** (탭하면 바로 변경) |
| 오늘 할일 | 3개 카드 리스트 | **한 줄 요약** 또는 공지로 대체 |

## 2. UI/UX 철학 분석

### 2.1 토스 디자인 원칙 적용

| 원칙 | 현재 문제 | 개선안 해결 |
|------|-----------|-------------|
| **즉시성** | 모달 열기 → 선택 → 확인 (3단계) | 드롭다운 → 탭 (2단계) |
| **맥락 유지** | 모달이 화면을 덮음 | 드롭다운은 대시보드 위에 오버레이 |
| **집중** | 할일 3개가 공간 차지 | 한 줄 요약으로 핵심만 |
| **예측 가능** | 월간에서 날짜 찾기 | 주간에서 바로 보임 |

### 2.2 사용자 시나리오 분석

**가장 흔한 날짜 이동 패턴:**

| 이동 | 빈도 | 현재 UX | 개선안 UX |
|------|------|---------|-----------|
| 오늘 → 내일 | 매우 높음 | 모달 → 캘린더 스크롤 → 선택 | **드롭다운 → 탭** |
| 오늘 → 어제 | 높음 | 모달 → 캘린더 스크롤 → 선택 | **드롭다운 → 탭** |
| 오늘 → 이번주 금요일 | 중간 | 모달 → 캘린더 → 선택 | **드롭다운 → 탭** |
| 오늘 → 지난주 | 낮음 | 모달 → 이전 달 → 선택 | 📅 버튼 → 월간 모달 |
| 오늘 → 다음 달 | 드묾 | 모달 → 다음 달 → 선택 | 📅 버튼 → 월간 모달 |

**결론**: 80%의 날짜 이동은 **이번 주 내**에서 발생 → 주간 드롭다운이 최적

## 3. 주간 드롭다운 상세 설계

### 3.1 드롭다운 구조

```
┌─────────────────────────────────────────────────┐
│  ←  12월 2주차 (9일 ~ 15일)  →                 │ ← 주차 네비게이션
├─────────────────────────────────────────────────┤
│   월      화      수      목      금      토    일   │
│   9      [10]     11      12      13      14    15   │
│   ●       ●       ●       ●       ●            ●    │ ← 수업 있는 날 도트
│  3개    3개     4개     1개     2개          1개   │ ← 수업 개수 (선택적)
└─────────────────────────────────────────────────┘
```

### 3.2 인터랙션

| 액션 | 결과 |
|------|------|
| 날짜 바 클릭 | 주간 드롭다운 토글 |
| 요일 탭 | 즉시 해당 날 대시보드로 전환 (애니메이션) |
| ← / → 버튼 | 이전/다음 주로 이동 |
| 📅 버튼 | 월간 캘린더 바텀시트 열기 |
| 바깥 영역 탭 | 드롭다운 닫기 |

### 3.3 상태별 스타일

| 상태 | 스타일 |
|------|--------|
| 오늘 | 파란 원형 배경 + 흰 글씨 |
| 선택된 날 (오늘 아닐 때) | 파란 테두리 |
| 수업 있는 날 | 하단에 파란 도트 |
| 수업 없는 날 | 회색 텍스트 |

## 4. 오늘 할일 vs 공지 레이아웃 분석

### 4.1 Option A: 통합 요약 바 (권장)

```
┌─────────────────────────────────────────────────┐
│  🔔 공지 2개  ·  📋 할일 3건                    │
│  김민수 결석 / 출결 미입력 2건, 진도 미기록 1건 │ ← 한 줄 요약
└─────────────────────────────────────────────────┘
         ↓ 탭하면 확장
┌─────────────────────────────────────────────────┐
│  🔔 공지사항 (2)              [전체보기]        │
│  • 김민수(중3A) 결석 - 병원                     │
│  • 12/11(수) 전체 회의                          │
│                                                 │
│  📋 오늘 할 일 (3)                              │
│  • 출결 미입력 2건                              │
│  • 진도 미기록 1건                              │
│  • 숙제 확인 5명                                │
└─────────────────────────────────────────────────┘
```

**장점:**
- 공간 효율 (접힌 상태에서 한 줄)
- 공지 + 할일 통합 관리
- 필요할 때만 확장

**단점:**
- 정보 숨김 (한 번 더 탭 필요)

---

### 4.2 Option B: 공지 우선 + 할일 뱃지

```
┌─────────────────────────────────────────────────┐
│  🔔 공지사항 (2)                   [전체보기]   │
│  ├─ 김민수(중3A) 결석 - 병원                   │
│  └─ 12/11(수) 전체 회의                        │
└─────────────────────────────────────────────────┘

히어로 카드 하단에 뱃지로:
┌─────────────────────────────────────────────────┐
│  [출결 2건] [진도 1건] [숙제 5명]               │ ← 할일 뱃지 (탭 가능)
└─────────────────────────────────────────────────┘
```

**장점:**
- 공지가 더 눈에 띔
- 할일은 히어로 카드 액션과 연결

**단점:**
- 할일이 분산됨

---

### 4.3 Option C: 할일 인라인 (한 줄)

```
┌─────────────────────────────────────────────────┐
│  📋 출결 2건 · 진도 1건 · 숙제 5명    [상세]   │ ← 한 줄
└─────────────────────────────────────────────────┘
```

**장점:**
- 최소 공간
- 핵심 숫자만

**단점:**
- 세부 정보 없음

---

### 4.4 레이아웃 권장: Option A (통합 요약 바)

**이유:**
1. **공간 효율**: 기본은 한 줄, 필요시 확장
2. **정보 계층**: 숫자로 빠르게 파악 → 확장해서 상세 확인
3. **일관성**: 공지와 할일을 같은 패턴으로 관리
4. **유연성**: 공지만 있는 날, 할일만 있는 날 대응 가능

## 6. 정보 계층 정리

### 6.1 최종 구조

```
Level 1: 날짜 선택
├─ 주간 드롭다운 (이번 주 빠른 이동)
└─ 월간 모달 (먼 날짜 탐색)

Level 2: 오늘의 핵심 (히어로)
├─ 수업 카드 캐러셀
└─ 출결/진도 액션 버튼

Level 3: 오늘의 요약 (한 줄)
├─ 공지 개수 + 미리보기
└─ 할일 개수 + 미리보기

Level 4: 오늘의 타임라인 (한 줄)
└─ 시간순 수업 리스트
```

### 6.2 vs 현재 대시보드

| 현재 | 개선안 | 변화 |
|------|--------|------|
| 공지 드롭박스 (3-5줄) | 통합 요약 바 (1줄) | -4줄 |
| 히어로 카드 | 동일 | 0 |
| 할일 리스트 (3카드) | 통합 요약에 포함 | -3카드 |
| 타임라인 | 한 줄로 압축 | -2줄 |
| **날짜 선택 없음** | **주간 드롭다운 추가** | +신기능 |

**결과**: 더 많은 기능 + 더 적은 스크롤

## 9. 결론

### 9.1 개선안 요약

| 항목 | 변경 |
|------|------|
| 날짜 선택 | 주간 드롭다운 + 월간 모달 분리 |
| 요일 이동 | 즉시 전환 (모달 확인 불필요) |
| 공지/할일 | 통합 요약 바 (한 줄, 펼침 가능) |
| 타임라인 | 한 줄 압축 |

### 9.2 UX 개선 효과

| 지표 | 현재 | 개선안 |
|------|------|--------|
| 내일 이동 탭 수 | 4회 (모달→선택→확인→닫기) | **2회** (드롭→탭) |
| 스크롤 필요 | 있음 | **최소화** |
| 정보 밀도 | 낮음 | **높음** |
| 핵심 집중 | 분산 | **집중** (히어로 중심) |

### 9.3 토스 철학 부합도

| 원칙 | 점수 | 이유 |
|------|------|------|
| 집중 | ⭐⭐⭐⭐⭐ | 히어로 카드 중심, 나머지 압축 |
| 단순 | ⭐⭐⭐⭐⭐ | 2단계 이하 접근 |
| 즉시성 | ⭐⭐⭐⭐⭐ | 드롭다운 → 즉시 전환 |
| 맥락 | ⭐⭐⭐⭐ | 주간 뷰로 이번 주 맥락 유지 |
