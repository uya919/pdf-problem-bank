# 공지 + 할일 통합 뱃지 연구

> 작성일: 2025-12-11
> 아이디어: 공지도 "읽어야 할 업무"로 취급하여 할일 뱃지와 통합

---

## 1. 현재 상황

### 현재 레이아웃
```
┌─────────────────────────────────────────────────┐
│ 🔔 공지 2 · 📋 할일 3                            │ ← 요약 헤더
├─────────────────────────────────────────────────┤
│ ● 김민수(중3A) 결석 - 병원                       │
│   어머니 연락 필요                               │ ← 공지 리스트
│ ● 12/11(수) 전체 회의                           │    (공간 많이 차지)
│   14:00 강당                                    │
├─────────────────────────────────────────────────┤
│ [출결 2] [진도 1] [숙제 5]                       │ ← 할일 뱃지
└─────────────────────────────────────────────────┘
```

**문제점:**
- 공지가 리스트로 펼쳐져 공간 많이 차지
- 할일 뱃지와 UI 불일치
- 카드 높이 과다

---

## 2. 제안: 공지 → 뱃지 통합

### 새 레이아웃
```
┌─────────────────────────────────────────────────┐
│ [🔔 공지 2] [✓ 출결 2] [📄 진도 1] [📝 숙제 5]   │
└─────────────────────────────────────────────────┘
```

**변화:**
| 항목 | Before | After |
|------|--------|-------|
| 공지 | 리스트 (펼침) | **뱃지 (접힘)** |
| 할일 | 뱃지 | 뱃지 (유지) |
| 전체 높이 | ~180px | **~60px** |
| 정보 접근 | 즉시 | 탭 필요 |

---

## 3. UX 철학 분석

### 토스 철학 적용

| 원칙 | 적용 |
|------|------|
| **집중** | 숫자만 보여주고 상세는 탭 후 |
| **단순** | 모든 업무를 동일한 뱃지 형태로 |
| **즉시성** | 한눈에 "오늘 할 일 4가지" 파악 |
| **행동 유도** | 빨간 숫자 → 탭 유도 |

### Progressive Disclosure

```
Level 1: 뱃지 요약    → [공지 2]
Level 2: 탭하면 상세  → 김민수 결석, 전체 회의
Level 3: 다시 탭하면  → 상세 페이지
```

## 4. 디자인 옵션

### Option A: 4개 뱃지 균등 (권장)

```
┌────────────────────────────────────────────────┐
│ [공지 2] [출결 2] [진도 1] [숙제 5]             │
└────────────────────────────────────────────────┘
```

**스펙:**
- 4개 뱃지, flex-1 균등 분배
- 공지: 빨간색 강조 (미읽음 있을 때)
- 탭 → 바텀시트 또는 상세 페이지

**장점:**
- 매우 컴팩트
- 일관된 UI
- 스크롤 최소화

---

### Option B: 공지 분리 강조

```
┌────────────────────────────────────────────────┐
│ [🔔 공지 2 (새글)]                              │ ← 공지 강조
├────────────────────────────────────────────────┤
│ [출결 2] [진도 1] [숙제 5]                      │ ← 할일
└────────────────────────────────────────────────┘
```

**장점:**
- 공지 = 중요 알림 강조
- 할일과 구분

**단점:**
- 2줄 차지

---

### Option C: 공지 우측 배치

```
┌────────────────────────────────────────────────┐
│ [출결 2] [진도 1] [숙제 5]      [🔔 2]          │
│                                 ↑ 공지 아이콘   │
└────────────────────────────────────────────────┘
```

**장점:**
- 할일 중심 (공지는 보조)
- 공간 효율

**단점:**
- 공지 인지 어려움

---

### Option D: 그리드 카드 + 공지 포함 (확장형)

```
┌───────────┬───────────┬───────────┬───────────┐
│    🔔     │     ✓     │     📄    │     📝    │
│  공지 2   │  출결 2   │  진도 1   │  숙제 5   │
│   새글    │  중1C반   │  중3A반   │  확인필요  │
└───────────┴───────────┴───────────┴───────────┘
```

**장점:**
- 정보량 최대
- 모든 업무 동등 취급
- 서브타이틀 표시 가능

**단점:**
- 4열은 좁을 수 있음 (모바일)

## 5. 공지 상세 접근 방식

### 5.1 바텀시트 (권장)

```
[공지 2] 탭 →

┌─────────────────────────────────────────────────┐
│ 공지사항                              [닫기]    │
├─────────────────────────────────────────────────┤
│ ● 김민수(중3A) 결석 - 병원                      │
│   어머니 연락 필요                              │
│                                                 │
│ ● 12/11(수) 전체 회의                          │
│   14:00 강당                                    │
└─────────────────────────────────────────────────┘
```

### 5.2 확장/접기

```
[공지 2] 탭 → 아래로 확장:

┌─────────────────────────────────────────────────┐
│ [🔔 공지 2 ▲] [✓ 출결 2] [📄 진도 1] [📝 숙제 5]│
├─────────────────────────────────────────────────┤
│ ● 김민수(중3A) 결석                             │
│ ● 전체 회의 14:00                               │
└─────────────────────────────────────────────────┘
```

### 5.3 페이지 이동

```
[공지 2] 탭 → /notices 페이지로 이동
```
