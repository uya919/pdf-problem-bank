## 1. 현재 상태 분석

### 1.1 구현 완료된 대시보드 컴포넌트

| 컴포넌트 | 기능 | 상태 |
|----------|------|------|
| HeroCarousel | 오늘 수업 캐러셀 (스와이프) | 완료 |
| TaskBadgeCard | 공지/출결/진도/숙제 4뱃지 드롭다운 | 완료 |
| DateSelector | 날짜 선택 + 주간 드롭다운 | 완료 |
| AttendanceModal | 출결 체크 (3상태 + 사유) | 완료 |
| ProgressModal | 진도 기록 바텀시트 | 완료 |
| HomeworkModal | 숙제 확인 모달 | 완료 |
| MonthlyCalendarModal | 월간 캘린더 모달 | 완료 |

### 1.2 현재 네비게이션 구조 (예정)

```
[홈]  [수업]  [학생]  [기록]  [더보기]
  │      │       │       │       │
  │      │       │       │       └─ 설정, 공지사항 전체, 프로필
  │      │       │       └─ 출결/진도/숙제 히스토리, 통계
  │      │       └─ 학생 목록, 학생 상세
  │      └─ 날짜별 수업, 캘린더, 수업 상세
  └─ 대시보드 (오늘 중심)
```

## 2. Hyeyum 기능 매핑 분석

## 3. 페이지별 상세 설계

### 3.1 [홈] 대시보드 페이지

> **목적**: 오늘, 지금, 해야 할 일의 허브

#### 3.1.1 위젯 구성

```
┌──────────────────────────────────────────────────────────┐
│  2025년 12월 11일 (수)  ▼                    [📅 월간]   │  ← DateSelector
├──────────────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────────────────┐  │
│  │  ⏱ 다음 수업        NOW                           │  │  ← HeroCarousel
│  │  17:00 - 19:00                                     │  │
│  │  중3A반 수학 | 학생 8명                             │  │
│  │  [✓ 출결 체크]    [📝 진도 기록]                    │  │
│  └────────────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────────────┤
│  [🔔 공지 2▲] [✓ 출결 1] [📄 진도 2] [📝 숙제 1]       │  ← TaskBadgeCard
│  ├─────────────────────────────────────────────────────  │
│  │  • 김민수(중3A) 결석 알림 - 어머니 전화 필요  [확인] │  │  ← 드롭다운
│  │  • 12/11(수) 전체 회의 14:00             [확인] │  │
│  └─────────────────────────────────────────────────────  │
└──────────────────────────────────────────────────────────┘
```

#### 3.1.2 액션 → 페이지 연결

| 액션 | 이동 | 데이터 전달 |
|------|------|-------------|
| 출결 체크 버튼 | AttendanceModal | classId, date |
| 진도 기록 버튼 | ProgressModal | classId, date |
| 출결 뱃지 탭 | 드롭다운 확장 | 미완료 출결 목록 |
| 진도 뱃지 탭 | 드롭다운 확장 | 미기록 진도 목록 |
| 숙제 뱃지 탭 | HomeworkModal | homeworkId |
| 공지 "전체보기" | [더보기] > 공지사항 | - |
| 월간 버튼 | MonthlyCalendarModal | selectedDate |
| 수업 카드 탭 | [수업] > 수업 상세 | classId |

#### 3.2.3 데이터 구조 (Supabase)

```typescript
// 수업 페이지에서 필요한 쿼리
interface ClassPageData {
  // 반 정보
  class: {
    id: string;
    name: string;
    subject: string;
    teacher_id: string;
    schedule: { days: string[]; start_time: string; end_time: string };
  };

  // 학생 목록
  students: {
    id: string;
    name: string;
    status: 'active' | 'inactive';
  }[];

  // 출결 기록
  attendance: {
    date: string;
    records: { student_id: string; status: AttendanceStatus }[];
  }[];

  // 진도 기록
  progress: {
    date: string;
    textbook: string;
    start_page: number;
    end_page: number;
    topic: string;
  }[];

  // 숙제
  homework: {
    id: string;
    title: string;
    due_date: string;
    submissions: { student_id: string; status: string }[];
  }[];
}
```

```tsx
// frontend/src/components/backoffice/navigation/BottomNav.tsx

interface NavItem {
  id: string;
  label: string;
  icon: string;
  activeIcon: string;

}

const NAV_ITEMS: NavItem[] = [
  { id: 'home', label: '홈', icon: '🏠', activeIcon: '🏠', path: '/backoffice' },

  { id: 'more', label: '더보기', icon: '☰', activeIcon: '☰', path: '/backoffice/more' },
];

export function BottomNav({ currentPath }: { currentPath: string }) {
  return (
    <nav className="fixed bottom-0 left-0 right-0 bg-white border-t border-gray-100">
      <div className="flex justify-around items-center h-16">

      </div>

  );
}
```

## 7. 결론 및 권장사항

### 7.1 핵심 원칙

1. **대시보드 = 오늘의 허브**
   - 오늘 해야 할 일만 집중
   - 과거/미래는 다른 탭에서

2. **Progressive Disclosure**
   - 기본: 요약 정보
   - 탭: 상세 정보
   - 모달: 입력/수정

3. **일관된 패턴**
   - 목록 → 상세 → 액션
   - 탭 → 필터 → 리스트

### 7.2 다음 단계 권장

| 우선순위 | 작업 | 이유 |
|---------|------|------|
| P0 | 라우터 설정 | 페이지 네비게이션 기반 |
| P0 | BottomNav 구현 | 모든 페이지 공통 |
| P1 | [수업] 페이지 | 대시보드 다음 핵심 |
| P1 | [학생] 페이지 | 수업과 연결 |
| P2 | [기록] 페이지 | 통계/히스토리 |
| P2 | [더보기] 페이지 | 부가 기능 |

### 7.3 데이터베이스 연동 시점

```
1. 목업/더미 데이터로 UI 완성 (현재)
2. 모든 페이지 레이아웃 완료
3. Supabase 연동 시작
4. 읽기 연동 → 쓰기 연동 순서
```
