# 할일 뱃지 1줄 표현 연구

> 작성일: 2025-12-11
> 요청: 모바일에서 할일 뱃지 3개를 1줄로 표현

---

## 1. 현재 상황 분석

### 1.1 현재 뱃지 텍스트
```
[✓ 출결 미입력 2건]  [📄 진도 미기록 1건]  [📝 숙제 확인 필요 5명]
```

### 1.2 문자 수 분석
| 뱃지 | 텍스트 | 글자 수 |
|------|--------|---------|
| 출결 | "출결 미입력 2건" | 8자 |
| 진도 | "진도 미기록 1건" | 8자 |
| 숙제 | "숙제 확인 필요 5명" | 10자 |
| **합계** | | **26자 + 아이콘 3개** |

### 1.3 모바일 화면 제약
- iPhone SE: 320px
- iPhone 14: 390px
- 일반 Android: 360~400px
- 좌우 패딩 제외: 약 **320~360px** 가용

### 1.4 현재 문제
```
320px 화면에서:
┌────────────────────────────────┐
│ [출결 미입력 2건] [진도 미기록 1건] │ ← 2개만 들어감
│ [숙제 확인 필요 5명]              │ ← 줄바꿈 발생
└────────────────────────────────┘
```

## 2. 해결 방안

### Option A: 텍스트 축약 (권장)

**현재 → 축약:**
| 현재 | 축약 버전 | 글자 수 |
|------|----------|---------|
| 출결 미입력 2건 | **출결 2** | 3자 |
| 진도 미기록 1건 | **진도 1** | 3자 |
| 숙제 확인 필요 5명 | **숙제 5** | 3자 |

**레이아웃:**
```
┌────────────────────────────────┐
│  [✓ 출결 2]  [📄 진도 1]  [📝 숙제 5]  │
└────────────────────────────────┘
```

**장점:**
- 가장 간결
- 아이콘으로 의미 전달
- 숫자로 긴급도 파악

**계산:**
- 각 뱃지: 아이콘(20px) + 텍스트(~36px) + 패딩(24px) = ~80px
- 3개: 240px + 간격(16px×2) = **272px** ✅

---

### Option B: 숫자만 강조

**형태:**
```
[✓ 2] [📄 1] [📝 5]
```

**장점:**
- 극도로 간결
- 아이콘이 의미 전달

**단점:**
- 처음 보는 사용자는 이해 어려움
- "2"가 뭘 의미하는지 모름

---

### Option C: 아이콘 + 뱃지 숫자

**형태:**
```
✓₂  📄₁  📝₅
```
또는
```
[✓] 2  [📄] 1  [📝] 5
```

**장점:**
- 매우 컴팩트

**단점:**
- 탭 영역이 작아 UX 저하
- 접근성 문제

---

### Option D: 카테고리명 + 숫자 (중간안)

**형태:**
```
[출결 2건] [진도 1건] [숙제 5명]
```

**장점:**
- 현재보다 40% 축약
- 의미 전달 유지

**계산:**
- 각 뱃지: 아이콘(20px) + 텍스트(~48px) + 패딩(24px) = ~92px
- 3개: 276px + 간격(16px×2) = **308px** ✅ (빠듯함)

---

### Option E: 가로 스크롤

**형태:**
```
┌────────────────────────────────┐
│ ← [출결 미입력 2건] [진도 미기록 1건] [숙제...] → │
└────────────────────────────────┘
```

**장점:**
- 텍스트 수정 불필요

**단점:**
- 숨겨진 항목 인지 어려움
- 스크롤 힌트 필요
- UX 복잡

---

## 3. 토스 스타일 분석

토스 앱의 유사 UI 패턴:

```
┌────────────────────────────────┐
│  송금 3  ·  충전 1  ·  결제 2   │  ← 인라인 텍스트
└────────────────────────────────┘
```

또는:
```
┌────────────────────────────────┐
│  [3건] 송금  [1건] 충전  [2건] 결제  │  ← 숫자 뱃지 + 텍스트
└────────────────────────────────┘
```

**토스 철학 적용:**
- **숫자가 핵심**: 몇 건인지가 가장 중요
- **행동 유도**: 탭하면 상세 페이지로
- **간결함**: 불필요한 단어 제거

## 4. 권장안: Option A 변형

### 4.1 최종 제안

```
┌────────────────────────────────┐
│  [✓ 출결 2]  [📄 진도 1]  [📝 숙제 5]  │
└────────────────────────────────┘
```

### 4.2 상세 스펙

| 항목 | 값 |
|------|-----|
| 뱃지 높이 | 32px |
| 폰트 크기 | 13px |
| 아이콘 크기 | 14px |
| 좌우 패딩 | 12px |
| 뱃지 간격 | 8px |
| 뱃지 너비 | auto (내용에 맞춤) |

### 4.3 텍스트 규칙

| 카테고리 | 축약 | 예시 |
|----------|------|------|
| 출결 미입력 | 출결 N | 출결 2 |
| 진도 미기록 | 진도 N | 진도 1 |
| 숙제 확인 필요 | 숙제 N | 숙제 5 |

### 4.4 320px 화면 계산

```
가용 너비: 320px - 32px(패딩) = 288px

뱃지 1: 12 + 14 + 4 + 39 + 12 = 81px  (출결 2)
뱃지 2: 12 + 14 + 4 + 39 + 12 = 81px  (진도 1)
뱃지 3: 12 + 14 + 4 + 39 + 12 = 81px  (숙제 5)
간격: 8px × 2 = 16px

합계: 81 + 81 + 81 + 16 = 259px ✅ (여유 29px)
```

## 6. 최종 결정

### 권장: Option A (텍스트 축약)

```tsx
// 현재
{ title: '출결 미입력', count: '2건' }

// 변경
{ title: '출결', count: '2' }
```

**이유:**
1. **1줄 보장**: 320px에서도 3개 뱃지 표시 가능
2. **의미 유지**: 아이콘 + 카테고리명으로 충분
3. **토스 철학**: 숫자가 핵심, 나머지는 최소화
4. **탭 영역**: 적절한 크기 유지 (44px 이상 높이)
