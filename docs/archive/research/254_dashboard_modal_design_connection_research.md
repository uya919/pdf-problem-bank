## 2. 연결성 디자인 원칙

### 2.1 Visual Continuity (시각적 연속성)

> "대시보드에서 모달까지 같은 공간에 있는 느낌"

```
대시보드                    모달
┌─────────┐               ┌─────────┐
│ 수업카드 │ ──[tap]──→   │ 상세기록 │
│ 미리보기 │               │ 입력폼  │
└─────────┘               └─────────┘
    ↑                         ↑
    └─── 같은 정보 확장 ────────┘
```

**원칙:**
1. 같은 컬러 시스템
2. 같은 타이포그래피
3. 같은 스페이싱 규칙
4. 정보의 연속성 (미리보기 → 상세)

### 2.2 Context Preservation (컨텍스트 유지)

```javascript
// 대시보드 수업 카드
{
  classId: "class-01",
  className: "중3A반",
  time: "17:00-19:00",
  lastProgress: "베이직쎈 p.42-45",  // ← 이 정보가
  unit: "이차방정식"                  // ← 모달에 전달
}

// 모달 열릴 때
{
  header: "중3A반 수업 기록",         // 어디서 왔는지 표시
  lastSession: "12/9 · 베이직쎈 42-45",
  currentUnit: "이차방정식"           // 자동 채움
}
```

### 2.3 Progressive Disclosure (점진적 노출)

| 레벨 | 화면 | 정보량 |
|------|------|--------|
| L1 | 대시보드 | 최소 (수업명, 시간) |
| L2 | 수업 카드 확장 | 요약 (지난 진도, 숙제) |
| L3 | 진도기록 모달 | 상세 (입력 폼) |

## 3. 대시보드 디자인 - v4 모달 연결

### 3.1 수업 카드 디자인 (대시보드)

```
┌─────────────────────────────────────┐
│  중3A반                    17:00   │  ← 헤더
│  ─────────────────────────────────  │
│  📚 이차방정식                      │  ← 단원명 (모달과 동일)
│  📄 베이직쎈 p.42-45               │  ← 지난 진도
│                                     │
│  ┌─────────────────────────────────┐│
│  │         기록하기                 ││  ← 모달 트리거
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

### 3.2 카드 → 모달 전환 애니메이션

```css
/* 카드에서 모달로 확장되는 느낌 */
@keyframes cardToModal {
  0% {
    transform: scale(0.95);
    opacity: 0;
    transform-origin: center bottom;
  }
  100% {
    transform: scale(1);
    opacity: 1;
  }
}

.modal-enter {
  animation: cardToModal 0.3s ease-out;
}
```

**전환 효과:**
1. 카드 탭 → 카드 살짝 눌림 (0.1s)
2. 오버레이 페이드인 (0.2s)
3. 모달 하단에서 슬라이드업 (0.3s)

**수업 카드 액션 버튼:**

- `📝 숙제` → 숙제관리 모달
- `📊 시험` → 시험점수 모달

## 7. 전체 플로우 시각화

### 7.1 Happy Path

```
[대시보드]
    │
    ├── 수업 카드 확인
    │   └── 📚 이차방정식
    │       📄 지난: p.42-45
    │
    └── [기록하기] 탭
            │
            ↓
[모달 열림] ← 애니메이션 0.3s
    │
    ├── 헤더: "중3A반 수업 기록"
    │
    ├── 지난 수업 카드 (대시보드와 동일 스타일)
    │   └── 📚 이차방정식
    │       📄 p.42-45 · 숙제 p.46
    │
    ├── 오늘 수업 입력
    │   ├── 단원명: [이차방정식] (자동 채움)
    │   ├── 진도: [베이직쎈] [46]~[50]
    │   ├── 숙제: [베이직쎈] [50]~[53]
    │   └── 비고: [textarea]
    │
    └── [저장하기]
            │
            ↓
[저장 완료]
    │
    ├── 성공 피드백 (체크 애니메이션)
    │
    └── 대시보드로 복귀
        └── 카드 업데이트: "기록 완료"
```

### 7.2 대시보드 카드 상태 변화

| 상태 | 카드 표시 | 버튼 |
|------|----------|------|
| 미기록 | 지난 진도만 표시 | [기록하기] (파란색) |
| 기록 완료 | 오늘 진도 추가 | [수정하기] (회색) |

```
[미기록 상태]
┌─────────────────────────────────────┐
│  🕐 17:00  중3A반 · 8명             │
│  📄 지난: p.42-45                   │
│  [기록하기]                         │  ← 파란 버튼
└─────────────────────────────────────┘

[기록 완료]
┌─────────────────────────────────────┐
│  🕐 17:00  중3A반 · 8명      ✓ 완료 │  ← 완료 배지
│  📄 오늘: p.46-50                   │  ← 오늘 진도
│  [수정하기]                         │  ← 회색 버튼
└─────────────────────────────────────┘
```

## 10. 결론

### 연결성 핵심 포인트

1. **시각적 통일**: 같은 컬러, 타이포, 스페이싱
2. **컨텍스트 전달**: 카드 정보 → 모달 자동 채움
3. **애니메이션 연결**: 카드에서 모달로 자연스러운 전환
4. **상태 동기화**: 모달 저장 → 카드 업데이트

### 구현 우선순위

| 순위 | 작업 | 난이도 |
|------|------|--------|
| 1 | 디자인 토큰 정의 | 낮음 |
| 2 | 대시보드 수업 카드 | 중간 |
| 3 | 모달 헤더 수정 | 낮음 |
| 4 | 카드 → 모달 전환 애니메이션 | 중간 |
| 5 | 저장 후 카드 상태 업데이트 | 중간 |
