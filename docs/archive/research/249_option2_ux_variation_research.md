# 안 2 UX 변형 연구 리포트

> 1안의 각 화면을 어떻게 변형할 수 있을까?

---

## 연구 배경

### 1안 (수업 중심) 기본 구조
```
홈: 다음 수업 히어로 + 오늘 할 일 + 오늘 일정
수업: 오늘의 수업 목록 + Quick Actions
학생: 반별 필터 + 학생 목록
기록: 기록 유형별 진입점
```

### 질문
1. 대시보드에 공지가 2-3개일 때 솔루션은?
2. 어제의 공지가 궁금할 땐?
3. "오늘 할 일" 대신 뭘 넣을 수 있을까?
4. 어제/지난 수업이 궁금할 땐?
5. 학생 페이지는 언제 누르게 될까?

---

## 1. 대시보드: 공지사항

### Q1. 공지가 2-3개일 때 솔루션

#### 문제 상황
```
공지 1: 김민수 결석 (긴급)
공지 2: 고려중 기말고사 (시험)
공지 3: 전체 회의 (학원)
공지 4: 크리스마스 휴원 (학원)
```

4개의 공지를 모두 보여주면 스크롤 없이 다른 정보를 볼 수 없음.

#### 솔루션 비교

| 패턴 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **A. 우선순위 정렬** | 긴급 > 시험 > 일반 순 표시, 최대 2개만 | 간결함 | 숨겨진 공지 놓칠 수 있음 |
| **B. 그룹화 (Grouped)** | "오늘의 공지 4건" → 탭하면 펼침 | 공간 절약 | 추가 탭 필요 |
| **C. 스와이프 (Carousel)** | 좌우로 넘기며 확인 | 한 눈에 구조 파악 | 숨겨진 카드 놓칠 수 있음 |
| **D. 배너 + 더보기** | 가장 긴급한 1개만 + "더보기" | 최소 공간 | 나머지 공지 접근성 낮음 |

#### 토스라면?

**토스 패턴 분석:**
> "토스가 생각하는 단순함이란 사용자가 특별히 알아야 할 것 없이 직관적으로 이해할 수 있는 상태"

토스는 **중요한 것만 보여주고, 나머지는 명확한 진입점 제공**:

```
┌────────────────────────────────────┐
│ 🔴 김민수(중3A) 오늘 결석 - 병원    │  ← 긴급만 메인에
│    어머니 연락 · 오전 9:23          │
└────────────────────────────────────┘
┌────────────────────────────────────┐
│ 📢 공지 3건 더보기                  │  ← 나머지는 그룹화
│    고려중 기말, 전체 회의...        │
└────────────────────────────────────┘
```

**권장: A + D 혼합**
- 긴급(결석/조퇴)은 항상 노출
- 나머지는 "공지 N건 더보기"로 그룹화

---

### Q2. 어제의 공지가 궁금할 때

#### 시나리오
```
강사: "어제 뭐 공지 왔었는데... 시험 일정이었나?"
```

#### 솔루션 비교

| 패턴 | 설명 | UX 복잡도 |
|------|------|-----------|
| **A. 공지 센터** | 별도 화면 (전체 공지 목록) | 낮음 |
| **B. 날짜 필터** | "오늘 / 어제 / 이번 주" 탭 | 중간 |
| **C. 검색** | 공지 내용 검색 | 높음 |
| **D. 히스토리 자동 유지** | 읽은 공지도 일정 기간 보관 | 낮음 (자동) |

#### 토스라면?

토스 앱의 알림 센터 패턴:
- 상단 종 아이콘 → 알림 센터로 이동
- 날짜별 그룹화 ("오늘", "어제", "이번 주")
- 읽은 알림도 일정 기간 보관

**권장: A + D**
```
대시보드 상단:
┌────────────────────────────────────┐
│ 혜윰학원              🔔 (3)  👤   │
└────────────────────────────────────┘
                         ↓
                    공지 센터 진입
                    (날짜별 그룹화)
```

### Q3. "오늘 할 일" 대신 무엇을?

#### 현재: 오늘 할 일
```
- 출결 미입력 3건
- 진도 미기록 2건
- 숙제 확인 5명
```

**문제**: "할 일"은 부담감을 줌. 매일 볼 때마다 "아직 안 했네..."

#### 대안 비교

| 대안 | 내용 | 감정 | 적합도 |
|------|------|------|--------|
| **A. 오늘 기록 현황** | "출결 완료 2/3, 진도 완료 1/2" | 성취감 | ⭐⭐⭐ |
| **B. 어제 완료 요약** | "어제 기록 완료 8건" | 긍정적 | ⭐⭐ |
| **C. 학생 현황** | "오늘 출석 20명, 결석 2명" | 중립 | ⭐⭐⭐ |
| **D. 수업 요약** | "오늘 수업 3개 | 완료 1개" | 중립 | ⭐⭐⭐ |
| **E. 최근 활동** | 내 기록 타임라인 | 기록 회고 | ⭐⭐ |

#### 토스라면?

토스 철학: **"Value First"** - 사용자에게 가치 있는 정보 먼저

**권장: C (학생 현황) 또는 A (기록 현황)**

```
변형 1: 학생 현황 (확인 중심)
┌────────────────────────────────────┐
│ 📊 오늘의 학생 현황                 │
│                                    │
│   출석        결석       조퇴       │
│   18명        2명        1명       │
│   ────        ────       ────      │
│   정상        김민수     박서현     │
│              이지훈                │
└────────────────────────────────────┘

변형 2: 기록 현황 (성취감 중심)
┌────────────────────────────────────┐
│ ✅ 오늘 기록 현황                   │
│                                    │
│   출결 ████████░░ 80%              │
│   진도 ██████░░░░ 60%              │
│   숙제 ████░░░░░░ 40%              │
│                                    │
│   [미완료 항목 보기]                │
└────────────────────────────────────┘
```

**핵심 차이:**
- "오늘 할 일" → 부담 ("해야 해")
- "오늘 현황" → 정보 ("상황이 이래")

## 2. 수업 탭: 지난 수업

### Q4. 어제나 지난 수업이 궁금할 때

#### 시나리오
```
강사: "어제 중3A반 어디까지 했더라?"
강사: "지난주 월요일에 뭐 했었지?"
```

#### 솔루션 비교

| 패턴 | 설명 | 구현 복잡도 | 사용 편의성 |
|------|------|------------|------------|
| **A. 날짜 탭** | "오늘 / 어제 / 이번 주" | 낮음 | 높음 |
| **B. 캘린더 피커** | 달력에서 날짜 선택 | 중간 | 중간 |
| **C. 스와이프** | 좌우로 날짜 이동 | 낮음 | 높음 |
| **D. 검색** | 반 이름 + 날짜 검색 | 높음 | 낮음 |

#### 토스라면?

Date Filter 모범 사례 ([Evolving Web](https://evolvingweb.com/blog/most-popular-date-filter-ui-patterns-and-how-decide-each-one)):
> "Quick Filter Shortcuts - Besides a standard date picker, provide shortcuts (Today, Yesterday, This Month) for fast selection"

**권장: A + C 혼합**

```
┌────────────────────────────────────┐
│ ◀ 12/9(월)   12/10(화) ▶          │ ← 스와이프 또는 화살표
│ ─────────────────────────────────  │
│ [오늘] [어제] [이번 주] [📅]       │ ← 빠른 필터
└────────────────────────────────────┘

수업 목록:
┌────────────────────────────────────┐
│ 15:00 중1C반                       │
│ 진도: 베이직쎈 p.42-45             │
│ 출석: 8/8명                        │
└────────────────────────────────────┘
```

#### 지난 수업 접근이 중요한 이유

1. **진도 이어가기**: "어디까지 했더라?"
2. **숙제 확인**: "지난번에 뭘 내줬지?"
3. **학생 기록 확인**: "이 학생 지난주에 뭐라고 했더라?"

**추가 제안: 수업 카드에 "지난 진도" 자동 표시**
```
┌────────────────────────────────────┐
│ 17:00 - 19:00                      │
│ 중3A반 수학                        │
│ ──────────────────────────────────  │
│ 📖 지난 진도: 베이직쎈 p.42-45     │ ← 자동 표시
│    이차방정식 풀이                  │
│ ──────────────────────────────────  │
│ [출결] [진도] [숙제] [시험]        │
└────────────────────────────────────┘
```

## 3. 학생 페이지: 진입 시나리오

### Q5. 학생 페이지는 언제 누르게 될까?

#### 시나리오 분석

| 시나리오 | 트리거 | 필요 정보 | 빈도 |
|----------|--------|-----------|------|
| **A. 연락처 찾기** | "김민수 전화번호가?" | 학생/학부모 연락처 | 가끔 |
| **B. 상담 전 확인** | "상담 전에 정보 확인" | 전체 기록, 성적 추이 | 가끔 |
| **C. 기록 이슈** | "이 학생 결석이 몇 번?" | 출결 히스토리 | 가끔 |
| **D. 성적 확인** | "지난 시험 점수가?" | 시험 점수 히스토리 | 보통 |
| **E. 특이사항 기록** | "오늘 상담 내용 기록" | 메모 입력 | 가끔 |
| **F. 반별 학생 확인** | "중3A반 누가 있지?" | 반별 학생 목록 | 보통 |

#### 문제: 학생 탭의 정체성

**현재 혼란:**
- 학생 목록을 보려고? → 수업 탭에서도 가능
- 특정 학생 찾기? → 검색이 더 빠름
- 학생 상세 정보? → 어디서 진입?

**핵심 질문:**
> "학생 탭만의 고유 가치는 무엇인가?"

#### 솔루션 비교

| 방향 | 학생 탭의 역할 | 장점 | 단점 |
|------|---------------|------|------|
| **A. 검색 허브** | 학생 빠른 검색 + 최근 조회 | 목적 명확 | 기능 단순 |
| **B. 반별 관리** | 반 선택 → 학생 목록 | 수업 준비에 유용 | 수업 탭과 중복 |
| **C. 학생 360도 뷰** | 학생별 전체 정보 (프로필, 기록, 성적) | 깊은 정보 | 진입 경로 복잡 |
| **D. 관심 학생** | 즐겨찾기/관심 학생 빠른 접근 | 개인화 | 설정 필요 |

#### 토스라면?

토스 철학: **"1 thing / 1 page"**

**권장: A + C 혼합**

학생 탭 = **"학생 검색 + 360도 뷰 진입점"**

```
학생 탭 메인:
┌────────────────────────────────────┐
│ 🔍 학생 검색                       │ ← 검색 바 상단 고정
├────────────────────────────────────┤
│ 최근 조회                          │
│ ┌──────┐ ┌──────┐ ┌──────┐        │
│ │김민수│ │이서연│ │박지훈│        │ ← 최근 본 학생
│ │중3A  │ │중3A  │ │중2B  │        │
│ └──────┘ └──────┘ └──────┘        │
├────────────────────────────────────┤
│ 반별 보기                          │
│ [중3A반 8명] [중2B반 6명] [중1C반] │ ← 반별 진입점
└────────────────────────────────────┘

학생 상세 (탭하면):
┌────────────────────────────────────┐
│ ← 김민수                    📞 💬  │
│                                    │
│ 중3A반 | 고려중 3학년              │
│ ──────────────────────────────────  │
│ 📊 성적 추이        📅 출결 현황   │
│ ┌──────────────┐    출석 42회      │
│ │ ↗ 78 → 85   │    결석 2회       │
│ └──────────────┘    조퇴 1회       │
│ ──────────────────────────────────  │
│ 📝 최근 기록                       │
│ 12/9 - 숙제 미제출                 │
│ 12/8 - Daily test 78점             │
│ ──────────────────────────────────  │
│ 📌 특이사항                        │
│ [+ 메모 추가]                      │
└────────────────────────────────────┘
```

## 4. 종합: 2안 변형 제안

### 변형 방향

| 화면 | 1안 (원본) | 2안 변형 제안 |
|------|-----------|--------------|
| **홈** | 다음 수업 히어로 + 오늘 할 일 | 공지 (우선순위) + 학생 현황 |
| **수업** | 오늘 수업만 | 날짜 필터 + 지난 진도 자동 표시 |
| **학생** | 반별 목록 | 검색 허브 + 최근 조회 + 360도 뷰 |

### 2안 변형 네비게이션

```
홈 - 수업 - 학생 - 기록 - 더보기
        (또는 "성적"으로 대체 가능)
```

### 화면별 변형 요약

#### 홈 (대시보드)
```
Before (1안):
- 공지 배너 1개
- 다음 수업 히어로
- 오늘 할 일 (미완료 목록)
- 오늘 일정

After (2안 변형):
- 긴급 공지 + "공지 N건 더보기"
- 학생 현황 (출석/결석/조퇴)
- 기록 현황 (프로그레스 바)
- 오늘 수업 요약
```

#### 수업
```
Before (1안):
- 오늘 수업만

After (2안 변형):
- 날짜 필터 (오늘/어제/이번 주)
- 수업 카드에 "지난 진도" 자동 표시
- 스와이프로 날짜 이동
```

#### 학생
```
Before (1안):
- 반별 필터
- 학생 목록

After (2안 변형):
- 검색 바 상단 고정
- 최근 조회 학생
- 반별 진입점
- 학생 360도 뷰
```

## 5. 결론

### 핵심 인사이트

| 질문 | 토스 관점 답변 |
|------|--------------|
| 공지 2-3개? | 긴급만 노출, 나머지 그룹화 |
| 어제 공지? | 공지 센터 (종 아이콘) |
| 오늘 할 일 대신? | "학생 현황" 또는 "기록 현황" |
| 지난 수업? | 날짜 필터 + 스와이프 |
| 학생 탭 언제? | 검색/상세 정보 필요할 때 |

### 2안 변형의 차별점

```
1안: "빨리 기록하자" (Action 중심)
    → 다음 수업, 할 일, Quick Action

2안 변형: "상황 파악하고 기록하자" (Context 중심)
    → 공지, 현황, 히스토리, 상세 정보
```

### 적합한 강사 유형

| 유형 | 특징 | 추천 |
|------|------|------|
| 빠른 기록형 | 수업 끝나자마자 기록 | 1안 |
| 꼼꼼 확인형 | 상황 파악 후 기록 | 2안 변형 |
| 학생 관리형 | 개별 학생 케어 중시 | 2안 변형 (학생 360도 뷰) |
