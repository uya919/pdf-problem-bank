# 기간 선택 UI 컴팩트화 연구 리포트

> 작성일: 2025-12-11
> 목적: 기간 선택 영역의 세로 크기 최적화

---

## 1. 현재 레이아웃 분석

### 1.1 현재 구조 (목업 기준)

```
┌─────────────────────────────────────────┐
│ 반 정보 헤더                    (56px)  │
│   중3A반 · 수학 · 월/수/금 17:00        │
├─────────────────────────────────────────┤
│ 기간 선택 영역                  (80px)  │  ← 문제 영역
│   "기간" 라벨                           │
│   [2회] [3회] [5회] [월간]              │
│   12/9 (월) ~ 12/11 (수)                │
└─────────────────────────────────────────┘
총 높이: 약 136px
```

### 1.2 세로 공간 내역

| 요소 | 높이 | 비고 |
|------|------|------|
| 반 정보 패딩 | 16px | p-4 |
| 반 이름 + 정보 | 24px | |
| 구분선 | 1px | border |
| 기간 영역 패딩 | 16px | p-4 |
| "기간" 라벨 | 16px | text-xs |
| 라벨-세그먼트 간격 | 12px | mb-3 |
| 세그먼트 컨트롤 | 36px | |
| 날짜 범위 텍스트 | 16px | |
| **합계** | **~137px** | |

---

## 2. 문제점

### 2.1 공간 낭비 요소

1. **"기간" 라벨이 별도 행**
   - 세그먼트만 봐도 "기간 선택"임을 알 수 있음
   - 불필요한 라벨 = 16px + 12px 마진 낭비

2. **날짜 범위가 별도 행**
   - 세그먼트 우측 공간 활용 가능

3. **반 정보와 기간 선택이 분리**
   - 두 카드 형태로 구분
   - 통합하면 패딩/보더 절약

---

## 3. 컴팩트화 방안

### 3.1 방안 A: 라벨 제거 + 인라인 날짜

```
┌─────────────────────────────────────────┐
│ 중3A반  수학 · 월/수/금 17:00  [기록→]  │
├─────────────────────────────────────────┤
│ [2회][3회][5회][월간]    12/9~12/11    │
└─────────────────────────────────────────┘
높이: 약 88px (-49px, 36% 감소)
```

**변경사항**:
- "기간" 라벨 삭제
- 날짜 범위를 세그먼트 우측에 인라인 배치
- 반 정보 + 기간을 하나의 카드로

### 3.2 방안 B: 헤더 내 세그먼트 통합

```
┌─────────────────────────────────────────┐
│ 중3A반                         [기록→]  │
│ 수학 · 월/수/금 17:00                   │
│ [2회][3회][5회][월간]    12/9~12/11    │
└─────────────────────────────────────────┘
높이: 약 96px (-41px, 30% 감소)
```

**변경사항**:
- 3줄 구조 (반 이름 / 상세 / 기간)
- 구분선 제거
- 더 일체감 있는 디자인

### 3.3 방안 C: 최소 높이 (Pill 스타일)

```
┌─────────────────────────────────────────┐
│ 중3A반 · 수학    [2회▼] 12/9~12/11     │
└─────────────────────────────────────────┘
높이: 약 48px (-89px, 65% 감소)
```

**변경사항**:
- 세그먼트 → 드롭다운 Pill로 변경
- 모든 정보 한 줄에
- 가장 컴팩트하지만 1탭 원칙 위반

## 4. 토스 스타일 분석

### 4.1 토스 앱의 기간 선택 패턴

**토스 거래내역 화면**:
```
┌─────────────────────────────────────┐
│ [12월 ▼]              [검색] [필터] │
└─────────────────────────────────────┘
```
- 드롭다운 사용 (컴팩트 우선)
- 한 줄에 여러 컨트롤

**토스 증권**:
```
┌─────────────────────────────────────┐
│ [1일] [1주] [1개월] [3개월] [1년]   │
└─────────────────────────────────────┘
```
- 세그먼트 사용
- 별도 행이지만 라벨 없음

### 4.2 핵심 발견

> **토스는 라벨을 거의 사용하지 않는다**
> - 컨트롤 자체가 의미를 전달
> - "기간:", "날짜:" 같은 라벨 불필요

## 5. 권장 방안: A안 (라벨 제거 + 인라인)

### 5.1 최종 디자인

```
┌─────────────────────────────────────────┐
│ 중3A반                                  │
│ 수학 · 월/수/금 17:00         [기록 →]  │
├─────────────────────────────────────────┤
│ [2회][3회][5회][월간]      12/9~12/11  │
└─────────────────────────────────────────┘
```

### 5.2 높이 비교

| 버전 | 높이 | 절감 |
|------|------|------|
| 현재 | 137px | - |
| **A안** | **88px** | **-36%** |
| B안 | 96px | -30% |
| C안 | 48px | -65% |

### 5.3 세부 스펙

```css
/* 반 정보 + 기간 통합 카드 */
.class-header-card {
  padding: 12px 16px;        /* py-3 px-4 (기존 p-4) */
}

/* 세그먼트 컨트롤 */
.segment-control {
  height: 32px;              /* 기존 36px → 32px */
  font-size: 13px;
}

/* 날짜 범위 (인라인) */
.date-range {
  font-size: 12px;
  color: #8B95A1;
  margin-left: auto;         /* 우측 정렬 */
}
```

### 5.4 레이아웃 코드

```html
<!-- 기간 선택 행 -->
<div class="flex items-center justify-between py-3 px-4 bg-[#FAFBFC]">
  <!-- 세그먼트 -->
  <div class="segment-control flex">
    <button class="active">2회</button>
    <button>3회</button>
    <button>5회</button>
    <button>월간</button>
  </div>

  <!-- 날짜 범위 (인라인) -->
  <span class="text-xs text-[#8B95A1]">12/9~12/11</span>
</div>
```

## 8. 결론

### 핵심 변경사항

1. **"기간" 라벨 삭제** → -28px
2. **날짜 범위 인라인 배치** → -16px
3. **패딩 최적화** → -8px
4. **세그먼트 높이 축소** → -4px

### 총 절감: **약 40px (29% 감소)**

### 원칙

> **"라벨이 필요하면 디자인이 잘못된 것"**
> - 좋은 UI는 라벨 없이도 의미 전달
> - 세그먼트 자체가 "기간 선택"임을 암시
