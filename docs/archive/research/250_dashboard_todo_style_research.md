# 대시보드 To-Do 스타일 공지 & 디자인 재연구

> 연구 목적: 선생님 대시보드의 공지사항을 체크 가능한 To-Do 스타일로 변경하고, 전체 디자인 개선

---

## 1. 사용자 피드백 요약

| 기존 문제 | 개선 방향 |
|-----------|-----------|
| 긴급공지 노출 | 카톡으로 하므로 불필요 |
| 공지 그냥 보여주기 | **체크하고 넘기는** To-Do 스타일 |
| 기록페이지 진입 | **학생 선택 시 바로 연결** |
| 대시보드 디자인 | 전면 재연구 필요 |

---

## 2. To-Do 스타일 공지 카드 패턴

### 2.1 체크 + 넘기기 패턴 유형

#### A. Gmail 스와이프 패턴
```
┌─────────────────────────────────────┐
│ ← 스와이프 →                        │
│  ✓ 김민수(중3A) 결석 - 병원          │
│    오늘 3:00pm | 학부모 연락완료      │
└─────────────────────────────────────┘
         ↓ 스와이프 시
    [✓ 완료] 또는 [나중에]
```
- **장점**: 빠른 처리, 한 손 조작
- **단점**: 실수로 넘길 수 있음

#### B. 체크박스 + 완료 애니메이션
```
┌─────────────────────────────────────┐
│ ○ 김민수(중3A) 결석 - 병원           │
│   오늘 3:00pm                       │
│   [학부모 연락] [확인 완료]          │
└─────────────────────────────────────┘
         ↓ 체크 시
┌─────────────────────────────────────┐
│ ✓ 김민수(중3A) 결석                  │  ← 축소 + 흐리게
└─────────────────────────────────────┘
```
- **장점**: 명확한 피드백, 실수 방지
- **단점**: 탭 필요 (스와이프보다 느림)

#### C. 드래그 앤 드롭 (Trello 스타일)
```
[ 오늘 공지 ]          [ 확인 완료 ]
┌──────────┐          ┌──────────┐
│ 김민수    │  ──→     │ 이지훈    │
│ 결석     │          │ 조퇴     │
└──────────┘          └──────────┘
```
- **장점**: 시각적 만족감
- **단점**: 모바일에서 복잡

### 2.2 권장 패턴: **체크박스 + 스와이프 병행**

> 토스 철학: "가장 자연스러운 방식으로"

```
┌─────────────────────────────────────┐
│ ○                                   │
│   김민수(중3A) 결석 - 병원           │
│   3:00pm · 학부모 연락 필요          │
│                          [연락하기] │
└─────────────────────────────────────┘
```
- **왼쪽 ○ 탭**: 확인 완료 (체크 표시 후 사라짐)
- **왼쪽 스와이프**: 바로 완료
- **오른쪽 스와이프**: 나중에 (하단으로 이동)
- **[연락하기]**: 바로 전화 연결

**완료 시 피드백:**
- 체크 애니메이션 (○ → ✓)
- 카드 축소 후 fade-out
- "N건 확인 완료" 스낵바

## 3. 대시보드 디자인 원칙 재정립

### 3.1 Glanceable Design (한눈에 파악)

> "5초 안에 오늘 할 일을 파악할 수 있어야 한다"

**핵심 원칙:**
1. **5-6개 카드 이하** (한 화면)
2. **좌측 상단 = 가장 중요** (시선 흐름)
3. **숫자 > 텍스트** (인지 속도)
4. **색상으로 상태 표현** (빨강=주의, 초록=정상)

### 3.2 토스 홈화면 구조 분석

```
┌─────────────────────────────────────┐
│  토스뱅크                    [알림] │  ← 헤더 (최소화)
├─────────────────────────────────────┤
│                                     │
│    잔액   3,456,789원               │  ← Hero 섹션 (핵심 지표)
│                                     │
├─────────────────────────────────────┤
│  [송금] [카드] [ATM] [더보기]       │  ← Quick Actions
├─────────────────────────────────────┤
│  ▸ 이번 달 소비 152만원             │  ← 카드 섹션들
│  ▸ 다가오는 결제 3건                │
│  ▸ 추천                            │
└─────────────────────────────────────┘
```

**학원 선생님 대시보드에 적용:**
- Hero 섹션 → **오늘의 핵심 숫자** (수업 3개, 학생 20명)
- Quick Actions → **자주 쓰는 기능** (기록, 출결, 연락)
- 카드 섹션 → **확인할 공지** (To-Do 스타일)

### 3.3 정보 우선순위 재배치

**기존 (문제점):**
```
1. 긴급 공지 (→ 카톡으로 이미 알고 있음)
2. 학생 현황 (→ 굳이 매번 볼 필요 없음)
3. 기록 현황 (→ 프로그레스바만으론 액션 불가)
```

**개선안:**
```
1. Hero: 오늘의 핵심 (수업 N개, 기록 N개 남음)
2. To-Do: 확인할 공지 (체크 가능)
3. Quick Action: 다음 액션 (기록하기, 학생 보기)
```

## 4. 기록페이지 ↔ 학생 연결

### 4.1 현재 흐름 (복잡)
```
홈 → 기록 탭 → 날짜 선택 → 수업 선택 → 학생 선택 → 기록 입력
```

### 4.2 개선 흐름 (학생 중심)
```
홈 → 학생 탭 → 학생 선택 → 바로 기록 입력 가능
```

**학생 상세 페이지 구조:**
```
┌─────────────────────────────────────┐
│ ← 김민수                     [···] │
├─────────────────────────────────────┤
│  중3A반 · 고려중 3학년              │
│  📊 85점 (↗+7)  📅 출석률 95%      │
├─────────────────────────────────────┤
│  [진도 기록] [출결 체크] [메모 추가] │  ← 바로 기록 가능!
├─────────────────────────────────────┤
│  ▾ 최근 기록                        │
│    12/10 진도 p.45 | 이차방정식     │
│    12/9  출결 출석                  │
├─────────────────────────────────────┤
│  ▾ 특이사항                         │
│    시험 전 불안해함, 격려 필요       │
└─────────────────────────────────────┘
```

## 5. 새로운 대시보드 디자인 제안

### Option A: 숫자 중심 (Glanceable)

```
┌─────────────────────────────────────┐
│  혜윰학원                    🔔 [≡] │
├─────────────────────────────────────┤
│                                     │
│         오늘 수업                   │
│           3개                       │
│                                     │
│    ┌─────┐  ┌─────┐  ┌─────┐       │
│    │ 20  │  │  2  │  │  5  │       │
│    │학생 │  │결석 │  │미기록│       │
│    └─────┘  └─────┘  └─────┘       │
├─────────────────────────────────────┤
│  확인할 공지 (2)                    │
│  ○ 김민수 결석 - 병원        3:00pm │
│  ○ 내일 중3A 시험일정        어제   │
├─────────────────────────────────────┤
│  [📝 기록하기]  [👥 학생 보기]      │
└─────────────────────────────────────┘
```

**특징:**
- 숫자가 크고 명확
- 공지는 To-Do 스타일
- 하단 액션 버튼

### Option B: 카드 중심 (토스 스타일)

```
┌─────────────────────────────────────┐
│  오늘 12월 10일 화요일       🔔 [≡] │
├─────────────────────────────────────┤
│  ┌─────────────────────────────────┐│
│  │  📚 오늘 수업 3개               ││
│  │  중3A 4:00pm · 중2B 6:00pm...   ││
│  │                    [수업 보기 →]││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │  ✓ 확인할 공지                  ││
│  │  ○ 김민수 결석          [연락] ││
│  │  ○ 중3A 시험일정        [확인] ││
│  │                     2건 더보기  ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │  📝 기록 현황                   ││
│  │  ████████░░ 8/10 완료           ││
│  │                    [기록하기 →] ││
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

**특징:**
- 카드로 그룹화
- 각 카드에 액션 버튼
- 프로그레스 시각화

### Option C: 액션 중심 (선생님 워크플로우)

```
┌─────────────────────────────────────┐
│  혜윰학원                    🔔 [≡] │
├─────────────────────────────────────┤
│  안녕하세요, 김선생님               │
│  오늘 확인할 것이 2건 있어요        │
├─────────────────────────────────────┤
│  ┌─────────────────────────────────┐│
│  │ ○ 김민수(중3A) 결석             ││
│  │   병원 · 학부모 연락 필요        ││
│  │   [📞 연락하기] [✓ 확인]        ││
│  └─────────────────────────────────┘│
│  ┌─────────────────────────────────┐│
│  │ ○ 중3A 내일 학교 시험           ││
│  │   수학 범위: 이차방정식          ││
│  │   [📋 진도 확인] [✓ 확인]       ││
│  └─────────────────────────────────┘│
├─────────────────────────────────────┤
│  오늘 수업                          │
│  ┌─────┐ ┌─────┐ ┌─────┐          │
│  │중3A │ │중2B │ │고1A │          │
│  │4:00 │ │6:00 │ │8:00 │          │
│  └─────┘ └─────┘ └─────┘          │
└─────────────────────────────────────┘
```

**특징:**
- 자연어로 상황 설명
- 공지에 바로 액션 버튼
- 수업은 간결하게

## 6. 권장 디자인: Option C (액션 중심)

### 선택 이유

| 기준 | A (숫자) | B (카드) | C (액션) |
|------|---------|---------|---------|
| 글랜스 가능 | ◎ | ○ | ○ |
| 바로 액션 | △ | ○ | ◎ |
| 정보 과부하 | ○ | △ | ◎ |
| 토스 철학 | ○ | ◎ | ◎ |
| 선생님 워크플로우 | △ | ○ | ◎ |

### 토스 철학 적용

1. **Value First**: "확인할 것이 2건 있어요" (가치 먼저)
2. **1 thing / 1 page**: 대시보드 = 확인 + 다음 액션
3. **Minimum Features**: 꼭 필요한 정보만
4. **Casual Concept**: 자연어로 안내

## 7. To-Do 완료 인터랙션 상세

### 7.1 체크 시 애니메이션
```
Step 1: ○ 탭
Step 2: ○ → ● (채워짐, 0.2s)
Step 3: ● → ✓ (체크 표시, 0.1s)
Step 4: 카드 높이 축소 (0.3s)
Step 5: 카드 fade-out (0.2s)
Step 6: 아래 카드 위로 슬라이드 (0.2s)
```

### 7.2 완료 피드백
```
┌─────────────────────────────────────┐
│                                     │
│   [✓ 1건 확인 완료]      [되돌리기] │
│                                     │
└─────────────────────────────────────┘
```
- 하단 스낵바 (3초 후 자동 사라짐)
- 되돌리기 가능

### 7.3 모두 완료 시
```
┌─────────────────────────────────────┐
│                                     │
│         ✓ 모두 확인했어요!          │
│                                     │
│   오늘 수업 준비가 끝났네요 👍      │
│                                     │
└─────────────────────────────────────┘
```

## 8. 결론

### 핵심 변경사항

1. **공지 → To-Do 스타일**
   - 체크박스 + 스와이프 병행
   - 액션 버튼 포함 (연락하기, 확인)
   - 완료 애니메이션

2. **기록 → 학생 연결**
   - 학생 선택 → 바로 기록 가능
   - 기록 탭 대신 학생 상세에서 처리

3. **대시보드 재설계**
   - Option C (액션 중심) 권장
   - 자연어 안내 + 큰 액션 버튼
   - 수업은 작은 카드로 간결하게
