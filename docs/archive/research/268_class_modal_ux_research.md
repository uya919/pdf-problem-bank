# 반별 출결/숙제 모달 UX 연구

> 작성일: 2025-12-11
> 목표: 토스 스타일 UI/UX 철학에 맞는 반별 모달 설계

---

## 1. 현재 플로우 vs 개선 플로우

### 현재 (단순 체크)
```
[출결 2] 탭 → 드롭박스 → [체크] 탭 → 바로 완료 ✓
[숙제 2] 탭 → 드롭박스 → [확인] 탭 → 바로 완료 ✓
```
**문제점**: 실제로 학생별 체크를 안 함

### 개선 (모달 추가)
```
[출결 2] 탭 → 드롭박스 → [체크] 탭 → 출결 모달 → 학생별 체크 → 완료
[숙제 2] 탭 → 드롭박스 → [확인] 탭 → 숙제 모달 → 학생별 확인 → 완료
```
**장점**: 실제 업무 처리 가능

## 2. 토스 UX 원칙 적용

### 2.1 Progressive Disclosure (점진적 공개)

```
Level 1: [출결 2]              ← 숫자만 (요약)
Level 2: 드롭박스              ← 반 목록
Level 3: 모달                  ← 학생 목록
```

**핵심**: 필요할 때만 상세 정보 표시

### 2.2 즉각적 피드백

| 액션 | 피드백 |
|------|--------|
| 학생 체크 | 즉시 체크 표시 + 카운트 업데이트 |
| 전체 완료 | 완료 애니메이션 + 자동 닫힘 |
| 저장 | "저장 완료" 토스트 |

### 2.3 행동 유도 (Call to Action)

- **주요 버튼**: 눈에 띄는 색상
- **완료 조건**: 명확히 표시 ("3/8명 체크")
- **진행률**: 시각적 표시

### 2.4 원탭 완료

- 복잡한 단계 최소화
- 빠른 일괄 처리 옵션 제공

## 3. 출결 모달 설계

### 3.1 구조

```
┌─────────────────────────────────────────────┐
│ ← 중1C반 출결                        [저장] │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │ 15:00-17:00 | 6명                       │ │
│ │ ━━━━━━━━━━━━━━━━━━━━━━━━━━ 100%         │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ ┌─ 일괄 처리 ─────────────────────────────┐ │
│ │ [전체 출석] [전체 결석] [초기화]        │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ ┌─ 학생 목록 ─────────────────────────────┐ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 김민수                    [출석 ✓]  │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 이영희                    [출석 ✓]  │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 박철수                    [결석]    │ │ │
│ │ │   └ 사유: _______________           │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 최지원                    [지각]    │ │ │
│ │ │   └ 10분 지각                       │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │        [완료] (6/6명 체크됨)            │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 3.2 출결 상태 옵션

| 상태 | 색상 | 아이콘 |
|------|------|--------|
| 출석 | 초록 `#E8F5E9` | ✓ |
| 결석 | 빨강 `#FFEBEE` | ✕ |
| 지각 | 주황 `#FFF3E0` | ⏰ |
| 조퇴 | 파랑 `#E3F2FD` | ← |

### 3.3 인터랙션

```
학생 카드 탭
    ↓
┌──────────────────────┐
│  [출석]  [결석]      │  ← 상태 선택 버튼
│  [지각]  [조퇴]      │
└──────────────────────┘
    ↓
결석/지각/조퇴 선택 시 → 사유 입력 필드 표시
```

### 3.4 일괄 처리 기능

- **전체 출석**: 모든 학생 출석 처리 (가장 많이 사용)
- **전체 결석**: 휴강 등 특수 상황
- **초기화**: 다시 체크

## 4. 숙제 모달 설계

### 4.1 구조

```
┌─────────────────────────────────────────────┐
│ ← 중3A반 숙제 확인                   [저장] │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │ p.46-48 | 제출 5명 · 미제출 2명         │ │
│ │ ━━━━━━━━━━━━━━━━━━━━━━━━━━ 71%          │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ ┌─ 필터 ──────────────────────────────────┐ │
│ │ [전체 7] [제출 5] [미제출 2]            │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ ┌─ 학생 목록 ─────────────────────────────┐ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 김민수                   [제출 ✓]   │ │ │
│ │ │ └ 점수: ⭐⭐⭐⭐⭐              │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 이영희                   [제출 ✓]   │ │ │
│ │ │ └ 점수: ⭐⭐⭐⭐☆              │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ │ ┌─────────────────────────────────────┐ │ │
│ │ │ 박철수                   [미제출]   │ │ │
│ │ │   └ 미제출 사유 입력...             │ │ │
│ │ └─────────────────────────────────────┘ │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │        [확인 완료] (7/7명 확인됨)       │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 4.2 숙제 상태 옵션

| 상태 | 색상 | 의미 |
|------|------|------|
| 제출 | 초록 | 숙제 제출함 |
| 미제출 | 빨강 | 숙제 안 함 |
| 일부 제출 | 주황 | 일부만 함 |

### 4.3 점수/피드백 옵션

**간단 버전 (별점)**
```
⭐⭐⭐⭐⭐  (5점 만점)
```

**상세 버전 (선택적)**
```
정답률: 80% (8/10)
코멘트: "계산 실수 주의"
```

### 4.4 미제출 학생 처리

```
┌─────────────────────────────────────────┐
│ 박철수                       [미제출]   │
│                                         │
│ 미제출 사유:                            │
│ ○ 깜빡함                               │
│ ○ 시간 부족                            │
│ ○ 어려워서 못함                        │
│ ○ 기타: _______________                │
│                                         │
│ [학부모 알림 보내기]                    │
└─────────────────────────────────────────┘
```

## 5. 공통 UX 패턴

### 5.1 모달 열기/닫기

**열기 애니메이션**: 바텀시트 슬라이드업
```css
@keyframes slideUp {
  from { transform: translateY(100%); }
  to { transform: translateY(0); }
}
```

**닫기**:
- 배경 탭
- X 버튼
- 스와이프 다운

### 5.2 저장 플로우

```
[저장] 탭
    ↓
로딩 스피너 (0.5초)
    ↓
"저장 완료" 토스트
    ↓
모달 자동 닫힘
    ↓
뱃지 숫자 감소 애니메이션
```

### 5.3 진행률 표시

```
━━━━━━━━━━━━━━━━━━━━━━━━━━ 100%  ← 초록
━━━━━━━━━━━━━━━━━━━━━━━━━━  71%  ← 주황 (완료 안 됨)
━━━━━━━━━━━━━━━━━━━━━━━━━━   0%  ← 빨강
```

### 5.4 카드 상태

```tsx
// 미처리
<Card className="border-l-4 border-l-gray-300">

// 처리 완료
<Card className="border-l-4 border-l-green-500 bg-green-50">

// 문제 있음 (결석, 미제출)
<Card className="border-l-4 border-l-red-500 bg-red-50">
```

## 8. UX 비교: 간단 vs 상세

### Option A: 간단 모달 (권장)

| 항목 | 설명 |
|------|------|
| 출결 | 학생 탭 → 출석/결석만 토글 |
| 숙제 | 학생 탭 → 제출/미제출만 토글 |
| 장점 | 빠름, 간단 |
| 단점 | 상세 정보 없음 |

**적합**: 빠른 처리가 중요할 때

### Option B: 상세 모달

| 항목 | 설명 |
|------|------|
| 출결 | 출석/결석/지각/조퇴 + 사유 |
| 숙제 | 제출/미제출 + 점수 + 코멘트 |
| 장점 | 상세 기록 가능 |
| 단점 | 입력 시간 오래 걸림 |

**적합**: 정확한 기록이 중요할 때

### 권장: 하이브리드

```
기본: 간단 모드 (탭으로 토글)
선택: [상세 입력] 버튼으로 확장
```

## 9. 목업 계획

### 필요한 화면

1. **출결 모달 - 기본**
   - 학생 목록
   - 출석/결석 토글

2. **출결 모달 - 결석 선택**
   - 사유 입력 필드

3. **숙제 모달 - 기본**
   - 학생 목록
   - 제출/미제출 토글

4. **숙제 모달 - 점수 입력**
   - 별점 선택

5. **완료 상태**
   - 저장 완료 피드백

## 10. 결론

### 권장 설계

| 모달 | 기본 모드 | 확장 모드 |
|------|----------|----------|
| 출결 | 출석/결석 토글 | 지각/조퇴 + 사유 |
| 숙제 | 제출/미제출 토글 | 점수 + 코멘트 |

### 핵심 UX 원칙

1. **빠른 처리**: 탭 한 번으로 토글
2. **일괄 처리**: [전체 출석] 버튼
3. **진행률 표시**: "6/6명 체크됨"
4. **즉각적 피드백**: 체크 시 색상 변화
5. **선택적 상세**: 필요할 때만 확장
