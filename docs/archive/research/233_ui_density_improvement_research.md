## 2. 구현 가능성 분석

### 2.1 해설 연결 뱃지

**난이도**: ⭐⭐ 쉬움 (30분)

**현재 데이터 흐름**:
```
useProblemsByBook() → problems[] → TossProblemCard
```

**필요한 작업**:
1. `useProblemsByBook`에서 해설 연결 정보 추가 조회
2. `TossProblemCard`에 `hasLinkedSolution` prop 추가
3. 카드에 작은 뱃지 표시

**구현 방법**:
```tsx
// TossProblemCard.tsx
{hasLinkedSolution && (
  <div className="absolute top-1 right-1 w-4 h-4 bg-purple-500 rounded-full
                  flex items-center justify-center">
    <BookOpen className="w-2.5 h-2.5 text-white" />
  </div>
)}
```

**우려 사항**:
- ⚠️ 추가 API 호출 필요 (`useLinkedSolutions`)
- 해결: 이미 `useLinkedSolutions` 훅 존재, 병합만 하면 됨

---

### 2.2 카드 크기 축소

**난이도**: ⭐ 매우 쉬움 (15분)

**현재**:
```tsx
// TossProblemCard.tsx
<div className="aspect-[4/5] ...">  // 세로가 긴 비율
  <div className="p-3">             // 패딩 넓음
    <span className="text-sm">      // 텍스트 큼
```

**개선**:
```tsx
<div className="aspect-square ...">  // 정사각형
  <div className="p-2">              // 패딩 축소
    <span className="text-xs">       // 텍스트 작게
```

**우려 사항**:
- ⚠️ 썸네일 이미지가 작아져 식별 어려울 수 있음
- 해결: 호버 시 확대 효과 추가

---

### 2.3 좌우 여백 축소 (PC 버전)

**난이도**: ⭐ 매우 쉬움 (5분)

**현재**:
```tsx
<div className="max-w-2xl mx-auto px-4">  // 최대 672px
```

**개선**:
```tsx
<div className="max-w-2xl md:max-w-4xl lg:max-w-6xl mx-auto px-4">
// 모바일: 672px, 태블릿: 896px, PC: 1152px
```

**추가로 열 수도 조정**:
```tsx
// CollapsibleGrid.tsx
<div className="grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-6 xl:grid-cols-8">
```

**우려 사항**:
- ⚠️ 카드가 너무 작아질 수 있음
- 해결: 카드 최소 너비 설정 (`min-w-[100px]`)

---

### 2.4 "더 보기" 버튼 오른쪽 배치

**난이도**: ⭐⭐⭐ 중간 (45분)

**현재 구조**:
```
┌──────────────────────────────────────────┐
│ [카드] [카드] [카드] [카드]               │
│                                          │
│           [+8개 더 보기]                  │  ← 아래 한 줄 차지
└──────────────────────────────────────────┘
```

**목표 구조 (Option A: 마지막 카드 옆)**:
```
┌──────────────────────────────────────────┐
│ [카드] [카드] [카드] [카드] [+8개]        │  ← 인라인
└──────────────────────────────────────────┘
```

**목표 구조 (Option B: 헤더 오른쪽)**:
```
┌──────────────────────────────────────────┐
│ ─── 8페이지 (12개) ───────── [+8개 더보기]│
│ [카드] [카드] [카드] [카드]               │
└──────────────────────────────────────────┘
```

**Option A 구현**:
```tsx
// CollapsibleGrid.tsx
<div className="grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-6">
  {visibleItems}

  {/* 더 보기 버튼을 그리드 아이템으로 */}
  {hasMore && !isExpanded && (
    <button className="aspect-square bg-grey-50 rounded-xl
                       flex items-center justify-center text-grey-500">
      +{hiddenCount}
    </button>
  )}
</div>
```

**Option B 구현**:
```tsx
// ProblemsInBook.tsx - 페이지 헤더에 버튼 추가
<div className="flex items-center gap-3 mb-4">
  <div className="h-px flex-1 bg-grey-200" />
  <span>{page}페이지</span>
  <span>({count}개)</span>
  {hiddenCount > 0 && (
    <button onClick={expand}>+{hiddenCount}</button>
  )}
  <div className="h-px flex-1 bg-grey-200" />
</div>
```

**우려 사항**:
- ⚠️ Option A: 카드와 버튼의 시각적 불일치
- ⚠️ Option B: CollapsibleGrid의 상태를 외부에서 제어해야 함
- 해결: Option A 권장 (그리드 내 통합이 더 자연스러움)
