# 수업 페이지 기간별 뷰 UX 연구 리포트

> 작성일: 2025-12-11

## 1. 현재 vs 제안 비교

| 항목 | 현재 (v2) | 제안 (v3) |
|------|-----------|-----------|
| 출석률 | 월별 출석률 (%) | **삭제** → 기간별 결석자 명단 |
| 진도 | 가장 최근 1회 수업 | **기간별** 수업 기록 타임라인 |
| 시험 | Daily/Weekly/Monthly 탭 | **기간별** 시험 결과 |
| 학생 | 섹션 중간 | **최하단** 고정 |
| 기본값 | - | **최근 2회 수업** |
| UI | 드롭다운 | **세그먼트 컨트롤** (1탭 = 1액션) |

## 2. 핵심 UX 원칙 적용

### 2.1 토스 철학: "맥락 중심의 정보"

**문제**: 출석률 "94%"는 의미가 불분명
- 언제부터 94%?
- 누가 결석했는지 모름
- 액션 불가능한 정보

**해결**: 기간 기반 결석자 명단
```
12/9 (월)  박선유 결석 (병원)
12/11 (수) 이사랑, 박성빈 결석
```
- 즉시 누구인지 파악
- 바로 연락 가능 (액션 가능)
- 맥락이 명확함

### 2.2 Progressive Disclosure 강화

**정보 우선순위 재설계**:
1. **기간 선택** (최상단) - 사용자가 먼저 범위 설정
2. **결석자** - 가장 긴급한 정보
3. **진도** - 수업 내용 타임라인
4. **시험** - 평가 결과
5. **학생** (최하단) - 참조용 정보

### 2.3 "최근 2회 수업"의 의미

**왜 2회인가?**
- 가장 최근 + 바로 전 수업 비교
- 정보량 최소화 → 집중도 향상
- 필요시 3회/5회로 확장 가능
- 토스 원칙: "적을수록 좋다"

## 3. 정보 구조 설계

### 3.1 기간 선택 UI (세그먼트 컨트롤)

```
┌─────────────────────────────────────────┐
│ 기간                                     │
│ ┌─────┬─────┬─────┬──────┐             │
│ │ 2회 │ 3회 │ 5회 │ 월간 │             │
│ │ ●●● │     │     │      │             │
│ └─────┴─────┴─────┴──────┘             │
│                    12/9 (월) ~ 12/11 (수) │
└─────────────────────────────────────────┘
```

**설계 의도**:
- **1탭 = 1액션** (드롭다운은 2탭 필요)
- 4개 옵션이 한눈에 보임
- "월간" 선택 시 캘린더 바텀시트 열림
- iOS/Android 네이티브 패턴 (익숙함)

> 상세 비교: [276_period_selector_ui_research.md](276_period_selector_ui_research.md)

### 3.2 결석자 섹션

```
┌─────────────────────────────────────┐
│ 🚨 결석                     총 3명  │
├─────────────────────────────────────┤
│ 12/11 (수)                          │
│   이사랑  [연락하기]               │
│   박성빈  (무단) [연락하기]         │
│                                     │
│ 12/9 (월)                           │
│   박선유  (병원) [연락하기]         │
└─────────────────────────────────────┘
```

**핵심 요소**:
- 날짜별 그룹핑 (최신순)
- 결석 사유 표시
- 즉각적인 액션 버튼 ("연락하기")
- 전체가 출석이면: "👏 전원 출석!" 메시지

### 3.3 진도 타임라인

```
┌─────────────────────────────────────┐
│ 📖 진도                    3회 수업  │
├─────────────────────────────────────┤
│ ● 12/11 (수) - 오늘                 │
│   3단원. 이차방정식 응용            │
│   베이직쎈 p.46-50                  │
│   숙제: p.51-53 (8문제)             │
│   ─────────────────────────────────│
│ ● 12/9 (월)                         │
│   3단원. 이차방정식 풀이            │
│   베이직쎈 p.42-45                  │
│   숙제: p.46-48 ✓ 완료 (6/8)        │
│   ─────────────────────────────────│
│ ○ 12/5 (목)                         │
│   2단원. 복습                       │
│   베이직쎈 p.38-41                  │
│   숙제: p.42 ✓ 완료 (7/8)           │
└─────────────────────────────────────┘
```

**설계 의도**:
- 타임라인 형태로 진행 흐름 시각화
- ● 최근 / ○ 과거 구분
- 숙제 완료 상태 즉시 확인
- 단원 변경 시 구분선 강조

### 3.4 시험 섹션

```
┌─────────────────────────────────────┐
│ 📝 시험                    2회 시험  │
├─────────────────────────────────────┤
│ 12/11 (수) Daily Test               │
│   범위: 이차방정식 p.42-50          │
│   ┌─────────────────────────────┐  │
│   │ 평균 82  최고 95  최저 68   │  │
│   │ ■■■■■■□□□□ (상6 중1 하1)   │  │
│   └─────────────────────────────┘  │
│   [상세보기]                        │
│   ─────────────────────────────────│
│ 12/5 (목) Weekly Test               │
│   범위: 2단원 전체                  │
│   평균 78점 | 최고 92 | 최저 55     │
│   [상세보기]                        │
└─────────────────────────────────────┘
```

**설계 의도**:
- 날짜순 나열 (타임라인과 일관성)
- 시험 유형 (Daily/Weekly/Monthly) 뱃지 표시
- 요약 통계 + 분포 바
- 상세 보기로 학생별 점수 확인

### 3.5 학생 섹션 (최하단)

```
┌─────────────────────────────────────┐
│ 👥 학생                        8명  │
├─────────────────────────────────────┤
│ ┌───────┐ ┌───────┐ ┌───────┐      │
│ │ 김민수 │ │ 이영희 │ │ 박철수 │ ... │
│ │  중3   │ │  중3   │ │  중3   │      │
│ └───────┘ └───────┘ └───────┘      │
│           [전체보기 →]              │
└─────────────────────────────────────┘
```

**최하단 배치 이유**:
- 학생 목록은 "참조" 정보
- 매번 확인할 필요 없음
- 필요 시에만 펼쳐서 확인
- 기본 접힘 상태 권장

## 4. 인터랙션 설계

### 4.1 기간 변경 시

```

        ↓
[로딩 스피너] (0.3초)
        ↓
전체 섹션 데이터 업데이트
```

```typescript
  id: string;
  date: string;           // "2024-12-11"
  classId: string;
  className: string;

  // 출결
  attendance: {
    present: string[];    // 출석 학생 ID

      studentId: string;
      studentName: string;
      reason?: string;    // "병원", "무단" 등

  };

  // 진도

    chapter: string;
    textbook: string;
    pages: string;

  };
}
```

## 6. 섹션 순서 최종 결정

```
1. 기간 선택 바 (고정)
2. 반 정보 헤더
3. 🚨 결석 섹션 (가장 긴급)
4. 📖 진도 섹션 (핵심 정보)
5. 📝 시험 섹션 (평가 정보)
6. 👥 학생 섹션 (참조용, 최하단)
```

**원칙**:
- 긴급도 순서 (결석 > 진도 > 시험 > 학생)
- 액션 가능성 순서
- Progressive Disclosure

## 10. 결론

### 핵심 개선점

1. **출석률 삭제 → 결석자 명단**
   - 추상적 수치 → 구체적 정보
   - 확인만 → 즉시 액션

2. **기간 기반 뷰**
   - "최근 2회"가 기본값 (집중!)
   - 세그먼트 컨트롤로 1탭 변경

3. **타임라인 진도**
   - 시간순 흐름 시각화
   - 연속성 파악 용이

4. **학생 최하단**
   - 참조 정보는 뒤로
   - 긴급 정보 우선
