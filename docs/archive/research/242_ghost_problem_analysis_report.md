## 3. 원인 분석

### 문제 발생 흐름

```
12:53 - 세트 1 그룹 생성 및 확정 (export)
        → problems/*.png, *.json 파일 생성

?????  - 사용자가 세트 1 그룹 삭제
        → groups.json에서 그룹 제거됨
        → problems/*.png, *.json 파일은 삭제되지 않음 ❌

15:51 - 세트 2 그룹 생성 및 확정 (export)
        → 새로운 problems/*.png, *.json 파일 생성
        → 해설 연결

현재  - 문제은행 API가 problems 폴더 스캔
        → 세트 1 + 세트 2 모두 반환 (중복!)
```

### 근본 원인

**그룹 삭제 시 export 파일이 함께 삭제되지 않음**

현재 시스템:
- 그룹 삭제 → `groups.json`에서만 제거
- `problems/*.png`, `problems/*.json` 파일은 그대로 유지
