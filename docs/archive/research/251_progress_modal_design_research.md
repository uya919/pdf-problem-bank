## 1. 기존 hyeyum 기능 분석

### 1.1 출결 체크 (AttendanceGrid)

| 조퇴 | ← | 일찍 퇴실 |

**대량 처리 버튼:**
- 전체 출석
- 전체 결석

```
└─────────────────────────────────────┘
```

### 1.2 진도 기록 (ProgressFormDialog)

**입력 항목:**
| 필드 | 필수 | 예시 |
|------|------|------|
| 날짜 | ✓ | 2024-12-10 |
| 교재 | ✓ | 베이직쎈 |
| 페이지 | ✓ | 42-45 |
| 주제 | - | 이차방정식 풀이 |
| 메모 | - | 응용문제 추가 필요 |

**특징:**
- 자주 쓰는 교재 버튼 (빠른 선택)
- 페이지 직접 입력
- 주제/메모는 선택사항

### 1.3 숙제 기록 (HomeworkFormDialog)

**입력 항목:**
| 필드 | 필수 | 예시 |
|------|------|------|
| 제목 | ✓ | p.46-48 풀이 |
| 설명 | - | 짝수 번호만 |
| 마감일 | ✓ | 2024-12-12 |

**자동 처리:**
- 수강생 전원에게 제출 레코드 자동 생성

## 2. 새로운 UX 철학 적용

### 2.1 토스 철학 재해석

| 원칙 | 기존 hyeyum | 새로운 해석 |
|------|-------------|-------------|
| **1 thing / 1 page** | 진도/숙제 별도 모달 | 하나의 플로우로 통합 |
| **Value First** | 빈 폼부터 시작 | 지난 진도 먼저 보여주기 |
| **Minimum Input** | 5개 필드 | 3개로 축소 (자동화) |
| **Context Aware** | 날짜만 기억 | 지난 진도 → 다음 페이지 자동 제안 |

### 2.2 핵심 인사이트

> **선생님이 진도 기록을 누를 때 필요한 것:**
> 1. "지난번에 어디까지 했지?" → **지난 진도 확인**
> 2. "오늘 어디까지 했지?" → **오늘 진도 입력**
> 3. "숙제를 뭘로 내지?" → **숙제 함께 기록**

### 2.3 플로우 재설계

**기존 플로우:**
```
진도 기록 버튼 → 진도 모달 → 저장 → 닫기
숙제 기록 버튼 → 숙제 모달 → 저장 → 닫기
```

**새로운 플로우:**
```
진도 기록 버튼 → 통합 모달 (지난 진도 + 오늘 진도 + 숙제) → 한 번에 저장
```

## 4. 스마트 자동화 기능

### 4.1 페이지 자동 제안

| 지난 진도 | 자동 제안 | 로직 |
|-----------|-----------|------|
| p.42-45 | p.46~ | 마지막 페이지 + 1 |
| p.100-105 | p.106~ | 마지막 페이지 + 1 |
| 단원 1 | 단원 2 | 다음 단원 제안 |

**구현:**
```javascript
function suggestNextPage(lastPages) {
  const match = lastPages.match(/(\d+)-(\d+)/);
  if (match) {
    const endPage = parseInt(match[2]);
    return `${endPage + 1}-`;
  }
  return '';
}
```

### 4.2 숙제 자동 완성

**진도 입력 시 숙제 자동 제안:**
| 진도 입력 | 숙제 제안 |
|-----------|-----------|
| p.46-48 | p.46-48 풀이 |
| p.46-48, 이차방정식 응용 | 이차방정식 응용 p.46-48 |

**마감일 자동 설정:**
- 기본값: 다음 수업일
- 또는 3일 후

### 4.3 교재 학습

**사용 빈도 기반 정렬:**
1. 최근 사용한 교재
2. 자주 사용한 교재
3. 나머지 교재

## 5. 인터랙션 상세

### 5.1 모달 진입 시

1. **지난 진도 자동 로드**
   - API 호출: `GET /progress?class_id={id}&limit=1&order=desc`
   - 지난 진도 카드에 표시
   - 없으면 "첫 수업입니다" 표시

2. **교재 자동 선택**
   - 지난 진도의 교재가 있으면 자동 선택
   - 없으면 자주 쓰는 교재 중 첫 번째

3. **페이지 힌트**
   - 지난 진도 페이지 표시
   - 다음 페이지 placeholder

### 5.2 저장 시

1. **진도 저장**
   - `POST /progress` (upsert)

2. **숙제 저장** (토글 ON인 경우)
   - `POST /homework`
   - 수강생 자동 할당

3. **피드백**
   - 토스트 메시지: "진도가 저장되었습니다"
   - 숙제도 저장 시: "진도와 숙제가 저장되었습니다"

### 5.3 애니메이션

| 요소 | 애니메이션 |
|------|------------|
| 모달 | slide-up (0.2s) |
| 숙제 섹션 | expand (0.15s) |
| 저장 버튼 | loading spinner |
| 성공 | checkmark + fade |

## 8. 기대 효과

### 8.1 시간 절약

| 작업 | 기존 | 개선 |
|------|------|------|
| 진도 기록 | 5개 필드 입력 | 2개 필드 (자동완성) |
| 숙제 기록 | 별도 모달 | 토글 ON만 |
| 지난 진도 확인 | 별도 페이지 이동 | 모달에서 바로 확인 |

**예상 절약 시간:** 수업당 2-3분

### 8.2 오류 감소

- 교재/페이지 자동 제안 → 입력 오류 감소
- 지난 진도 확인 → 중복 기록 방지
- 숙제 자동 완성 → 누락 방지

### 8.3 사용자 만족도

- 컨텍스트 제공 → 인지 부하 감소
- 원클릭 저장 → 빠른 완료
- 스마트 자동화 → "앱이 알아서 해주는" 느낌
