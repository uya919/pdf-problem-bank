# 기록 페이지 반별 필터링 UX 연구 리포트

> 작성일: 2025-12-12
> 문제: 헤더의 "전체 반" 드롭다운이 UI/UX 철학에 부적합

---

## 1. 현재 구현의 문제점

### 현재 구조
```
┌──────────────────────────────────────┐
│  기록            [전체 반 ▼]         │  ← 헤더
│  ┌────┬────┬────┬────┐              │
│  │출결│진도│숙제│성적│              │  ← 탭
│  └────┴────┴────┴────┘              │
├──────────────────────────────────────┤
│  컨텐츠...                           │
└──────────────────────────────────────┘
```

### 문제점 분석

| 문제 | 설명 |
|------|------|
| **위계 불명확** | 필터가 페이지 레벨인지 탭 레벨인지 모호함 |
| **맥락 부족** | "전체 반"만으로는 무엇을 필터링하는지 불분명 |
| **시각적 약함** | 작은 드롭다운이 헤더 오른쪽에 숨어있음 |
| **탭과 분리** | 필터와 탭이 분리되어 연결성 부족 |
| **토스 철학 위반** | 토스는 "필터보다 구조화된 정보"를 선호 |

---

## 2. 토스/애플 필터링 철학

### 2.1 토스의 접근법: "필터 없이 구조화"

토스 앱은 **범용 필터를 피하고**, 데이터 자체를 구조화합니다:

```
❌ 토스가 하지 않는 것:
┌─────────────────────────┐
│  내 자산   [계좌 선택 ▼] │
└─────────────────────────┘

✅ 토스가 하는 것:
┌─────────────────────────┐
│  내 자산                 │
│  ┌───────────────────┐  │
│  │  토스뱅크  12,340원  │  │
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │  국민은행  5,000원   │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

**핵심 원칙**:
- 필터로 숨기지 말고, 모두 보여주되 **그룹핑**으로 정리
- 사용자가 원하는 것은 "필터링"이 아니라 "원하는 정보 찾기"

### 2.2 애플의 접근법: "컨텍스트 내 필터"

애플은 필터가 필요할 때 **컨텐츠 영역 내에** 배치합니다:

```
Photos 앱:
┌─────────────────────────┐
│  라이브러리              │  ← 헤더 (필터 없음)
│  ┌────────────────────┐ │
│  │ 년 │ 월 │ 일 │ 모두 │ │  ← 컨텐츠 내 세그먼트
│  └────────────────────┘ │
│  [사진들...]            │
└─────────────────────────┘
```

## 3. 기록 페이지 특성 분석

### 3.1 탭별 데이터 특성

| 탭 | 기본 뷰 | 반별 필터 필요성 |
|---|---|---|
| **출결** | 날짜별 → 반별 카드 | 낮음 (이미 반별 그룹화) |
| **진도** | 반별 진도율 나열 | 낮음 (이미 반별 표시) |
| **숙제** | 미제출 학생 리스트 | 중간 (학생이 많을 때) |
| **성적** | 시험별 결과 | 중간 (특정 반만 볼 때) |

### 3.2 사용 시나리오

1. **시나리오 A**: 전체 현황 파악
   - "오늘 출결은 어땠지?" → 전체 보기
   - "이번 주 숙제 제출률은?" → 전체 보기

2. **시나리오 B**: 특정 반 집중
   - "중3A반 성적 추이를 보고 싶어" → 반 필터
   - "중2A반 진도가 어디까지 갔지?" → 반 필터

**인사이트**: 대부분의 경우 전체 현황을 먼저 보고, 필요시 특정 반으로 드릴다운

## 4. 대안 패턴 비교

### 옵션 A: 필터 제거 + 그룹핑 강화 ⭐ 추천

**개념**: 필터 없이 모든 반을 보여주되, 시각적 그룹핑 강화

```
┌──────────────────────────────────────┐
│  기록                                │
│  ┌────┬────┬────┬────┐              │
│  │출결│진도│숙제│성적│              │
│  └────┴────┴────┴────┘              │
├──────────────────────────────────────┤
│  이번 주 출결 현황                    │
│  출석 24  지각 3  결석 1  출석률 89%  │
├──────────────────────────────────────┤
│  ▼ 중3A반  17:00-19:00        7/8명 │  ← 접힘/펼침 가능
│  ▼ 중2A반  18:00-20:00        3/3명 │
│  ▼ 중1A반  19:00-21:00        4/4명 │
└──────────────────────────────────────┘
```

**장점**:
- 한눈에 전체 현황 파악
- 관심 있는 반만 펼쳐서 상세 확인
- 토스 철학과 일치

**단점**:
- 반이 많으면 스크롤 길어짐 (5개 이상)

---

### 옵션 B: 탭 아래 칩 필터

**개념**: 탭 바로 아래에 가로 스크롤 칩으로 반 선택

```
┌──────────────────────────────────────┐
│  기록                                │
│  ┌────┬────┬────┬────┐              │
│  │출결│진도│숙제│성적│              │
│  └────┴────┴────┴────┘              │
│  ┌────┐┌─────┐┌─────┐┌─────┐        │
│  │전체││중3A ││중2A ││중1A │ →      │  ← 칩 필터
│  └────┘└─────┘└─────┘└─────┘        │
├──────────────────────────────────────┤
│  컨텐츠...                           │
└──────────────────────────────────────┘
```

**장점**:
- 필터가 컨텐츠와 가까워 맥락 명확
- 선택된 반이 시각적으로 명확
- 한 번에 여러 반 상태 확인 가능

**단점**:
- 수직 공간 추가 사용
- 탭이 2줄이 되어 복잡해 보일 수 있음

---

### 옵션 C: 탭 내 세그먼트 통합

**개념**: 각 탭 컨텐츠 최상단에 세그먼트 컨트롤 배치

```
┌──────────────────────────────────────┐
│  기록                                │
│  ┌────┬────┬────┬────┐              │
│  │출결│진도│숙제│성적│              │
│  └────┴────┴────┴────┘              │
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │ 전체 │ 중3A │ 중2A │ 중1A      │  │  ← 컨텐츠 내 세그먼트
│  └────────────────────────────────┘  │
│  이번 주 출결 현황                    │
│  ...                                │
└──────────────────────────────────────┘
```

**장점**:
- 필터가 컨텐츠의 일부로 느껴짐
- 애플 Photos 스타일과 유사
- 탭마다 독립적 필터 상태 가능

**단점**:
- 탭 전환 시 필터 상태 유지 여부 결정 필요

---

### 옵션 D: 반 카드 클릭 드릴다운

**개념**: 전체 보기에서 특정 반 카드 클릭 시 상세 모드

```
기본 뷰:
┌──────────────────────────────────────┐
│  중3A반 ●   중2A반 ●   중1A반 ●      │  ← 클릭 가능한 미니 카드
├──────────────────────────────────────┤
│  [전체 반 요약 컨텐츠]               │
└──────────────────────────────────────┘

드릴다운 뷰 (중3A반 클릭 후):
┌──────────────────────────────────────┐
│  ← 전체    중3A반                    │  ← 뒤로가기 추가
├──────────────────────────────────────┤
│  [중3A반 상세 컨텐츠]                │
└──────────────────────────────────────┘
```

**장점**:
- 명확한 전체/상세 모드 분리
- 드릴다운 UX로 직관적

**단점**:
- 탭 + 드릴다운 조합이 복잡해질 수 있음
- 구현 복잡도 증가

## 5. 추천 솔루션

### 1순위: 옵션 A (필터 제거 + 그룹핑 강화)

**이유**:
1. **토스 철학 준수**: 필터보다 구조화된 정보
2. **정보 밀도 증가**: 한눈에 모든 반 현황 파악
3. **사용자 행동 최적화**: 대부분 전체 현황 → 특정 반 순서
4. **구현 단순화**: 필터 상태 관리 불필요

**구현 방향**:
- 각 탭에서 반별 카드/섹션으로 데이터 그룹화
- 접기/펼치기로 상세 정보 토글
- 요약 카드는 전체 데이터 기준으로 표시

### 2순위: 옵션 C (탭 내 세그먼트)

**이유**:
- 반이 5개 이상으로 많아질 경우 그룹핑만으로 부족
- 필터가 필요하다면 컨텐츠 영역 내에 배치

## 6. 탭별 적용 방안 (옵션 A 기준)

### 출결 탭
```
현재: 요약 카드 + 반별 카드
개선: 그대로 유지 (이미 그룹핑됨)
```

### 진도 탭
```
현재: 반별 프로그레스바 + 히스토리
개선: 그대로 유지 (이미 반별 표시)
```

### 숙제 탭
```
현재: 전체 요약 + 미제출 학생 + 히스토리
개선: 반별 제출 현황 카드로 그룹화
┌───────────────────────────────────┐
│ 중3A반  제출 7/8  ●               │
│ ├ 미제출: 박성빈 (3회 연속)        │
├───────────────────────────────────┤
│ 중2A반  제출 3/3  ●               │
│ └ 모두 제출                       │
└───────────────────────────────────┘
```

### 성적 탭
```
현재: 최근 시험 결과 + 경고 학생 + 히스토리
개선: 시험별 카드 내에 반 정보 포함
┌───────────────────────────────────┐
│ 12/11 월간 테스트                  │
│ ├ 중3A반  평균 78점               │
│ └ 중2A반  평균 82점               │
└───────────────────────────────────┘
```

## 7. 결론

| 항목 | 현재 | 개선 |
|------|------|------|
| 필터 위치 | 헤더 드롭다운 | **제거** |
| 데이터 표시 | 필터된 데이터만 | **전체 + 그룹핑** |
| 상세 확인 | 드롭다운 선택 | **접기/펼치기** |
| 사용자 경험 | 필터 → 확인 | **한눈에 확인 → 관심 영역 펼침** |

**최종 권장사항**:
헤더의 "전체 반" 드롭다운을 **제거**하고, 각 탭에서 반별로 **그룹화된 카드**를 보여주는 방식으로 변경. 이는 토스 디자인 철학인 "필터보다 구조화"에 부합하며, 선생님이 한눈에 모든 반의 현황을 파악할 수 있게 합니다.
