# 모든 뱃지 드롭박스 인터랙션 연구

> 작성일: 2025-12-11
> 목표: 공지/출결/진도/숙제 모두 드롭박스로 상세 내용 표시

---

## 1. 컨셉

### 통일된 인터랙션 패턴

```
[뱃지 N] 탭 → 드롭박스 열림 → 항목 탭 → 완료 처리 → 숫자 감소
```

**핵심 원칙:**
- 모든 뱃지가 **동일한 인터랙션** 패턴
- **Progressive Disclosure**: 요약 → 상세
- **즉각적 피드백**: 완료 시 숫자 감소
- **토스 철학**: 간결함 + 행동 유도

## 2. 뱃지별 드롭박스 설계

### 2.1 공지 (🔔)

**뱃지:** `[🔔 공지 2]`

**드롭박스 내용:**
```
┌─────────────────────────────────────────────┐
│ ● 김민수(중3A) 결석 - 병원                   │
│   어머니 연락 필요                           │
│ ● 12/11(수) 전체 회의                       │
│   14:00 강당                                │
└─────────────────────────────────────────────┘
```

**완료 조건:** 탭하면 읽음 처리
**완료 시:** 숫자 감소, 항목 흐리게

---

### 2.2 출결 (✓)

**뱃지:** `[✓ 출결 2]`

**드롭박스 내용:**
```
┌─────────────────────────────────────────────┐
│ ○ 중1C반 (6명)                      [체크]  │
│   15:00-17:00 완료                          │
│ ○ 중2B반 (7명)                      [체크]  │
│   19:00-21:00 예정                          │
└─────────────────────────────────────────────┘
```

**완료 조건:** [체크] 버튼 탭 또는 출결 페이지 이동
**완료 시:** 숫자 감소, 체크 표시

**추가 정보:**
- 반 이름
- 학생 수
- 수업 시간
- 상태 (완료/예정)

---

### 2.3 진도 (📄)

**뱃지:** `[📄 진도 1]`

**드롭박스 내용:**
```
┌─────────────────────────────────────────────┐
│ ○ 중3A반                            [기록]  │
│   17:00-19:00 수업 중                       │
│   최근: 이차방정식 (p.42-45)                 │
└─────────────────────────────────────────────┘
```

**완료 조건:** [기록] 버튼 탭 → 진도 모달 열림 → 저장
**완료 시:** 숫자 감소, 기록 완료 표시

**추가 정보:**
- 반 이름
- 수업 시간
- 최근 진도 (참고용)

---

### 2.4 숙제 (📝)

**뱃지:** `[📝 숙제 5]`

**드롭박스 내용:**
```
┌─────────────────────────────────────────────┐
│ ○ 김민수 (중3A)                     [확인]  │
│   p.46-48 제출함                            │
│ ○ 이영희 (중3A)                     [확인]  │
│   p.46-48 제출함                            │
│ ○ 박철수 (중3A)                     [확인]  │
│   미제출                                    │
│                         + 2명 더보기        │
└─────────────────────────────────────────────┘
```

**완료 조건:** [확인] 버튼 탭
**완료 시:** 숫자 감소, 확인 완료 표시

**추가 정보:**
- 학생 이름 + 반
- 제출 상태
- 미제출 시 빨간색 강조

## 3. 드롭박스 공통 디자인

### 3.1 레이아웃

```
┌─────────────────────────────────────────────┐
│ [뱃지 row - 4개 균등 배치]                   │
├─────────────────────────────────────────────┤
│ [드롭박스 - 선택된 뱃지 아래로 확장]          │
│                                             │
│  ○ 항목 1                          [액션]   │
│    상세 정보                                │
│                                             │
│  ○ 항목 2                          [액션]   │
│    상세 정보                                │
│                                             │
└─────────────────────────────────────────────┘
```

### 3.2 항목 구조

```tsx
interface DropdownItem {
  id: string;
  title: string;        // 주요 정보 (반 이름, 학생 이름)
  subtitle: string;     // 부가 정보 (시간, 상태)
  status: 'pending' | 'done';
  actionLabel: string;  // 버튼 텍스트 (체크, 기록, 확인)
}
```

### 3.3 색상 체계

| 뱃지 | 배경 (미완료) | 배경 (완료) | 점 색상 |
|------|--------------|------------|---------|
| 공지 | `#FFEBEE` | `#F5F5F5` | `#FF6B6B` |
| 출결 | `#E8F5E9` | `#F5F5F5` | `#4CAF50` |
| 진도 | `#E3F2FD` | `#F5F5F5` | `#2196F3` |
| 숙제 | `#FFF3E0` | `#F5F5F5` | `#FF9800` |

## 4. 인터랙션 플로우

### 4.1 기본 플로우

```
┌──────────────────────────────────────────────┐
│                                              │
│  [공지 2] [출결 2] [진도 1] [숙제 5]          │
│                                              │
│      │                                       │
│      ▼ 탭                                    │
│                                              │
│  [공지 2▲] [출결 2] [진도 1] [숙제 5]         │
│  ├─────────────────────────────────────────┤ │
│  │ ● 항목 1                         [액션] │ │
│  │ ● 항목 2                         [액션] │ │
│  └─────────────────────────────────────────┘ │
│                                              │
│      │ [액션] 탭                             │
│      ▼                                       │
│                                              │
│  [공지 1▲] ...                               │ │
│  │ ○ 항목 1 (완료)                          │ │
│  │ ● 항목 2                         [액션] │ │
│                                              │
└──────────────────────────────────────────────┘
```

### 4.2 뱃지 전환

```
[공지 2▲] 열린 상태에서 [출결 2] 탭
    ↓
[공지 2▼] 닫히고 [출결 2▲] 열림
```

## 5. 특수 케이스

### 5.1 모두 완료 시

```
[✓ 공지 ✓] [✓ 출결 ✓] [✓ 진도 ✓] [✓ 숙제 ✓]
     ↑ 모든 뱃지 회색 + 체크
```

**축하 메시지 (선택적):**
```
┌─────────────────────────────────────────────┐
│  🎉 오늘 할 일을 모두 완료했어요!             │
└─────────────────────────────────────────────┘
```

### 5.2 항목이 많을 때 (5개 이상)

```
│ ○ 항목 1                          [확인]  │
│ ○ 항목 2                          [확인]  │
│ ○ 항목 3                          [확인]  │
│                                           │
│           + 2명 더보기                     │
│                    ↓ 탭하면 전체 페이지     │
```

### 5.3 0개일 때

뱃지 숨김 또는 비활성화:
```
[공지 0] → 표시 안 함 (또는 회색 비활성화)
```

## 6. 데이터 구조

### 6.1 통합 Task 인터페이스

```typescript
interface Task {
  type: 'notice' | 'attendance' | 'progress' | 'homework';
  count: number;
  items: TaskItem[];
}

interface TaskItem {
  id: string;
  title: string;
  subtitle: string;
  status: 'pending' | 'done';
  meta?: {
    className?: string;      // 출결, 진도
    studentCount?: number;   // 출결
    time?: string;           // 출결, 진도
    studentName?: string;    // 숙제
    submitted?: boolean;     // 숙제
  };
}
```

### 6.2 예시 데이터

```typescript
const tasks: Task[] = [
  {
    type: 'notice',
    count: 2,
    items: [
      { id: '1', title: '김민수(중3A) 결석', subtitle: '어머니 연락 필요', status: 'pending' },
      { id: '2', title: '전체 회의', subtitle: '14:00 강당', status: 'pending' },
    ]
  },
  {
    type: 'attendance',
    count: 2,
    items: [
      { id: '1', title: '중1C반', subtitle: '15:00-17:00 완료', status: 'pending', meta: { studentCount: 6 } },
      { id: '2', title: '중2B반', subtitle: '19:00-21:00 예정', status: 'pending', meta: { studentCount: 7 } },
    ]
  },
  // ...
];
```

## 8. UX 장점

| 항목 | 효과 |
|------|------|
| **일관성** | 모든 뱃지가 동일한 패턴 |
| **발견성** | 숨겨진 기능 없음, 탭하면 상세 |
| **피드백** | 완료 시 즉시 숫자 감소 |
| **효율성** | 대시보드에서 바로 처리 가능 |
| **동기부여** | 숫자 줄이기 = 게임화 |
