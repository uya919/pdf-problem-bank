# 강사 워크플로우 중심 디자인 대안 연구

> 같은 업무, 다른 관점: 워크플로우의 어떤 부분을 강조하느냐에 따라 UX가 달라진다

---

## 1. 연구 배경

### 1.1 강사의 전체 워크플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                      강사의 하루                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  [출근] ──→ [확인] ──→ [수업준비] ──→ [수업] ──→ [기록] ──→ [퇴근] │
│              │           │            │         │              │
│              ▼           ▼            ▼         ▼              │
│         ┌────────┐  ┌────────┐   ┌────────┐ ┌────────┐         │
│         │공지사항 │  │지난진도 │   │출결체크│ │진도기록│         │
│         │학원일정 │  │확인    │   │수업진행│ │숙제기록│         │
│         │숙제현황 │  │숙제확인 │   │        │ │시험점수│         │
│         │        │  │        │   │        │ │특이사항│         │
│         └────────┘  └────────┘   └────────┘ └────────┘         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 워크플로우의 핵심 단계

| 단계 | 활동 | 필요 정보 | 결과물 |
|------|------|----------|--------|
| **확인** | 공지, 일정, 지난 내용 파악 | 공지사항, 캘린더, 이전 기록 | 오늘 할 일 파악 |
| **수업준비** | 지난 진도 확인, 오늘 내용 준비 | 지난 진도, 숙제 제출 현황 | 수업 계획 |
| **수업** | 출결, 수업 진행 | 학생 명단, 출결 상태 | 수업 완료 |
| **기록** | 진도, 숙제, 시험, 특이사항 | 오늘 수업 내용, 학생별 상태 | 기록 완료 |

### 1.3 현재 문제점

```
문제 1: 단계 간 단절
├── 지난 진도 확인 → 별도 화면
├── 오늘 진도 기록 → 또 별도 화면
└── 연결고리가 없음

문제 2: 정보 분산
├── 학생 정보 → 학생 메뉴
├── 출결 정보 → 출결 메뉴
├── 진도 정보 → 반 메뉴 → 진도 탭
└── 한 학생을 파악하려면 여러 화면 이동

문제 3: 맥락 손실
├── "저번에 뭐 했지?" → 찾아봐야 함
├── "이 학생 요즘 어때?" → 여러 화면 이동
└── 기록할 때 이전 맥락 참조 어려움
```

## 2. 세 가지 접근법 비교

### 2.1 개요

| 구분 | 안 1: 수업 중심 | 안 2: 학생 중심 | 안 3: 맥락 연결 |
|------|----------------|----------------|----------------|
| **Hub** | 수업(반) | 학생 | 이전 기록 |
| **핵심 질문** | "이 수업에서 뭘 기록할까?" | "이 학생은 어떤 상태지?" | "어디까지 했지?" |
| **강조** | 빠른 기록 | 개인별 파악 | 연속성 |
| **은유** | 체크리스트 | 프로필 카드 | 이어보기 |

### 2.2 워크플로우 비교

```
안 1: 수업 → 즉시 기록
──────────────────────────
수업 카드 → [출결] [진도] [숙제] → 완료
         ↑
    한 곳에서 모든 기록


안 2: 학생 → 전체 파악
──────────────────────────
학생 선택 → 출결 | 진도 | 숙제 | 시험 | 노트 → 기록
            ↑
    한 학생의 모든 정보


안 3: 확인 → 이어서 기록
──────────────────────────
지난 진도 → 오늘 진도 연결 → 숙제 연결 → 완료
    ↑
  맥락을 보면서 기록
```

## 3. 안 1: 수업 중심 (Class-Centric)

### 3.1 핵심 개념

> "수업이 끝나면 바로 기록, 2단계 내 완료"

**Hub**: 수업(반)
**은유**: 체크리스트 - 할 일을 빠르게 처리

### 3.2 해결하는 문제

| 문제 | 현재 | 해결책 |
|------|------|--------|
| 기록까지 너무 많은 단계 | 7단계 | 2단계 |
| 기록 버튼 찾기 어려움 | 메뉴 → 탭 → 버튼 | 수업 카드에 바로 표시 |
| 여러 기록 분산 | 출결/진도/숙제 각각 | 한 카드에서 연속 기록 |

### 3.3 워크플로우 상세

```
[홈 대시보드]
     │
     ▼
┌─────────────────────┐
│ 중3A반 수학          │
│ 17:00-19:00         │
│ ┌─────┬─────┬─────┐ │
│ │출결 │진도 │숙제 │ │  ← 바로 기록 가능
│ └─────┴─────┴─────┘ │
└─────────────────────┘
     │
     ▼
[출결 체크] → [진도 기록] → [숙제 기록] → 완료
     ↑
   연속 흐름
```

### 3.4 강점과 약점

**강점:**
- ✅ 기록 속도 최적화
- ✅ 수업 직후 바로 처리
- ✅ 반별 관리 효율적

**약점:**
- ⚠️ 개별 학생 추적 어려움
- ⚠️ 지난 맥락 참조 불편
- ⚠️ 학부모 상담 시 정보 분산

### 3.5 적합한 사용자

- 여러 반을 담당하는 강사
- 수업 직후 기록하는 습관이 있는 강사
- 빠른 처리를 선호하는 강사

## 4. 안 2: 학생 중심 (Student-Centric)

### 4.1 핵심 개념

> "이 학생의 모든 것을 한눈에"

**Hub**: 학생
**은유**: 프로필 카드 - 한 사람에 대한 모든 정보

### 4.2 해결하는 문제

| 문제 | 현재 | 해결책 |
|------|------|--------|
| 학생별 정보 분산 | 출결/진도/숙제 각각 | Single Student View |
| 학부모 상담 시 정보 수집 | 여러 화면 이동 | 한 화면에 종합 |
| 특정 학생 추적 어려움 | 반별로 흩어짐 | 학생 타임라인 |

### 4.3 워크플로우 상세

```
[학생 선택: 김민수]
         │
         ▼
┌─────────────────────────────────────────┐
│ 김민수 (중3, 중3A반)                     │
│                                         │
│ [출결 100%] [진도 정상] [숙제 양호]      │  ← 한눈에 상태 파악
│                                         │
│ ┌─────────────────────────────────────┐ │
│ │ 📅 최근 활동                        │ │
│ │ 12/10 출석 ✓ | 진도: p.42-45       │ │
│ │ 12/9  출석 ✓ | 숙제: 완료          │ │
│ │ 12/8  지각   | Daily-test: 85점    │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ [+출결] [+진도] [+숙제] [+시험] [+노트] │  ← 바로 기록
└─────────────────────────────────────────┘
```

### 4.4 Single Student View 구성

```
┌─────────────────────────────────────────┐
│           학생 프로필 카드               │
├─────────────────────────────────────────┤
│ 📊 요약 Dashboard                       │
│ ├── 출석률: 95% (20/21일)               │
│ ├── 진도 상태: 정상 (반 평균 대비)       │
│ ├── 숙제 제출률: 88%                    │
│ └── 최근 시험: Daily 85점, Monthly 78점 │
├─────────────────────────────────────────┤
│ 📅 타임라인 (최근 활동)                  │
│ ├── 12/10: 출석, 진도 p.42-45           │
│ ├── 12/9: 출석, 숙제 완료               │
│ └── 12/8: 지각 (사유: 병원)             │
├─────────────────────────────────────────┤
│ 📝 특이사항 노트                        │
│ └── "수학 응용문제 추가 설명 필요"       │
├─────────────────────────────────────────┤
│ 🎯 Quick Actions                        │
│ [출결 기록] [진도 추가] [숙제 확인]      │
│ [시험 점수] [노트 추가]                  │
└─────────────────────────────────────────┘
```

### 4.5 강점과 약점

**강점:**
- ✅ 학생별 종합 파악 용이
- ✅ 학부모 상담에 최적
- ✅ 개인별 맞춤 관리 가능
- ✅ 학생 추적/분석 강력

**약점:**
- ⚠️ 반 전체 기록 시 비효율
- ⚠️ 수업 직후 일괄 기록 불편
- ⚠️ 학생 수가 많으면 탐색 시간 증가

### 4.6 적합한 사용자

- 소수 학생을 깊이 관리하는 강사
- 학부모 상담이 잦은 강사
- 개인별 맞춤 지도를 중시하는 강사

### 4.7 UX 패턴 참조

**Single Student View (교육 소프트웨어 패턴):**
> "한 학생의 모든 데이터를 한 곳에서 추적"
> — SchoolTool, Schoolytics, Panorama Education

**핵심 원칙:**
1. 학생 선택 시 모든 관련 정보 즉시 표시
2. 타임라인으로 변화 추이 파악
3. Quick Actions로 바로 기록 가능

## 5. 안 3: 맥락 연결 (Context-Continuity)

### 5.1 핵심 개념

> "어디까지 했지? 거기서 이어서"

**Hub**: 이전 기록 (맥락)
**은유**: 이어보기 - Netflix처럼 "지난 시간에..."

### 5.2 해결하는 문제

| 문제 | 현재 | 해결책 |
|------|------|--------|
| 지난 진도 기억 못함 | 별도로 찾아봐야 함 | 자동으로 보여줌 |
| 기록 시 맥락 단절 | 이전 기록 참조 어려움 | 나란히 표시 |
| 연속성 없는 기록 | 매번 처음부터 | 이어서 기록 |

### 5.3 워크플로우 상세

```
[진도 기록 시작]
         │
         ▼
┌─────────────────────────────────────────┐
│ 중3A반 진도 기록                         │
├─────────────────────────────────────────┤
│ 📖 지난 시간 (12/9)                     │  ← 맥락 먼저 표시
│ ├── 교재: 베이직쎈                       │
│ ├── 범위: p.38-41                       │
│ └── 주제: 이차방정식 기본                │
│                                         │
│ ─────────── 이어서 ───────────          │
│                                         │
│ 📝 오늘 (12/10)                         │  ← 이어서 기록
│ ├── 교재: [베이직쎈 ▼] (자동 선택)       │
│ ├── 범위: [42] ~ [45]  (자동 제안: 42)  │
│ └── 주제: [이차방정식 활용    ]          │
└─────────────────────────────────────────┘
```

### 5.4 Task Continuity 패턴

```
┌─────────────────────────────────────────┐
│        맥락 연결 기록 화면               │
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────────┐    ┌─────────────┐     │
│  │ 지난 시간   │ ──→│ 오늘        │     │
│  │ (Read-only)│    │ (Editable) │     │
│  ├─────────────┤    ├─────────────┤     │
│  │ 진도: p.38  │    │ 진도: p.42  │     │
│  │ 숙제: p.39  │───→│ 숙제: p.43  │     │
│  │ 시험: 80점  │    │ 시험: [  ] │     │
│  └─────────────┘    └─────────────┘     │
│                                         │
│        ↑ 맥락 참조하며 기록              │
│                                         │
└─────────────────────────────────────────┘
```

### 5.5 연결 기록의 흐름

```
Step 1: 진도 연결
────────────────────
지난 진도: p.38-41 (이차방정식 기본)
    ↓
오늘 진도: p.42-45 (이차방정식 활용)
    ↓
  [자동으로 페이지 연결 제안]


Step 2: 숙제 연결
────────────────────
지난 숙제: p.39 5번~10번
    ↓
  [미제출 학생 3명 표시]
    ↓
오늘 숙제: p.43 1번~5번
    ↓
  [전체 학생에게 자동 할당]


Step 3: 시험 연결
────────────────────
지난 Daily-test: 평균 82점
    ↓
오늘 Daily-test: [점수 입력]
    ↓
  [추이 그래프 자동 업데이트]
```

### 5.6 강점과 약점

**강점:**
- ✅ 맥락 파악 자동화
- ✅ 연속적인 기록 지원
- ✅ 기억에 의존하지 않음
- ✅ 데이터 일관성 유지

**약점:**
- ⚠️ 첫 기록 시에는 맥락 없음
- ⚠️ 불규칙한 수업에는 부적합
- ⚠️ 화면 복잡도 증가 가능

### 5.7 적합한 사용자

- 연속적인 커리큘럼을 진행하는 강사
- 진도 이어가기가 중요한 강사
- 기억력에 의존하기 싫은 강사

### 5.8 UX 패턴 참조

**Task Continuity (Mozilla UX Research):**
> "사용자가 중단한 지점에서 자연스럽게 재개"

**핵심 원칙 (UXmatters):**
1. **Data Continuity**: 관련 정보를 컨텍스트 간 유지
2. **Contextual Flexibility**: 현재 맥락에서 수정 가능
3. **Fluid Task Transitions**: 매끄러운 전환

## 6. 세 가지 접근법 심층 비교

### 6.1 정보 구조 비교

```
안 1: 수업 중심
──────────────────
홈
├── 오늘 수업
│   ├── 중3A반 → [출결] [진도] [숙제]
│   ├── 중2B반 → [출결] [진도] [숙제]
│   └── 중1C반 → [출결] [진도] [숙제]
└── 오늘 할 일 (미완료 카운트)


안 2: 학생 중심
──────────────────
홈
├── 최근 본 학생
│   └── 김민수 → 전체 정보
├── 학생 검색
└── 반별 학생 목록
    ├── 중3A반 학생들
    └── 중2B반 학생들


안 3: 맥락 연결
──────────────────
홈
├── 이어서 기록하기
│   ├── 중3A반: 지난 진도 p.38 → 오늘?
│   └── 중2B반: 지난 진도 p.22 → 오늘?
├── 숙제 확인 필요 (지난 것 연결)
└── 시험 점수 추이
```

```
안 2: 학생 → 전체 파악
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[학생 선택] ──→ [모든 정보 확인] ──→ [기록]
              ↑
         한 사람에 집중


안 3: 확인 → 이어서 기록
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[지난 기록 확인] ──→ [이어서 기록] ──→ [연결 완료]
                  ↑
            맥락을 보면서 연속 기록
```

---

## 7. 결론

### 7.1 각 접근법의 핵심 가치

| 접근법 | 핵심 가치 | 최적 상황 |
|--------|----------|----------|
| **안 1** | 속도 | 수업 직후 빠른 기록 |
| **안 2** | 깊이 | 개인별 심층 관리 |
| **안 3** | 연속성 | 맥락 기반 기록 |

### 7.2 하이브리드 가능성

세 가지 접근법은 상호 배타적이지 않습니다:

```
통합 가능한 요소:
├── 안 1의 Quick Actions → 안 2, 안 3에도 적용 가능
├── 안 2의 Single Student View → 안 1의 수업 상세에 추가
└── 안 3의 맥락 표시 → 안 1의 기록 화면에 추가
```

### 7.3 선택 가이드

```
빠른 기록이 중요하다면 → 안 1
개인별 관리가 중요하다면 → 안 2
연속성이 중요하다면 → 안 3
```
