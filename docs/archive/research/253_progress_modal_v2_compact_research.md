# 진도기록 모달 v2 - 컴팩트 디자인 연구

> 목적: 스크롤 최소화, 입력 간소화를 위한 개선안

---

## 1. 변경 요구사항 분석

### 1.1 지난 수업 섹션

| 항목 | v1 (현재) | v2 (개선) | 이유 |
|------|-----------|-----------|------|
| 주제 표시 | 2줄 (라벨 + 값) | 1줄 (인라인) | 스크롤 절약 |
| 숙제 제출 | "제출 6/8명" 표시 | 삭제 | 불필요한 정보 |
| 레이아웃 | 수직 나열 | 수평 그리드 | 밀도 증가 |

### 1.2 오늘 수업 섹션

| 항목 | v1 (현재) | v2 (개선) | 이유 |
|------|-----------|-----------|------|
| 주제 → 단원명 | 매번 입력 | 유지 (sticky) | 단원 진행 중 반복 입력 방지 |
| 힌트 텍스트 | "💡 지난 주제: ..." | 삭제 | 간소화 |
| 진도 입력 | 드롭박스 + 텍스트 | 스마트 입력 | 투박함 해소 |
| 숙제 | 토글 (ON/OFF) | 기본 ON | 숙제가 기본 |

### 1.3 추가 고려사항

- **데이터 구조**: 단원명 유지를 위한 상태 관리

## 2. 컴팩트 레이아웃 설계

### 2.1 지난 수업 - 1줄 디자인

**v1 (3줄):**
```
📚 주제
이차방정식 풀이

📄 진도
베이직쎈 p.42-45

📝 숙제
p.46-48 짝수번호
✓ 제출 6/8명
```

**v2 (2줄):**
```
📚 이차방정식 풀이
📄 베이직쎈 p.42-45 · 숙제 p.46-48
```

**디자인 원칙:**
- 아이콘 + 값을 한 줄에
- 중간점(·)으로 정보 구분
- 숙제 제출 현황 생략

### 2.2 단원명 스티키 (Sticky Unit)

**개념:**
```
수업 1: 단원명 "이차방정식" 입력
수업 2: 단원명 자동 유지 (변경 버튼만 표시)
수업 3: 단원명 자동 유지
수업 4: 단원명 "이차함수"로 변경
수업 5: 새 단원명 유지
```

**UI:**
```
┌─────────────────────────────────────┐
│  📚 단원명                          │
│  ┌─────────────────────────────────┐│
│  │ 이차방정식              [변경]  ││  ← 유지 모드
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘

또는 (변경 시):

┌─────────────────────────────────────┐
│  📚 단원명                          │
│  ┌─────────────────────────────────┐│
│  │ 이차함수                        ││  ← 입력 모드
│  └─────────────────────────────────┘│
│  💡 이전: 이차방정식                 │
└─────────────────────────────────────┘
```

**데이터 구조:**
```typescript
interface ClassProgress {
  classId: string;
  unitName: string;        // 단원명 (sticky)
  unitStartDate: string;   // 단원 시작일
  textbook: string;
  startPage: number;
  endPage: number;
}
```

## 3. 진도 입력 UI 개선안

### 3.1 현재 문제점

```
현재 (v1):
┌───────────┐ ┌──────────────────┐
│ 베이직쎈 ▼│ │ 46-50           │
└───────────┘ └──────────────────┘

문제:
1. 두 개의 분리된 입력 필드
2. 드롭박스가 공간 차지
3. 교재 선택 → 페이지 입력 순서 강제
```

### 3.2 대안 1: 통합 입력 필드 (Unified Input)

```
┌─────────────────────────────────────┐
│ 베이직쎈 46-50                      │
└─────────────────────────────────────┘
     ↓ 자동 파싱
교재: 베이직쎈
페이지: 46-50
```

**장점:**
- 한 번에 입력
- 자연스러운 표현 ("베이직쎈 46-50페이지")

**구현:**
```javascript
function parseProgress(input) {
  // "베이직쎈 46-50" → { textbook: "베이직쎈", pages: "46-50" }
  const match = input.match(/^(.+?)\s+(\d+(?:-\d+)?)$/);
  if (match) {
    return { textbook: match[1], pages: match[2] };
  }
  return null;
}
```

### 3.3 대안 2: 슬라이더 + 자동완성 (Smart Slider)

```
┌─────────────────────────────────────┐
│  📄 진도                            │
│                                     │
│  교재: [베이직쎈 ▼]                 │
│                                     │
│  페이지: 46 ────●────────── 50      │
│          ↑ 시작      끝 ↑          │
│                                     │
│  💡 지난 진도: p.45                 │
└─────────────────────────────────────┘
```

**장점:**
- 시각적으로 범위 명확
- 터치 친화적

**단점:**
- 구현 복잡
- 페이지 수가 많으면 정밀도 떨어짐

### 3.4 대안 3: 스텝퍼 입력 (Stepper)

```
┌─────────────────────────────────────┐
│  📄 진도                            │
│                                     │
│  베이직쎈                           │
│  ┌───────────────────────────────┐  │
│  │  [-]  46  ~  50  [+]         │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

**장점:**
- 숫자 직접 입력 가능
- +/- 버튼으로 미세 조정

### 3.5 대안 4: 칩 기반 입력 (Chip-based) ⭐ 권장

```
┌─────────────────────────────────────┐
│  📄 진도                            │
│                                     │
│  [베이직쎈 ▼]  p.[46] ~ [50]       │
└─────────────────────────────────────┘
```

**특징:**
- 교재: 드롭다운 칩 (탭하면 선택)
- 페이지: 숫자만 입력하는 작은 필드

**장점:**
- 컴팩트
- 각 요소 독립적 수정 가능

## 4. 숙제 - 기본 ON 설계

### 4.1 토글 제거

**v1 (토글):**
```
📝 숙제 내기           [ON]
[베이직쎈▼] [51-53 홀수]
마감 [다음 수업▼]
```

**v2 (항상 표시):**
```
📝 숙제
[베이직쎈▼]  p.[51] ~ [53]

□ 숙제 없음 (체크 시 숨김)
```

### 4.2 숙제 자동완성 개선

```javascript
// 진도 기반 숙제 자동 제안
function suggestHomework(progress) {
  const { textbook, startPage, endPage } = progress;

  return {
    textbook,
    startPage,
    endPage,
    type: 'all', // 기본: 전체
  };
}
```

**자동 제안 로직:**
1. 교재: 진도와 동일
2. 페이지: 진도 범위와 동일

### 4.3 비고 필드

숙제 아래에 간단한 메모를 남길 수 있는 텍스트 필드:

```
📝 비고
┌─────────────────────────────────────┐
│ 다음 주 시험 범위 안내함            │
└─────────────────────────────────────┘
```

**용도:**
- 특이사항 메모 (결석자, 보충 필요 등)
- 시험/이벤트 기록
- 학부모 전달 사항

## 5. 오늘 수업 한줄 디자인 연구

### 5.1 현재 문제점

```
현재 (v2):
📚 단원명  [이차방정식      ] [변경]
📄 진도    [베이직쎈▼] p.[46] ~ [50]
📝 숙제    [베이직쎈▼] p.[51] ~ [53]
           □ 숙제 없음

→ 세로로 3개 섹션 = 스크롤 필요
```

### 5.2 대안 1: 인라인 그리드 (Inline Grid)

```
┌─────────────────────────────────────┐
│  📚 [이차방정식    ▼]               │  ← 단원명 (드롭다운으로 변경)
│  📄 [베이직쎈▼] [46]-[50]          │  ← 진도
│  📝 [베이직쎈▼] [51]-[53] □없음    │  ← 숙제+체크박스 한줄
│  💬 [비고 입력...]                  │  ← 비고
└─────────────────────────────────────┘
```

**장점:** 모든 요소가 한 줄씩
**단점:** 가로 공간 부족 시 깨짐

### 5.3 대안 2: 탭 기반 (Tab-based)

```
┌─────────────────────────────────────┐
│  [진도] [숙제] [비고]               │  ← 탭 선택
├─────────────────────────────────────┤
│  📚 단원명: 이차방정식              │
│  📄 [베이직쎈▼] p.[46] ~ [50]      │
└─────────────────────────────────────┘
```

**장점:** 화면 전환으로 깔끔
**단점:** 탭 전환 필요 (입력 속도 저하)

### 5.4 대안 3: 스마트 자동완성 (Smart Auto) ⭐ 권장

```
┌─────────────────────────────────────┐
│  📄 [베이직쎈▼] p.[46] ~ [50]      │  ← 진도만 입력
│  ────────────────────────────────── │
│  📝 숙제: p.46-50 (진도와 동일)     │  ← 자동 표시
│     □ 숙제 없음                     │
│  💬 [비고...]                       │
└─────────────────────────────────────┘
```

**핵심 아이디어:**
1. 단원명: 상단에 읽기 전용으로 표시 (변경 버튼만)
2. 진도: 메인 입력
3. 숙제: 진도와 동일하게 자동 세팅 (수정 가능)
4. 비고: 한 줄 입력

**장점:**
- 진도 입력 한 번이면 끝
- 숙제는 대부분 진도와 동일
- 예외만 수정

### 5.5 대안 4: 초컴팩트 (Ultra Compact)

```
┌─────────────────────────────────────┐
│  이차방정식                    [변경]│  ← 단원명 헤더
├─────────────────────────────────────┤
│  진도 [베이직쎈▼] [46]-[50]        │
│  숙제 [베이직쎈▼] [50]-[53]        │  ← 비우면 없음
│  비고 [                           ]│  ← 자동 높이
└─────────────────────────────────────┘
```

**특징:**
- 숙제: 비워두면 자동으로 "없음"
- 비고: 자동 줄넘김 (입력에 따라 높이 조절)

### 5.6 미니 입력 필드 연구

**표준 vs 미니 사이즈:**
| 항목 | 표준 | 미니 | 차이 |
|------|------|------|------|
| 높이 | 44px | 32px | -12px |
| 폰트 | 14px | 13px | -1px |
| 패딩 | 14px | 10px | -4px |

**미니 사이즈 장점:**
- 더 많은 필드를 화면에 표시
- 폼 밀도 증가
- 모바일에서도 충분히 터치 가능 (32px > 최소 권장 28px)

**구현 예시:**
```css
.input-mini {
  height: 32px;
  padding: 0 10px;
  font-size: 13px;
  border-radius: 8px;
}
```

### 5.7 자동 높이 비고 필드 (Auto-resize Textarea)

**구현 방법:**
```javascript
// 자동 높이 조절 textarea
function autoResize(textarea) {
  textarea.style.height = 'auto';
  textarea.style.height = textarea.scrollHeight + 'px';
}

// 사용
<textarea
  oninput="autoResize(this)"
  rows="1"
  style="min-height: 32px; resize: none;"
/>
```

**특징:**
- 기본: 1줄 (32px)
- 입력 시: 내용에 따라 자동 확장
- 최대: 제한 없음 (또는 max-height 설정)

**CSS:**
```css
.notes-auto {
  min-height: 32px;
  max-height: 96px;  /* 약 3줄 */
  overflow-y: auto;
  resize: none;
  line-height: 1.4;
}
```

## 7. 인터랙션 상세

### 7.1 단원명 유지 로직

```javascript
// 수업 기록 시
function saveProgress(classId, data) {
  const { unitName, textbook, pages, homework } = data;

  // 단원명을 반 설정에 저장 (다음 수업에도 유지)
  if (unitName !== getCurrentUnit(classId)) {
    setClassUnit(classId, {
      name: unitName,
      startedAt: new Date(),
    });
  }

  // 진도 저장
  saveProgressRecord(classId, { textbook, pages, homework });
}

// 모달 열 때
function openProgressModal(classId) {
  const currentUnit = getCurrentUnit(classId);

  return {
    unitName: currentUnit?.name || '', // 유지된 값
    isUnitLocked: !!currentUnit,       // 변경 버튼 표시 여부
    ...
  };
}
```

### 7.2 페이지 입력 자동 포맷

```javascript
// 입력: "4650" → 표시: "46-50"
function formatPageRange(input) {
  const digits = input.replace(/\D/g, '');

  if (digits.length >= 4) {
    const mid = Math.ceil(digits.length / 2);
    const start = digits.slice(0, mid);
    const end = digits.slice(mid);
    return `${start}-${end}`;
  }

  return digits;
}
```

### 7.3 숙제 자동 완성

```javascript
// 진도 입력 시 숙제 자동 완성
function onProgressChange(textbook, startPage, endPage) {

  setHomework({
    textbook,
    startPage,
    endPage,
    type: 'all'  // 전체
```
