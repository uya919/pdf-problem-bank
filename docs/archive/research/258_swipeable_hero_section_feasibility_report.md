# Hero Section 스와이프 기능 구현 가능성 리포트

> 작성일: 2025-12-10
> 요청: 히어로 섹션을 좌우로 넘기면서 그날 수업들을 탐색

---

## 1. 개요

현재 DashboardHeroCard는 "다음 수업" 하나만 표시합니다.
제안: 오늘 모든 수업을 좌우 스와이프로 탐색 가능하게 변경

```
┌─────────────────────────────┐
│  ← [중1C반] [중3A반] [중2B반] →  │  (인디케이터)
│                             │
│  ⏱ 다음 수업 5분 후          │
│  중3A반 수학 | 학생 8명       │
│  17:00 ~ 19:00              │
│  [출결 체크] [진도 기록]      │
└─────────────────────────────┘
        ● ○ ○  (도트 인디케이터)
```

---

## 2. 구현 가능성: ✅ 높음

### 2.1 라이브러리 옵션

| 라이브러리 | 번들 크기 | 터치 지원 | 추천도 |
|------------|-----------|-----------|--------|
| **Embla Carousel** | 7KB | 우수 | ⭐⭐⭐⭐⭐ |
| Swiper | 40KB+ | 우수 | ⭐⭐⭐⭐ |
| react-slick | 30KB+ | 보통 | ⭐⭐⭐ |
| 순수 CSS + JS | 0KB | 직접 구현 | ⭐⭐⭐ |

**권장: Embla Carousel**
- 경량 (7KB gzipped)
- 모바일 터치 네이티브 수준
- React hooks 친화적
- 토스/카카오 앱에서도 사용하는 패턴

### 2.2 예상 구현 코드

```tsx
import useEmblaCarousel from 'embla-carousel-react';

function HeroCarousel({ classes }: { classes: ClassInfo[] }) {
  const [emblaRef, emblaApi] = useEmblaCarousel({
    loop: false,
    startIndex: getCurrentClassIndex(classes)  // 현재 수업에서 시작
  });

  return (
    <div ref={emblaRef} className="overflow-hidden">
      <div className="flex">
        {classes.map((cls) => (
          <div key={cls.id} className="flex-[0_0_100%]">
            <DashboardHeroCard classInfo={cls} />
          </div>
        ))}
      </div>
    </div>
  );
}
```

### 2.3 구현 난이도

| 항목 | 난이도 | 예상 시간 |
|------|--------|-----------|
| 기본 스와이프 | 쉬움 | 1시간 |
| 인디케이터 | 쉬움 | 30분 |
| 자동 현재 수업 포커스 | 보통 | 30분 |
| 애니메이션 다듬기 | 보통 | 1시간 |
| **총합** | - | **3시간** |

## 3. UX 장점

### 3.1 정보 접근성 향상
- 한 화면에서 오늘 모든 수업 빠르게 확인
- 스크롤 없이 수업 간 전환

### 3.2 모바일 친화적
- 터치 제스처는 모바일에서 자연스러움
- 토스, 카카오페이 등 앱에서 익숙한 패턴

### 3.3 빠른 출결/진도 입력
- 완료된 수업 → 스와이프 → 바로 진도 기록
- 여러 수업 연속 처리 시 효율적

## 4. 우려 사항 및 해결책

### 4.1 ⚠️ 현재 수업 찾기 어려움

**문제**: 스와이프하다가 "지금 해야 할 수업"을 놓칠 수 있음

**해결책**:
1. **자동 스크롤**: 페이지 진입 시 현재/다음 수업으로 자동 이동
2. **시각적 강조**: 현재 수업 카드에 테두리 또는 "다음" 뱃지
3. **홈 버튼**: 탭하면 현재 수업으로 돌아가기

```tsx
// 현재 수업 강조
<div className={cn(
  "rounded-2xl",
  isCurrent && "ring-2 ring-white/50"
)}>
```

### 4.2 ⚠️ 수업이 1개일 때 어색함

**문제**: 수업이 하나면 스와이프할 게 없음

**해결책**:
- 수업 1개: 기존 단일 카드 UI 유지
- 수업 2개 이상: 스와이프 활성화

```tsx
{classes.length === 1 ? (
  <DashboardHeroCard classInfo={classes[0]} />
) : (
  <HeroCarousel classes={classes} />
)}
```

### 4.3 ⚠️ 수업 없는 날

**문제**: 오늘 수업이 없으면?

**해결책**: 기존 `NoClassHeroCard` 유지 (변경 없음)

### 4.4 ⚠️ 스와이프 vs 스크롤 충돌

**문제**: 세로 스크롤과 가로 스와이프가 간섭할 수 있음

**해결책**:
- Embla는 터치 각도 감지로 자동 구분
- threshold 조정으로 민감도 튜닝 가능

```tsx
useEmblaCarousel({
  dragThreshold: 10,  // 10px 이상 움직여야 스와이프 인식
})
```

### 4.5 ⚠️ 성능 (수업이 많을 때)

**문제**: 하루에 수업이 10개 이상이면?

**해결책**:
- 학원 특성상 하루 최대 5-8개 수업 (현실적 범위)
- Embla는 가상화 없이도 20개까지 부드러움
- 필요시 가상화(virtualization) 추가 가능

### 4.6 ⚠️ 접근성 (A11y)

**문제**: 스와이프는 키보드/스크린리더로 어려움

**해결책**:
1. 좌우 화살표 버튼 추가 (선택적)
2. aria-label로 현재 위치 안내
3. 키보드 방향키 지원

```tsx
<div
  role="region"
  aria-label={`${currentIndex + 1}/${total} 수업`}
  tabIndex={0}
  onKeyDown={handleArrowKeys}
>
```

## 5. 디자인 변형 옵션

### Option A: 기본 스와이프 (권장)
```
┌─────────────────────────────┐
│  [히어로 카드 전체 영역]      │
│                             │
│  ← 스와이프 →                │
└─────────────────────────────┘
        ● ○ ○
```

### Option B: 상단 탭 + 스와이프
```
   [완료] [중3A] [예정]   ← 탭으로도 전환 가능
┌─────────────────────────────┐
│  [히어로 카드]              │
└─────────────────────────────┘
```

### Option C: 미니 카드 + 스와이프 (토스 스타일)
```
┌─────────────────────────────┐
│  [중1C 완료] [중3A 다음] [중2B]  │  ← 작은 카드들
└─────────────────────────────┘
        ↓ 선택하면 상세 표시
```
