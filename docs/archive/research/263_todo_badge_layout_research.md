# 할일 뱃지 레이아웃 연구

> 작성일: 2025-12-11
> 이슈: 왼쪽 정렬 시 오른쪽 여백 과다

---

## 1. 현재 상황

```
┌────────────────────────────────────────┐
│  [출결 2] [진도 1] [숙제 5]            │  ← 오른쪽 여백 과다
│                              ~~~~~~~~~ │
└────────────────────────────────────────┘
```

**문제점:**
- 3개 뱃지가 왼쪽에 몰려 있음
- 오른쪽 약 40% 공간이 비어 있음
- 시각적 불균형 → 미완성된 느낌

---

## 2. UI/UX 철학 기준

### 토스 디자인 원칙

| 원칙 | 적용 |
|------|------|
| **여백은 의미가 있어야 함** | 불필요한 여백은 제거 |
| **시선 흐름 유도** | 좌→우 자연스럽게 |
| **탭 영역 충분히** | 최소 44px 높이, 적절한 너비 |
| **일관성** | 다른 요소와 정렬 맞춤 |

### Apple Human Interface Guidelines

> "Use consistent alignment to create visual harmony"
> "Ensure touch targets are at least 44pt"

---

## 3. 대안 분석

### Option A: 균등 분배 (flex-1)

```
┌────────────────────────────────────────┐
│ [   출결 2   ] [   진도 1   ] [   숙제 5   ] │
└────────────────────────────────────────┘
```

**CSS:**
```css
.badge { flex: 1; justify-content: center; }
```

**장점:**
- 여백 완전 제거
- 균형잡힌 레이아웃
- 탭 영역 최대화

**단점:**
- 뱃지 크기가 내용과 무관하게 결정
- 토스 스타일과 다소 다름 (토스는 내용 기반 크기)

**평점: ★★★★☆**

---

### Option B: 중앙 정렬

```
┌────────────────────────────────────────┐
│       [출결 2] [진도 1] [숙제 5]       │
└────────────────────────────────────────┘
```

**CSS:**
```css
.container { justify-content: center; }
```

**장점:**
- 시각적 균형
- 구현 간단

**단점:**
- 좌우 여백 동일하게 남음
- 공간 활용도 낮음

**평점: ★★★☆☆**

---

### Option C: 양끝 정렬 (space-between)

```
┌────────────────────────────────────────┐
│ [출결 2]      [진도 1]      [숙제 5] │
└────────────────────────────────────────┘
```

**CSS:**
```css
.container { justify-content: space-between; }
```

**장점:**
- 여백 활용
- 시선 분산

**단점:**
- 뱃지 간격이 너무 넓어 그룹감 상실
- 3개가 하나의 "할일" 그룹임을 인지하기 어려움

**평점: ★★☆☆☆**

---

### Option D: 균등 간격 (space-evenly)

```
┌────────────────────────────────────────┐
│   [출결 2]   [진도 1]   [숙제 5]   │
└────────────────────────────────────────┘
```

**CSS:**
```css
.container { justify-content: space-evenly; }
```

**장점:**
- 균형잡힌 간격
- 그룹감 유지

**단점:**
- Option C보다 나으나 여전히 간격 넓음

**평점: ★★★☆☆**

---

### Option E: 균등 분배 + 최대 너비 제한 (권장)

```
┌────────────────────────────────────────┐
│ [  출결 2  ] [  진도 1  ] [  숙제 5  ] │
└────────────────────────────────────────┘
```

**CSS:**
```css
.badge {
  flex: 1;
  max-width: 120px;  /* 너무 넓어지지 않도록 */
  justify-content: center;
}
.container {
  justify-content: center;  /* 3개가 중앙에 모임 */
  gap: 8px;
}
```

**장점:**
- 균형 + 그룹감 유지
- 탭 영역 충분
- 너무 넓어지지 않음

**단점:**
- 화면이 매우 넓을 때 양쪽 여백 발생

**평점: ★★★★☆**

---

### Option F: 전체 너비 균등 (최종 권장)

```
┌────────────────────────────────────────┐
│[    출결 2    ][    진도 1    ][    숙제 5    ]│
└────────────────────────────────────────┘
```

**CSS:**
```css
.badge {
  flex: 1;
  text-align: center;
  justify-content: center;
}
```

**장점:**
- 여백 완전 제거
- 탭 영역 최대화 (UX 향상)
- 깔끔하고 정돈된 느낌
- 토스 앱의 퀵메뉴와 유사

**단점:**
- 뱃지가 내용보다 넓어 보일 수 있음

**평점: ★★★★★**

## 4. 토스 앱 사례 분석

### 토스 홈 퀵액션

```
┌─────────────────────────────┐
│ [송금] [결제] [충전] [주식] │  ← 균등 분배
└─────────────────────────────┘
```

### 토스 알림 뱃지

```
┌─────────────────────────────┐
│ [3건 미확인]   [1건 새소식] │  ← flex-1 + 간격
└─────────────────────────────┘
```

**토스 패턴:**
- **행동 유도 버튼**: 균등 분배 (flex-1)
- **정보 표시 뱃지**: 내용 기반 크기
- **할일은 행동 유도** → 균등 분배가 적합

## 5. 최종 권장안

### 권장: Option F (전체 너비 균등 분배)

```tsx
<div className="flex gap-2">
  {todos.map((todo) => (
    <button className="flex-1 flex items-center justify-center gap-1 ...">
      <span>{todo.icon}</span>
      <span>{todo.title} {todo.count}</span>
    </button>
  ))}
</div>
```

### 변경 사항

| 항목 | Before | After |
|------|--------|-------|
| flex | (없음) | `flex-1` |
| justify | (없음) | `justify-center` |
| 텍스트 정렬 | 좌측 | 중앙 |

### 예상 결과

**390px 화면 (iPhone 14):**
```
┌──────────────────────────────────────┐
│ 패딩16 │ 뱅116 │ 간8 │ 뱅116 │ 간8 │ 뱅116 │ 패딩16 │
│        │출결 2│     │진도 1│     │숙제 5│        │
└──────────────────────────────────────┘
계산: 16 + 116 + 8 + 116 + 8 + 116 + 16 = 396px (약간 조정됨)
```

**320px 화면 (iPhone SE):**
```
각 뱅 너비: (320 - 32 - 16) / 3 = 90px
→ 충분한 탭 영역 확보
```

## 7. 구현 코드

### NoticeAndTodoCard.tsx 변경

```tsx
// Before
<div className="flex gap-2">
  <button className="flex items-center gap-1 px-3 py-2 ...">

// After
<div className="flex gap-2">
  <button className="flex-1 flex items-center justify-center gap-1 px-3 py-2 ...">
```

### 추가 고려사항

1. **4개 이상일 때**: 스크롤 또는 "+N" 뱃지
2. **1-2개일 때**: flex-1 유지하되 max-width 적용 고려
3. **긴 텍스트**: truncate 처리
