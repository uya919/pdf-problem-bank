# Hyeyum 백오피스 단계별 개발 계획

> 작성일: 2025-12-11
> 방법론: 목업 → 기능 구현
> UI/UX 철학: 토스 스타일

---

## 개발 원칙

### 1. 토스 UI/UX 철학

| 원칙 | 의미 | 적용 |
|------|------|------|
| **집중** | 한 화면 = 한 가지 목적 | 페이지별 명확한 역할 |
| **단순** | 필요한 것만, 필요할 때 | Progressive Disclosure |
| **즉각적** | 탭 한 번에 완료 | 최소 클릭 수 |
| **일관성** | 동일한 패턴 반복 | 컴포넌트 재사용 |

### 2. 개발 방법론

```
목업 (HTML) → 검토 → React 컴포넌트 → 페이지 통합 → 기능 연동
```

### 3. 파일 규칙

- 목업: `docs/mockups/[페이지명]-v[버전].html`
- 컴포넌트: `frontend/src/components/backoffice/[카테고리]/[컴포넌트].tsx`
- 페이지: `frontend/src/pages/backoffice/[페이지].tsx`
