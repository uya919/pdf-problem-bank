
## 토스 디자인 원칙 적용

| 원칙 | 적용 내용 |
|------|----------|
| **1 Thing per 1 Page** | 메인 → 교재별 → 교재 내 문제 단계적 드릴다운 |
| **Minimum Features** | 검색, 교재별, 전체보기 3가지 핵심 기능만 |
| **Clear CTA** | 빠른 접근 카드로 명확한 다음 단계 제시 |
| **친근한 UX 문구** | "~개의 문제를 보관하고 있어요" |
| **부드러운 애니메이션** | framer-motion으로 페이드인, 스케일 효과 |
