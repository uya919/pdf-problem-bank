## 0. 핵심 결정: 점수 내부/외부 분리

### 제안 분석

| 구분 | 내부(강사용) | 외부(학부모용) |
|------|-------------|---------------|
| 척도 | 5점 (1-5) | 3단계 라벨 |
| 표시 | ★★★★☆ | 좋음 / 보통 / 주의 |
| 목적 | 데이터 정밀도, 추세 분석 | 민원 최소화, 납득 용이 |

**매핑 로직:**
```typescript
function scoreToLabel(score: number): '좋음' | '보통' | '주의' {
  if (score >= 4) return '좋음';
  if (score === 3) return '보통';
  return '주의';  // 1-2점
}
```

### ✅ 결론: 수용

**이유:**
1. 숫자는 비교/경쟁 심리 유발 → 라벨은 상태 설명
2. "3점이 왜 3점이냐" 문의 차단
3. 내부 데이터 정밀도는 유지 (추세 분석, AI 예측 등 활용 가능)

**구현 방안:**
- DB: `attitude_score INTEGER(1-5)` 그대로 저장
- 강사 UI: 별점 5개 입력
- 학부모 앱: `scoreToLabel()` 변환 후 라벨만 표시
- 라벨 옆에 근거 캡션 추가

## 1. 루브릭 문구 행동/빈도 기반 통일

### 현재 문제점

| 현재 문구 | 문제점 |
|-----------|--------|
| "필기 완벽" | 주관적, 스타일 차이를 점수화 |
| "필기 불량" | 부정적 라벨링, 민원 유발 |
| "수업 방해" | 극단적 표현, 학부모 자극 |

### 제안된 공통 프레임

| 점수 | 키워드 | 의미 |
|------|--------|------|
| 5 | 거의 항상 / 자발적 / 지속 | 코칭 없이 스스로 유지 |
| 4 | 대체로 / 가끔 코칭 | 가끔 리마인드 필요 |
| 3 | 들쭉날쭉 / 코칭하면 수행 | 일관성 부족, 지도 필요 |
| 2 | 자주 놓침 / 반복 개입 | 빈번한 개입 필요 |
| 1 | 거의 안 됨 / 수업 영향 | 심각한 수준 |

### ✅ 결론: 수용

**새로운 루브릭 (최종안):**

#### 수업 태도
| 점수 | 기준 |
|------|------|
| 5 | 준비·집중 자발적 유지 |
| 4 | 대체로 집중, 흔들리면 회복 |
| 3 | 산만 잦음, 리마인드 시 회복 |
| 2 | 산만 지속, 수업 흐름 영향 |
| 1 | 참여 거부/방해 수준 |

#### 이해도
| 점수 | 기준 |
|------|------|
| 5 | 스스로 적용·설명 가능 |
| 4 | 적용 가능, 힌트면 해결 |
| 3 | 설명 후 따라함 (유사 필요) |
| 2 | 반복 설명 필요 (실수 반복) |
| 1 | 기초 재정비 필요 |

#### 숙제 완료도
| 점수 | 기준 |
|------|------|
| 5 | 95-100% + 오답정리 |
| 4 | 80-94% |
| 3 | 50-79% |
| 2 | 20-49% |
| 1 | 0-19% 또는 미제출 |

## 2. 근거 자동첨부

### 제안 분석

**표시 위치:** 각 항목 별점 바로 아래 (회색 캡션)

**데이터 소스 (Supabase 실제 분석):**

| 항목 | 근거 데이터 | 소스 테이블 | 데이터 현황 | 활용 가능성 |
|------|------------|------------|------------|------------|
| 수업 태도 | "지각 1회" | `attendance` | ✅ 53건 | **Phase 2 즉시** |
| 이해도 | "주간테스트 72점" | `exam_scores` | ⚠️ 0건 | 데이터 축적 후 |
| 숙제 완료도 | "숙제 4/5 제출" | `submissions` | ⚠️ 0건 | 데이터 축적 후 |
| (추가) 진도 | "함수 3-2 완료" | `progress` | ✅ 109건 | **Phase 2 가능** |

### ✅ 결론: 조건부 수용

**수용 조건 (실제 DB 기반):**

| Phase | 자동첨부 가능 | 비고 |
|-------|--------------|------|
| **MVP** | 없음 | 강사 수동 입력 |
| **Phase 2** | 출결 + 진도 | `attendance` 53건, `progress` 109건 |
| **Phase 3** | 시험 + 숙제 | `exam_scores`, `submissions` 데이터 축적 후 |

**Phase 2 자동첨부 예시:**
- 수업 태도: "이번 주 출석 5/5, 지각 0회"
- 숙제/이해도: "이번 주 진도: 함수 단원 3-2 완료"

**이유:**
- `attendance` 테이블: 53건 데이터 존재 → **Phase 2에서 즉시 가능**
- `progress` 테이블: 109건 데이터 존재 → **Phase 2에서 추가 가능**
- `exam_scores` 테이블: 0건 (비어있음) → 데이터 축적 필요
- `submissions` 테이블: 0건 (숙제 제출 추적 없음) → 시스템 도입 필요

**MVP 구현안:**
```typescript
// 별점 아래에 선택적 근거 입력 (1줄 텍스트)
<input
  placeholder="근거: 숙제 4/5, 지각 1회 등 (선택)"
  className="text-xs text-gray-400"
/>
```

## 3. 코멘트 템플릿/문장 라이브러리

### 제안 분석

**UI:** 텍스트 입력 위에 칩(버튼) 배치

**칩 클릭 시:** 미리 정의된 문장 자동 삽입

### ✅ 결론: 수용

**칩 카테고리 (3개):**

#### 잘한 점 칩 (6개)
| 칩 라벨 | 삽입 문장 |
|---------|----------|
| 집중력 | 수업 집중력이 좋아졌습니다. |
| 적극성 | 질문과 발표에 적극적으로 참여했습니다. |
| 이해력 | 새로운 개념을 빠르게 이해했습니다. |
| 숙제성실 | 숙제를 빠짐없이 성실하게 완료했습니다. |
| 오답정리 | 오답 정리를 꼼꼼하게 했습니다. |
| 성장 | 이전 주 대비 눈에 띄게 성장했습니다. |

#### 개선할 점 칩 (8개)
| 칩 라벨 | 삽입 문장 |
|---------|----------|
| 계산실수 | 계산 실수 잦음 → 검산 루틴 연습 권장 |
| 개념적용 | 개념 이해는 되나 적용 연습 필요 |
| 숙제누락 | 숙제 누락 발생 → 제출 시간 고정 권장 |
| 집중저하 | 수업 초반 집중 약함 → 워밍업 필요 |
| 오답반복 | 같은 유형 오답 반복 → 오답노트 권장 |
| 풀이과정 | 풀이 과정 생략 많음 → 단계별 작성 연습 |
| 시간관리 | 문제 풀이 시간 관리 연습 필요 |
| 복습부족 | 이전 진도 복습 부족 → 주 1회 복습 권장 |

#### 학부모 전달사항 칩 (6개)
| 칩 라벨 | 삽입 문장 |
|---------|----------|
| 격려 | 꾸준히 노력하는 모습이 보기 좋습니다. 응원 부탁드립니다. |
| 복습권장 | 집에서 오늘 배운 내용 복습하면 더 효과적입니다. |
| 숙제확인 | 숙제 완료 여부 확인 부탁드립니다. |
| 컨디션 | 최근 컨디션이 좋지 않아 보입니다. 가정에서 관심 부탁드립니다. |
| 상담권장 | 학습 방향 상담을 권장드립니다. 편하신 시간에 연락 주세요. |
| 칭찬 | 이번 주 정말 잘했습니다! 가정에서 칭찬 부탁드립니다. |

**추가 기능: "학부모 톤 변환"**
- 개선할 점 입력 후 버튼 클릭 → 부드러운 말투로 자동 변환
- 예: "계산 실수 잦음" → "계산 정확도를 높이기 위해 검산 연습을 하면 좋겠습니다."

## 4. 학부모 민원 트리거 관리

### 제안 분석

**문제:** 낮은 점수(1-2점)만 주고 개선 계획 없으면 민원 폭증

**해결책:** 점수 2점 이하 시 "개선 계획" 필수 입력

### ✅ 결론: 수용

**구현 로직:**
```typescript
const hasLowScore =
  form.attitude_score <= 2 ||
  form.understanding_score <= 2 ||
  form.homework_completion_score <= 2;

const canSave = !hasLowScore || form.improvements.trim().length > 0;

if (!canSave) {
  toast.error('주의 항목이 있습니다. 개선 계획을 입력해주세요.');
  return;
}
```

**UI 표시:**
- 2점 이하 항목 옆에 ⚠️ 아이콘
- "개선할 점" 입력칸 테두리 주황색으로 강조
- 저장 버튼 클릭 시 미입력이면 안내 메시지

**추가 고려:**
- 2점 이하가 연속 2주면 "상담 권장" 자동 표시
- 관리자 대시보드에 "주의 학생" 리스트 표시

## 5. 별 3개 vs 5개 (강사용)

### 비교 분석

| 항목 | 5점제 | 3점제 |
|------|-------|-------|
| 데이터 정밀도 | 높음 | 낮음 |
| 입력 속도 | 보통 | 빠름 |
| 중간값 몰림 | 3점 몰림 | 2점(보통) 몰림 |
| 추세 분석 | 정밀 | 거친 |
| AI 활용 | 유리 | 불리 |

### ✅ 결론: 5점제 유지 (강사용)

**이유:**
1. 학부모에게는 3단계로 변환해서 보여주므로 민원 이슈 없음
2. 강사 데이터 정밀도 유지 → 추세 분석, 자동 알림 가능
3. 3점제의 "2점 몰림" 문제 회피
