**문서 번호**: 419
**작성일**: 2025-12-22
**Stage**: 신규 (운영 페이지 하위)
**목적**: 학년별 반배정 시험 관리 및 성적 분석 시스템 UX/UI 설계

---

## 1. 연구 배경

### 1.1 요구사항 요약

| 항목 | 내용 |
|------|------|
| **사용 빈도** | 학기별, 월별, 주별, 일별 (다양) |
| **동시 응시자** | 최대 50명 |
| **과목** | 국어, 영어, 수학 |
| **문항 수** | 5~30문항 |
| **문항 유형** | 객관식 + 주관식 혼합 |
| **오답 입력** | 선생님 직접 입력 |
| **반 분류** | 3~4개 (상/중/하 또는 A/B/C/D) |
| **반배정 기준** | 상황에 따라 다름 (점수 컷, 상위 %) |
| **시험지 업로드** | 스캔 이미지 또는 사진 (추후) |
| **풀이과정 공유** | 선생님만 확인 |
| **플랫폼** | PC 전용 (관리자 운영페이지) |

### 1.2 핵심 Use Case

```
1. 시험 생성 → 2. 문항 설정 → 3. 학생별 답안 입력 → 4. 자동 채점
       ↓                                                    ↓
5. 점수 확인 → 6. 순위 정렬 → 7. 반배정 기준 설정 → 8. 반배정 결과 확인
       ↓
9. (추후) 시험지 업로드 → 풀이과정 확인
```

## 2. 토스 스타일 디자인 철학 적용

### 2.1 핵심 원칙

| 원칙 | 시험 관리 적용 방법 |
|------|---------------------|
| **Simple Over Complex** | 한 화면에 하나의 작업만 집중 (시험 목록 → 성적 입력 → 결과 확인) |
| **White Space is King** | 넉넉한 여백, 테이블 밀도 낮추기 |
| **One Action Per Screen** | 단계별 워크플로우 (Stepper UI) |
| **Progressive Disclosure** | 기본 정보만 표시, 상세는 클릭 시 확장 |
| **Conversational UI** | "중1 12월 레벨테스트가 완료되었어요" |

### 2.2 컬러 시스템 (성적 특화)

| 용도 | 색상 | 코드 | 사용처 |
|------|------|------|--------|
| 상위권 (1반) | 토스 블루 | #3182F6 | A반 배지, 고득점 강조 |
| 중상위권 (2반) | 민트 | #00C9A7 | B반 배지 |
| 중위권 (3반) | 노랑 | #FFB800 | C반 배지 |
| 하위권 (4반) | 회색 | #8B95A1 | D반 배지 |
| 정답 | 초록 | #00C853 | 정답 표시 |
| 오답 | 빨강 | #F04452 | 오답 표시, 미제출 |
| 미응시 | 연회색 | #E5E8EB | 미응시 상태 |

### 4.1 성적 입력 효율화

| 기능 | 설명 | 구현 방법 |
|------|------|----------|

| **일괄 입력** | 전원 정답/전원 오답 버튼 | 버튼 클릭 시 전체 값 설정 |
| **복사 붙여넣기** | 엑셀에서 복사한 데이터 붙여넣기 | onPaste 이벤트 핸들링 |
| **미입력 강조** | 빈 셀 빨간 테두리 | 유효성 검사 + 스타일 |

### 5.1 Supabase 테이블 설계

```sql
-- 시험 기본 정보
CREATE TABLE exams (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,                    -- 시험명
  exam_date DATE NOT NULL,               -- 시험 일자
  subject TEXT NOT NULL,                 -- 과목 (math/english/korean)
  grade TEXT NOT NULL,                   -- 학년 (초1~고3)
  exam_type TEXT NOT NULL,               -- 시험 유형
  total_questions INTEGER NOT NULL,      -- 총 문항 수
  total_score INTEGER NOT NULL,          -- 총점
  status TEXT DEFAULT 'draft',           -- draft/scoring/completed
  created_at TIMESTAMPTZ DEFAULT NOW(),
  created_by UUID REFERENCES profiles(id)
);

-- 시험 문항 정보
CREATE TABLE exam_questions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  exam_id UUID REFERENCES exams(id) ON DELETE CASCADE,
  question_number INTEGER NOT NULL,      -- 문항 번호
  question_type TEXT NOT NULL,           -- objective/subjective
  score INTEGER NOT NULL,                -- 배점
  correct_answer TEXT,                   -- 정답 (null이면 수동 채점)
  UNIQUE(exam_id, question_number)
);

-- 학생별 답안
CREATE TABLE exam_answers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  exam_id UUID REFERENCES exams(id) ON DELETE CASCADE,
  student_id UUID REFERENCES students(id),
  question_number INTEGER NOT NULL,
  answer TEXT,                           -- 학생 답안
  score INTEGER,                         -- 획득 점수
  is_correct BOOLEAN,                    -- 정오 여부
  UNIQUE(exam_id, student_id, question_number)
);

-- 학생별 총점 (계산된 뷰 또는 테이블)
CREATE TABLE exam_results (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  exam_id UUID REFERENCES exams(id) ON DELETE CASCADE,
  student_id UUID REFERENCES students(id),
  total_score INTEGER NOT NULL,          -- 총점
  rank INTEGER,                          -- 순위
  assigned_class TEXT,                   -- 배정된 반
  exam_paper_url TEXT,                   -- 시험지 이미지 URL
  teacher_note TEXT,                     -- 선생님 메모
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(exam_id, student_id)
);

-- 반배정 기준 저장
CREATE TABLE exam_class_criteria (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  exam_id UUID REFERENCES exams(id) ON DELETE CASCADE,
  class_count INTEGER NOT NULL,          -- 반 개수 (3 or 4)
  criteria_type TEXT NOT NULL,           -- score_cut/percentage/count
  criteria_json JSONB NOT NULL           -- 상세 기준
);
```

  grade: string;
  exam_type: ExamType;
  total_questions: number;
  total_score: number;

}

export interface ExamQuestion {
  id: string;
  exam_id: string;
  question_number: number;
  question_type: QuestionType;
  score: number;
  correct_answer: string | null;
}

export interface ExamAnswer {
  id: string;
  exam_id: string;
  student_id: string;
  question_number: number;

// 시험 생성
export function useCreateExam() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: examApi.create,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['exams'] });
    }
  });
}

// 답안 입력
export function useSaveAnswers() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: examApi.saveAnswers,
    onSuccess: (_, { examId }) => {
      queryClient.invalidateQueries({ queryKey: ['exam', examId] });
    }
  });
}

// 자동 채점
export function useAutoGrade(examId: string) {
  return useMutation({
    mutationFn: () => examApi.autoGrade(examId)
  });

## 10. 핵심 UX 요약

### 10.1 토스 스타일 적용 포인트

1. **깔끔한 카드 UI**: 시험 목록을 카드형으로 표시, 핵심 정보만 노출
2. **단계별 생성 플로우**: Stepper UI로 복잡한 시험 생성을 3단계로 분리
3. **진행률 시각화**: 성적 입력 진행률을 프로그레스 바로 명확히 표시
4. **드래그 앤 드롭**: 반배정 시 직관적인 학생 이동
5. **키보드 최적화**: 대량 데이터 입력 시 마우스 없이 빠르게 진행
6. **상태 명확화**: 완료/진행중/미완료를 아이콘과 색상으로 구분

### 10.2 학원 현장 최적화

1. **빠른 입력**: 키보드만으로 50명 답안 입력 가능
2. **유연한 반배정**: 점수 컷, 비율, 인원수 3가지 방식 지원
3. **수동 조정**: 자동 배정 후 드래그로 세부 조정 가능
4. **오답 분석**: 문항별 오답률로 수업 개선 포인트 파악
5. **시험지 보관**: 풀이 과정 이미지 첨부로 나중에 확인 가능
