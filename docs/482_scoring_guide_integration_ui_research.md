# Stage 58 채점 기준 통합 UI 연구

> 작성일: 2026-01-08
> 목적: WeeklyReportModal에 채점 기준 가이드 통합 방안 분석

---

## 1. 사용자 제안 요약

| 항목 | 내용 |
|------|------|
| 변경 사항 | 참여도(participation) 항목 제거 → 3개 항목만 |
| 모바일 UI | ⓘ 버튼 → 탭 시 기준 표시 (툴팁/바텀시트) |
| 태블릿 UI | 채점 기준 상시 표시 (사이드 패널 또는 인라인) |

**최종 평가 항목 (3개):**
1. 수업 태도 (attitude_score)
2. 이해도 (understanding_score)
3. 숙제 완료도 (homework_completion_score)

---

## 2. 장점 분석

### 2.1 UX 개선
- **학습 곡선 감소**: 신규 강사도 채점 기준 즉시 확인 가능
- **일관성 향상**: 모든 강사가 동일한 기준 참조 → 점수 편차 감소
- **작업 효율**: 별도 문서/가이드북 없이 모달 내에서 완결

### 2.2 디바이스별 최적화
- **모바일**: 화면 공간 절약 (ⓘ 버튼으로 필요시만 표시)
- **태블릿**: 넓은 화면 활용 (상시 표시로 빠른 참조)

### 2.3 유지보수
- 채점 기준 변경 시 한 곳만 수정
- 별도 PDF/문서 배포 불필요

---

## 3. 우려 사항 및 분석

### 3.1 🟡 모바일 화면 공간 (중간 우려)

**문제:**
- 바텀시트 모달 높이 제한 (~70vh)
- 3개 평가 항목 + 3개 텍스트 입력 + 저장 버튼 이미 빡빡함
- ⓘ 버튼 탭 시 추가 UI 필요

**해결책:**
```
Option A: 인라인 툴팁 (추천)
- ⓘ 탭 → 해당 항목 아래에 기준 펼침 (아코디언)
- 다른 항목 탭 → 기존 접힘, 새 항목 펼침
- 장점: 컨텍스트 유지, 스크롤 최소화

Option B: 오버레이 툴팁
- ⓘ 탭 → 팝오버로 기준 표시
- 장점: 레이아웃 변경 없음
- 단점: 터치 영역 작음, 실수로 닫힐 수 있음

Option C: 별도 바텀시트
- ⓘ 탭 → 새 바텀시트로 기준 전체 표시
- 장점: 충분한 공간
- 단점: 컨텍스트 전환, 2중 바텀시트 복잡
```

**권장: Option A (인라인 아코디언)**

---

### 3.2 🟢 태블릿 레이아웃 (낮은 우려)

**문제:**
- 상시 표시 시 폼 영역 축소
- 기준 패널이 너무 길면 스크롤 필요

**해결책:**
```

│ 김민지 주간 리포트                                    [×] │
├────────────────────────────────────────────────────────────┤
│ ┌─────────────────────┐ ┌────────────────────────────────┐ │
│ │ ⭐ 평가 항목        │ │ 📋 채점 기준                   │ │
│ │                     │ │                                │ │
│ │ 수업 태도  ★★★★☆ │ │ [수업 태도]                    │ │
│ │ 이해도     ★★★☆☆ │ │ 5점: 수업 전 미리 준비...     │ │
│ │ 숙제완료   ★★★★★ │ │ 4점: 시간 내 준비...          │ │
│ │                     │ │ 3점: 약간 늦게 준비...        │ │
│ ├─────────────────────┤ │ 2점: 자주 늦음...             │ │
│ │ ✏️ 상세 평가        │ │ 1점: 수업 방해...             │ │
│ │                     │ │                                │ │
│ │ 잘한 점             │ │ [이해도]                       │ │
│ │ ┌─────────────────┐ │ │ 5점: 응용 문제까지...         │ │
│ │ │                 │ │ │ ...                            │ │
│ │ └─────────────────┘ │ │                                │ │
│ │                     │ │ [숙제 완료도]                  │ │
│ │ 개선할 점           │ │ 5점: 100% 완료 + 오답정리...  │ │
│ │ ┌─────────────────┐ │ │ ...                            │ │
│ │ │                 │ │ │                                │ │
│ │ └─────────────────┘ │ └────────────────────────────────┘ │
│ │                     │                                    │
│ │ [     저장하기     ]│                                    │
│ └─────────────────────┘                                    │
└────────────────────────────────────────────────────────────┘
```

**구현 방식:**
- 태블릿: `flex-row` (폼 60% + 기준 40%)
- 기준 패널 내부 스크롤 (`overflow-y: auto`)
- 현재 선택된 항목 기준 하이라이트

---

### 3.3 🟡 정보 과부하 (중간 우려)

**문제:**
- 모든 기준을 한 번에 보여주면 강사가 압도당할 수 있음
- 특히 첫 사용 시

**해결책:**
1. **모바일**: 기본적으로 기준 숨김, ⓘ 탭 시만 표시
2. **태블릿**: 현재 포커스된 항목의 기준만 상세 표시, 나머지는 축약
3. **점진적 공개**: 첫 사용자에게만 "기준 보기" 토글 안내 툴팁

---

### 3.4 🟢 개발 복잡도 (낮은 우려)

**추가 작업:**
- `ScoringGuide.tsx` 컴포넌트 (50줄)
- `useIsMobile` 훅 활용
- 반응형 분기 (`md:` 브레이크포인트)

**복잡도 증가 최소화:**
```typescript
// WeeklyReportModal.tsx 내부
const isMobile = useIsMobile();

return (
  <div className={isMobile ? 'flex-col' : 'flex-row'}>
    <ReportForm ... />
    {!isMobile && <ScoringGuide activeField={focusedField} />}
  </div>
);
```

## 4. 최종 권장안

### 4.1 ✅ 수용 (조건부)

**조건:**
1. 모바일은 **인라인 아코디언** 방식 (Option A)
2. 기준 텍스트는 **간결하게 축약** (전체 가이드의 50% 수준)
3. 태블릿 기준 패널은 **스크롤 가능**, 현재 항목 하이라이트

### 4.2 구현 상세

**모바일 (< 768px):**
```
┌─────────────────────────────────┐
│ 수업 태도            ⓘ   ★★★★☆ │
├─────────────────────────────────┤  ← ⓘ 탭 시 펼침
│ 5점: 수업 전 준비, 필기 완벽    │
│ 4점: 시간 내 준비, 필기 꼼꼼    │
│ 3점: 약간 늦음, 기본 필기       │
│ 2점: 자주 늦음, 필기 불량       │
│ 1점: 수업 방해                   │
└─────────────────────────────────┘
```

**태블릿 (≥ 768px):**
- 2컬럼 레이아웃 (폼 60% + 기준 40%)
- 기준 패널 상시 표시
- 현재 포커스 항목 하이라이트 (배경색 변경)

### 4.3 축약된 채점 기준 (모바일용)

| 항목 | 5점 | 4점 | 3점 | 2점 | 1점 |
|------|-----|-----|-----|-----|-----|
| 수업 태도 | 미리 준비, 완벽 필기 | 시간 내 준비 | 약간 늦음 | 자주 늦음 | 수업 방해 |
| 이해도 | 응용까지 해결 | 기본 정확 | 설명 후 이해 | 반복 설명 필요 | 기초 모름 |
| 숙제 완료 | 100%+오답정리 | 90%+ | 70-90% | 50-70% | 50% 미만 |
