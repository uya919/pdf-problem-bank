# 필터 레이아웃 공백 최적화 UX 연구 리포트

> 작성일: 2025-12-17
> 상태: 분석 완료

---

## 1. 문제 정의

### 1.1 사용자 피드백
> "지금 3~4줄을 사용하면서 공백이 많이 생기는것"

### 1.2 현재 구현 (4줄 레이아웃)

```
┌──────────────────────────────────────────────────────────────────────┐
│ 학부   [전체] [초등부] [중등부] [고등부]          ← 오른쪽 공백 많음  │
│ 학년   [전체] [중1] [중2] [중3]                   ← 오른쪽 공백 많음  │
│ 과목   [전체] [수학] [국어] [영어] [과학]         ← 오른쪽 공백 많음  │
│ 검색   🔍 [학생 이름 검색...___________________]  ← flex-1 전체 차지  │
└──────────────────────────────────────────────────────────────────────┘
```

**문제점:**
- 각 줄의 토글 버튼이 왼쪽에 몰려있고 오른쪽은 빈 공간
- 4줄 × 약 48px = **192px** 세로 공간 차지
- 테이블 영역이 그만큼 줄어듦
- 정보 밀도가 낮음

## 2. 공백 발생 원인 분석

### 2.1 현재 CSS 구조

```tsx
<div className="flex items-center gap-3">
  <span className="w-12">학부</span>      // 48px 고정
  <div className="flex gap-1 p-1 bg-grey-100 rounded-lg">
    [버튼들...]                           // 내용만큼만 차지
  </div>
  // ← 나머지 공간이 빈 공백
</div>
```

### 2.2 각 줄의 실제 너비

| 필터 | 버튼 개수 | 예상 너비 | 남는 공백 (1200px 기준) |
|------|-----------|-----------|-------------------------|
| 학부 | 4개 | ~280px | ~870px (72%) |
| 학년 | 4개 | ~200px | ~950px (79%) |
| 과목 | 5개 | ~320px | ~830px (69%) |
| 검색 | 1개 | flex-1 | 0px (검색이 전체 차지) |

**평균 72%의 공간이 낭비되고 있음**

## 3. 해결 방안 분석

### 3.1 Option A: 2줄 레이아웃 (학부+학년 / 과목+검색)

```
┌──────────────────────────────────────────────────────────────────────┐
│ 학부 [전체][초][중][고]   학년 [전체][중1][중2][중3]                  │
│ 과목 [전체][수][국][영][과]   검색 🔍[이름...]  재원20|휴원2  [정렬▼] │
└──────────────────────────────────────────────────────────────────────┘
```

**장점:**
- 4줄 → 2줄 (50% 감소)
- 세로 공간 절약
- 테이블 영역 확대

**단점:**
- 학년 필터가 항상 표시됨 (학부 선택 전에도)
- 한 줄이 복잡해 보일 수 있음

**UX 평가:** ⭐⭐⭐ (3/5)
- 기능적 그룹핑이 약함

---

### 3.2 Option B: 계층적 2줄 (학부→학년 동적 / 과목+검색)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [전체] [초등부] [중등부▾ 중1 중2 중3] [고등부]     ← 드롭다운 확장    │
│ 과목 [전체][수학][국어][영어][과학]   🔍[...]  재원20  [정렬▼]        │
└──────────────────────────────────────────────────────────────────────┘
```

**장점:**
- 학부 선택 시 학년이 인라인 드롭다운으로 표시
- 공간 효율 극대화 (2줄)

**단점:**
- 드롭다운 UX가 토글보다 클릭 수 많음
- 구현 복잡도 높음

**UX 평가:** ⭐⭐⭐ (3/5)

---

### 3.3 Option C: 같은 줄에 여러 필터 그룹 (권장)

```
┌──────────────────────────────────────────────────────────────────────┐
│ 학부 [전체][초등부][중등부][고등부]    과목 [전체][수학][국어][영어][과학] │
│ 학년 [전체][중1][중2][중3]           검색 🔍[이름...]  재원20  [정렬▼]    │
└──────────────────────────────────────────────────────────────────────┘
```

**또는 학년이 없을 때:**

```
┌──────────────────────────────────────────────────────────────────────┐
│ 학부 [전체][초등부][중등부][고등부]    과목 [전체][수학][국어][영어][과학] │
│ 검색 🔍[이름...]           재원 20 | 휴원 2 | 졸업 2        [이름순 ▼]   │
└──────────────────────────────────────────────────────────────────────┘
```

**장점:**
- 관련 필터끼리 같은 줄에 배치 (학부+과목 = 데이터 필터)
- 검색+상태+정렬 = 조회 도구
- 2~3줄로 축소
- 공백 최소화

**단점:**
- 줄이 길어 보일 수 있음 (PC에서는 OK)

**UX 평가:** ⭐⭐⭐⭐ (4/5)

### 3.4 Option D: Flex Wrap + Gap (자동 줄바꿈)

```tsx
<div className="flex flex-wrap items-center gap-4">
  <div>학부 [토글들]</div>
  <div>과목 [토글들]</div>
  <div>학년 [토글들]</div>  // 학부 선택 시만
  <div>검색 [입력]</div>
  <div>상태 [카운트]</div>
  <div>정렬 [드롭다운]</div>
</div>
```

```
PC (넓은 화면):
┌──────────────────────────────────────────────────────────────────────┐
│ 학부[...] 과목[...] 학년[...] 검색[...] 재원20 휴원2 졸업2 [정렬▼]    │
└──────────────────────────────────────────────────────────────────────┘

태블릿 (좁은 화면):
┌────────────────────────────────────────┐
│ 학부[...] 과목[...]                     │
│ 학년[...] 검색[...]                     │
│ 재원20 휴원2 졸업2 [정렬▼]              │
└────────────────────────────────────────┘
```

**장점:**
- 반응형 자동 조절
- 화면 너비에 따라 최적 배치
- 공백 자동 최소화

**단점:**
- 레이아웃이 화면마다 달라짐
- 예측 가능성 낮음

**UX 평가:** ⭐⭐⭐ (3/5)

---

### 3.5 Option E: 컴팩트 칩 스타일 (토스 패턴)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [🏫 중등부 ▼] [📚 수학 ▼] [🔍 검색...]    재원20 휴원2 졸업2  [정렬▼] │
└──────────────────────────────────────────────────────────────────────┘
```

**장점:**
- 1줄로 모든 필터 표현
- 드롭다운으로 세부 선택
- 매우 컴팩트

**단점:**
- 현재 선택 상태가 한눈에 안 보임
- 드롭다운 열어야 옵션 확인
- 토글의 "한눈에" 장점 상실

**UX 평가:** ⭐⭐ (2/5)
- 토글 UX 철학과 충돌

---

### 3.6 Option F: 라벨 제거 + 구분선 (권장)

```
┌──────────────────────────────────────────────────────────────────────┐
│ [전체][초등부][중등부][고등부]  │  [전체][수학][국어][영어][과학]      │
│ [전체][중1][중2][중3]          │  🔍[이름...]  재원20 휴원2  [정렬▼]  │
└──────────────────────────────────────────────────────────────────────┘
```

**장점:**
- 라벨("학부", "과목") 제거로 공간 절약
- 구분선(|)으로 그룹 구분
- 토글 자체가 라벨 역할 (전체/초등부 → 학부임을 암시)
- 2줄로 압축

**단점:**
- 첫 사용자는 각 그룹이 뭔지 헷갈릴 수 있음
- 아이콘이나 툴팁 필요할 수 있음

**UX 평가:** ⭐⭐⭐⭐ (4/5)

## 8. 결론

### 핵심 변경사항

1. **학부 + 과목을 같은 줄에 배치** (라벨 제거, 구분선 사용)
2. **학년은 학부 아래 들여쓰기로 표시** (계층 관계 표현)
3. **검색 줄에 상태 카운트 + 정렬 추가** (공간 활용)
4. **선택 스타일 변경**: 검정 → 흰색 + 그림자

### 기대 효과

- 세로 공간 **25~50% 절약**
- 테이블 영역 확대
- 정보 밀도 향상
- 공백 최소화
