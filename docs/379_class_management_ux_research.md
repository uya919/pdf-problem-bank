## 1. 요구사항 분석

### 1.1 핵심 기능
- **반 목록 조회**: 학원의 모든 반 리스트
- **수업시간 관리**: 요일/시간 설정
- **담당 강사 배정**: 각 반에 강사 지정
- **반 추가/수정/삭제**: CRUD 기능

### 1.2 데이터 구조
```typescript
interface Class {
  id: string;
  name: string;           // "중1A반", "고2수학심화"
  subject: string;        // "math", "korean", "english", "science"
  grade_id: string;       // 학년 (grades 테이블 참조)
  teacher_id?: string;    // 담당 강사 (profiles 테이블 참조)
  schedule: Schedule[];   // 수업 시간표
  capacity: number;       // 정원
  current_students: number;
  is_active: boolean;
}

interface Schedule {
  day: number;            // 0=월, 1=화, ..., 6=일
  start_time: string;     // "16:00"
  end_time: string;       // "17:30"
}
```

## 2. UX/UI 벤치마크 분석

### 2.1 토스 디자인 원칙 적용

| 원칙 | 적용 방법 |
|------|----------|
| **단순함** | 핵심 정보만 테이블에 표시, 상세는 모달로 |
| **명확함** | 과목별 컬러 코딩으로 구분 |

**클래스팅/클래스123**

**구글 클래스룸**

## 4. 시간표 UI 옵션

### 4.1 옵션 A: 드롭다운 방식 (권장)

```
요일: [월 v]  시작: [16:00 v]  종료: [17:30 v]  [추가]

선택된 시간:
┌──────────────────────────────────────────────┐
│ 월요일 16:00~17:30                      [✕] │
│ 수요일 16:00~17:30                      [✕] │
└──────────────────────────────────────────────┘
```

**장점**:
- 구현 간단
- 모바일 친화적
- 직관적

### 4.2 옵션 B: 주간 시간표 그리드

```
     월   화   수   목   금   토   일
09                           ██
10                           ██
...
16   ██       ██
17   ██       ██
18
```

**장점**:
- 시각적으로 일목요연
- 시간 충돌 확인 용이

**단점**:
- 구현 복잡
- 터치 인터페이스에서 불편

### 4.3 최종 선택: **옵션 A (드롭다운)**

이유:
1. 기존 UI 패턴과 일관성
2. 빠른 구현 가능
3. 모바일/PC 모두 적합

## 10. Supabase 스키마 확인

### 10.1 필요 테이블

```sql
-- classes 테이블 (기존 존재 확인 필요)
CREATE TABLE classes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  subject_id UUID REFERENCES subjects(id),
  grade_id UUID REFERENCES grades(id),
  teacher_id UUID REFERENCES profiles(id),
  capacity INTEGER DEFAULT 8,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT now(),
  updated_at TIMESTAMP DEFAULT now()
);

-- class_schedules 테이블
CREATE TABLE class_schedules (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  class_id UUID REFERENCES classes(id) ON DELETE CASCADE,
  day_of_week INTEGER NOT NULL, -- 0=월, 6=일
  start_time TIME NOT NULL,
  end_time TIME NOT NULL
);
```

### 10.2 RLS 정책

```sql
-- 모든 인증 사용자 조회 가능
CREATE POLICY "Authenticated users can view classes"
  ON classes FOR SELECT
  USING (auth.role() = 'authenticated');

-- admin/owner만 수정 가능
CREATE POLICY "Admins can manage classes"
  ON classes FOR ALL
  USING (
    public.get_user_role(auth.uid()) IN ('admin', 'owner')
  );
```
