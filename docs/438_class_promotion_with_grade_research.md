## 1. 요청 사항

학생 학년 승급 시 등록된 반(class)도 함께 승급시키는 기능

**예시:**
- 중1 심화반 학생 → 중2 심화반으로 자동 이동
- 초6 심화반 학생 → 중1 심화반으로 자동 이동
- 자동 매칭이 어려운 학생 → 반 해제 후 수동 재배정

## 2. 현재 시스템 분석

### 2.1 관련 테이블 구조

```
students
├── id (UUID)
├── name
├── grade_id (FK → grades)
└── is_active

enrollments (학생-반 연결)
├── id (UUID)
├── student_id (FK → students)
├── class_id (FK → classes)
├── is_active
└── enrolled_at

classes
├── id (UUID)
├── name (예: "중1 심화반", "초6A반")
├── grade_id (FK → grades)
└── is_active

grades
├── id (UUID)
├── name (예: "중1", "초6", "고3")
└── sort_order
```

### 2.2 현재 학년 승급 로직
- `grade_promotion.py`에서 학생의 `grade_id`만 변경
- 반(class) 정보는 변경하지 않음
- 결과: 학년은 올라가지만 반은 그대로 → 데이터 불일치

## 3. 구현 가능성 분석

### 3.1 핵심 로직

```python
# 의사 코드
def promote_student_class(student, old_grade, new_grade):
    # 1. 현재 학생의 반 조회
    current_enrollment = get_enrollment(student_id)
    current_class = get_class(current_enrollment.class_id)

    # 2. 반 이름에서 학년 추출
    # "중1 심화반" → "심화반"
    class_suffix = extract_class_suffix(current_class.name)

    # 3. 새 학년에 맞는 반 찾기
    # "중2" + "심화반" → "중2 심화반"
    new_class_name = f"{new_grade} {class_suffix}"
    new_class = find_class_by_name(new_class_name)

    # 4-A. 새 반이 존재하면 이동
    if new_class:
        update_enrollment(student_id, new_class.id)
        return "자동 이동"

    # 4-B. 새 반이 없으면 반 해제
    else:
        deactivate_enrollment(student_id)
        return "반 해제 (수동 배정 필요)"
```

### 3.2 반 이름 패턴 분석

| 패턴 | 예시 | 추출 방식 |
|------|------|-----------|
| `{학년} {반명}` | 중1 심화반, 초6 A반 | 공백 기준 분리 |
| `{학년}{반명}` | 중1A, 고2B | 학년 prefix 제거 |
| `{반명} {학년}` | 심화반 중1 | 학년 suffix 제거 |
| 커스텀 | 올림피아드반, 특목반 | 학년 정보 없음 |

**권장 패턴**: `{학년} {반명}` (예: "중1 심화반")

### 2.3 현재 DB 반 이름 패턴 분석

실제 데이터 조회 결과:

| 반 이름 | 학년 | 패턴 분석 |
|---------|------|-----------|
| 중1 수학 기초 | 중1 | `{학년} {과목} {레벨}` |
| 중1 수학 심화 | 중1 | `{학년} {과목} {레벨}` |
| 중1 수학 정규 | 중1 | `{학년} {과목} {레벨}` |
| 중2 수학 기초 | 중2 | `{학년} {과목} {레벨}` |
| 중2 수학 심화 | 중2 | `{학년} {과목} {레벨}` |
| 초5 영어 H반 | 초5 | `{학년} {과목} {반명}` |
| 고1 수학 정규1 | 고1 | `{학년} {과목} {레벨}{번호}` |

**분석 결과:**
- ✅ **일관된 패턴**: `{학년} {과목} {레벨}` 형태로 통일됨
- ✅ **자동 매칭 가능**: "중1 수학 심화" → "중2 수학 심화" 변환 용이
- ⚠️ **일부 예외**: "고1 수학 정규1", "고1 수학 정규2" 같은 번호 붙은 반
- ⚠️ **grade_id null**: 일부 반(고1~고2 일부)에 grade_id가 설정되지 않음

### 3.3 구현 복잡도

| 항목 | 난이도 | 설명 |
|------|--------|------|
| 반 이름 파싱 | 중 | 정규식으로 학년/반명 분리 |
| 새 반 매칭 | 중 | 동일 반명 + 새 학년 조합 |
| 반 해제 처리 | 하 | enrollment.is_active = false |
| 미리보기 UI | 중 | 자동/수동 배정 미리 표시 |
| 롤백 지원 | 상 | enrollment 변경 이력 저장 |

## 4. 우려되는 점

### 4.1 반 이름 일관성 문제

**문제**: 반 이름 규칙이 통일되어 있지 않으면 자동 매칭 실패

```
현재 반: "중1심화"
예상 반: "중2심화"
실제 반: "중2 심화반"  ← 이름 불일치로 매칭 실패
```

**해결책**:
1. 반 이름 규칙 표준화 (마이그레이션)
2. 또는 classes 테이블에 `class_type` 컬럼 추가 (예: "심화", "기본", "특강")

### 4.2 정원 초과 문제

**문제**: 새 반의 정원이 이미 가득 찼을 경우

```
중2 심화반 정원: 8명
현재 등록: 7명
승급 대상: 5명 → 12명이 되어 정원 초과
```

**해결책**:
1. 정원 초과 학생은 자동으로 "반 해제" 처리
2. 미리보기에서 정원 현황 표시
3. 또는 경고 후 관리자가 정원 조정

### 4.3 초등→중등 전환

**문제**: 학부가 바뀌면서 반 구조가 완전히 달라짐

```
초6 심화반 → 중1 심화반
- 초등부는 담임/부담임 시스템
- 중등부는 담당 강사 시스템
- 과목도 다를 수 있음 (초등 수학 vs 중등 수학)
```

**해결책**:
- 학부 전환(초→중, 중→고) 시에는 무조건 "반 해제" 처리
- 관리자가 수동 배정

### 4.4 다중 반 등록

**문제**: 한 학생이 여러 반에 등록된 경우

```
김철수 학생:
- 중1 수학 심화반
- 중1 영어 기초반
- 중1 특강반
```

**해결책**:
- 모든 등록된 반에 대해 승급 로직 적용
- 각 반별로 자동/수동 판정

### 4.5 반 없는 학년 문제

**문제**: 특정 학년에만 존재하는 반

```
"초6 올림피아드반" 존재
"중1 올림피아드반" 미존재 → 자동 해제
```

**해결책**:
- 미리보기에서 명확하게 표시
- "새 반 자동 생성" 옵션 제공 (선택적)

## 5. 사용자 확인 결과

### Q1. 학부 전환 처리
> **답변: 자동 이동** - 같은 이름의 반이 있으면 자동 이동 (초6 수학 심화 → 중1 수학 심화)

### Q2. 정원 초과 시 처리
> **답변: 정원 무시** - 일단 이동 후 관리자가 조정

### Q3. 다중 반 등록
> **답변: 모든 반 승급** - 과목별 반이므로 모든 등록된 반에 대해 승급 시도

### Q4. 매칭 안 되는 반
> **답변: 반 해제** - 수동 배정 필요로 표시

### Q5. 번호 붙은 반 (정규1, 정규2)
> **답변: 반 해제** - 어떤 번호로 갈지 알 수 없으므로 수동 배정

### 6.1 미리보기 화면 확장

```

│  학년 승급 미리보기                                          │
├─────────────────────────────────────────────────────────────┤
│  ✅ 자동 반 이동: 45명                                       │
│  ⚠️ 수동 배정 필요: 8명                                      │
│  🎓 졸업 (고3): 12명                                         │
├─────────────────────────────────────────────────────────────┤
│  이름    │ 현재 학년 │ 현재 반      │ → │ 새 학년 │ 새 반        │
│─────────┼──────────┼─────────────┼───┼────────┼─────────────│
│  김철수  │ 중1      │ 중1 심화반   │ ✅ │ 중2    │ 중2 심화반   │
│  박영희  │ 초6      │ 초6 A반     │ ⚠️ │ 중1    │ (수동 배정)  │
│  이민수  │ 고3      │ 고3 심화반   │ 🎓 │ -      │ 졸업        │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 처리 규칙

| 조건 | 처리 | 상태 |
|------|------|------|
| 동일 반명 + 새 학년 반 존재 + 정원 여유 | 자동 이동 | ✅ |
| 동일 반명 + 새 학년 반 존재 + 정원 초과 | 반 해제 | ⚠️ |
| 동일 반명 + 새 학년 반 미존재 | 반 해제 | ⚠️ |
| 학부 전환 (초→중, 중→고) | 반 해제 | ⚠️ |
| 고3 (졸업) | 반 해제 + 비활성화 | 🎓 |
