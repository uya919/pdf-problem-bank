# PC 관리자 대시보드 - 캘린더 전체 디자인 대안 연구리포트

> Stage 13 캘린더 UI 전체 리디자인 연구

---

## 1. 문제 정의

### 1.1 현재 상황
- Stage 13에서 v5 토스 UX 철학 기반 PC 주간 캘린더 구현 완료
- **사용자 피드백**: "캘린더 전체 디자인이 마음에 들지 않음"
- 선택 상태 스타일만이 아닌 **캘린더 전체 디자인**에 대한 불만족

### 1.2 현재 디자인 분석

**현재 WeeklyCalendar 특징:**
```
┌─────────────────────────────────────────────────────────────┐
│ ← 12월 3주 →                                          오늘  │  ← 헤더
├───────┬───────┬───────┬───────┬───────┬───────┬───────────┤
│월   16│화   17│수   18│목   19│금   20│토   21│일      22│  ← 날짜 셀
│       │공지   │       │오늘   │공지   │       │          │
│       │       │       │공지   │       │       │          │
└───────┴───────┴───────┴───────┴───────┴───────┴──────────┘
```

| 요소 | 현재 값 | 문제점 |
|------|---------|--------|
| 컨테이너 | `rounded-2xl border border-grey-200` | 평범함 |
| 셀 높이 | `min-h-[88px]` | 정보가 적어 보임 |
| 헤더 스타일 | 좌측 화살표+텍스트+화살표 | 심플하지만 밋밋 |
| 날짜 표시 | 좌측 상단 요일, 우측 상단 숫자 | 표준적 |
| 공지 표시 | 텍스트 2줄 | PC인데 정보 부족 |

## 2. 현재 대시보드 디자인 시스템 분석

### 2.1 전체 레이아웃

**AdminDashboard 구성:**
1. **상단 네비게이션**: 로고 + 메뉴탭 + 과목필터 + 프로필
2. **주간 캘린더** ← 리디자인 대상
3. **KPI 지표 바**: 4열 그리드, 카드 스타일
4. **현재 진행 중 섹션**: rounded-2xl 카드
5. **오늘 할 일 바**: grey-100 배경 뱃지들
6. **오늘 수업 일정**: 타임라인 스타일

### 2.2 사용 중인 디자인 토큰

| 요소 | 토큰 |
|------|------|
| 카드 배경 | `bg-white` |
| 카드 테두리 | `border border-grey-200` |
| 카드 둥글기 | `rounded-2xl` (16px) |
| 강조 배경 | `bg-blue-50`, `bg-orange-50` |
| 텍스트 컬러 | grey-900, grey-600, grey-400 |
| 강조 컬러 | blue-500, orange-500, green-500 |
| 그림자 | 거의 없음 (border 기반) |
| 간격 | `space-y-5`, `gap-4` |

### 2.3 디자인 특징

1. **플랫 디자인**: 그림자 최소화, border로 구분
2. **토스 컬러 팔레트**: grey 계열 + 파란색 강조
3. **라운드 코너**: rounded-xl ~ rounded-2xl
4. **여백 중심**: 넉넉한 패딩 (p-4, p-5)
5. **카드 기반 레이아웃**: 각 섹션이 독립된 카드

## 3. 캘린더 디자인 대안 연구

### 3.1 Option A: 미니멀 라인 캘린더 (Notion 스타일)

**컨셉**: 극도의 단순화, 선으로만 구분

```
12월 3주                                              ← 오늘

 월        화        수        목        금        토        일
─────────────────────────────────────────────────────────────
 16       17       18       19       20       21       22
          공지             ● 오늘    휴원      특강
                          결석
```

**특징:**
- 테두리 없음, 수평선만
- 오늘은 작은 점(●)으로 표시
- 폰트 위계로 구분
- 매우 가벼운 느낌

**장점:**
- 극도로 깔끔
- 정보 밀도 낮음 → 시원함
- Notion, Linear 등 프로덕티비티 툴 느낌

**단점:**
- 클릭 영역 불명확
- 너무 단조로울 수 있음

---

### 3.2 Option B: 카드 그리드 캘린더 (Apple Calendar 스타일)

**컨셉**: 각 날짜가 독립된 카드, 그림자와 호버 효과

```
┌─── 12월 3주 ──────────────────────────────────── 오늘 ───┐
│                                                          │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │
│  │ 월  16 │ │ 화  17 │ │ 수  18 │ │ 목  19 │ │ 금  20 │ │
│  │        │ │ 📄교재 │ │        │ │ ⚠결석  │ │ 🔴휴원 │ │
│  │        │ │        │ │        │ │ 📅상담 │ │        │ │
│  └────────┘ └────────┘ └────────┘ └────────┘ └────────┘ │
│  ┌────────┐ ┌────────┐                                  │
│  │ 토  21 │ │ 일  22 │  ← 주말은 별도 행 또는 옅은 색   │
│  │ 특강   │ │ 휴원   │                                  │
│  └────────┘ └────────┘                                  │
└──────────────────────────────────────────────────────────┘
```

**특징:**
- 각 셀에 미세한 그림자 (`shadow-sm`)
- 호버 시 그림자 강화 (`shadow-md`)
- 셀 간 gap으로 구분 (border 대신)
- 둥근 모서리 각 셀에 적용

**장점:**
- 각 날짜가 명확히 구분됨
- 호버/클릭 피드백 자연스러움
- 현대적이고 깔끔한 느낌

**단점:**
- 그림자가 많아지면 무거워 보임
- 기존 대시보드의 플랫한 느낌과 다름

---

### 3.3 Option C: 풀 블리드 헤더 캘린더 (Google Calendar 스타일)

**컨셉**: 요일 헤더가 강조된 구조

```
┌──────────────────────────────────────────────────────────┐
│       ◀  12월 3주  ▶                              오늘   │
├──────┬──────┬──────┬──────┬──────┬──────┬──────────────┤
│  월  │  화  │  수  │  목  │  금  │  토  │      일      │ ← 요일 헤더 (bg-grey-50)
├──────┼──────┼──────┼──────┼──────┼──────┼──────────────┤
│  16  │  17  │  18  │  19  │  20  │  21  │      22      │ ← 날짜
│      │공지  │      │오늘  │휴원  │특강  │              │ ← 공지
│      │      │      │결석  │      │      │              │
└──────┴──────┴──────┴──────┴──────┴──────┴──────────────┘
```

**특징:**
- 요일 행이 별도 배경색 (bg-grey-50)
- 날짜가 셀 상단 중앙에 크게
- 공지가 아래에 표시
- 그리드 라인 명확

**장점:**
- 요일 파악 쉬움
- 전통적인 캘린더 느낌
- 정보 구조 명확

**단점:**
- 다소 구식으로 보일 수 있음
- 토스 스타일과 거리감

---

### 3.4 Option D: 컴팩트 타임라인 캘린더 (Linear 스타일)

**컨셉**: 가로 타임라인 형태, 좌측에 날짜

```
┌──────────────────────────────────────────────────────────┐
│ ◀ 12월 3주 ▶                                      오늘   │
├──────────────────────────────────────────────────────────┤
│                                                          │
│ 월 16  ─────────────────────────────────────────────────│
│                                                          │
│ 화 17  ─────────────────────────────────────  📄 교재변경│
│                                                          │
│ 수 18  ─────────────────────────────────────────────────│
│                                                          │
│ 목 19  ●━━━━━━━━━━━━━━━━━━━━━━━  ⚠ 결석2명 │ 📅 상담    │ ← 오늘 강조
│                                                          │
│ 금 20  ─────────────────────────────────────  🔴 휴원    │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**특징:**
- 세로로 날짜 나열 (가로 스크롤 없음)
- 각 날짜 행에 공지 표시
- 오늘은 굵은 선 + 강조 배경
- 매우 컴팩트한 높이

**장점:**
- 세로 공간 효율적
- 공지가 날짜와 같은 행에 표시
- 스캔하기 쉬움

**단점:**
- 전통적인 캘린더 느낌 없음
- 주간 전체 조망 어려움

### 3.5 Option E: 확장형 정보 캘린더 (Asana 스타일)

**컨셉**: PC 화면 활용, 더 많은 정보 표시

```
┌──────────────────────────────────────────────────────────────────────┐
│ ◀ 12월 3주 ▶                                                   오늘 │
├─────────────┬─────────────┬─────────────┬─────────────┬─────────────┤
│ 월          │ 화          │ 수          │ 목 (오늘)   │ 금          │
│ 16          │ 17          │ 18          │ 19          │ 20          │
│─────────────│─────────────│─────────────│─────────────│─────────────│
│             │ 📄 교재변경 │             │ ⚠ 결석 2명 │ 🔴 휴원     │
│             │    안내     │             │ 📅 상담예정│             │
│             │             │             │    14:00   │             │
│             │             │             │ 📝 중3A    │             │
│             │             │             │    진도미입│             │
├─────────────┴─────────────┴─────────────┴─────────────┴─────────────┤
│ 토 21                      │ 일 22                                   │
│ 특강 09:00                │ 휴원                                    │
└──────────────────────────────────────────────────────────────────────┘
```

**특징:**
- 셀 높이 증가 (140px 이상)
- 여러 줄의 공지 표시 가능
- 평일 5칸, 주말 2칸 (5:2 비율)
- 상세 정보 직접 표시

**장점:**
- PC 화면 최대 활용
- 클릭 없이 정보 파악
- 정보 밀도 높음

**단점:**
- 공간 많이 차지
- 공지 없는 날은 허전함

### 3.6 Option F: 스트라이프 캘린더 (Stripe Dashboard 스타일)

**컨셉**: 스트라이프 대시보드처럼 미니멀 + 데이터 중심

```
┌──────────────────────────────────────────────────────────┐
│ 12월 3주                                           오늘 →│
│──────────────────────────────────────────────────────────│
│ 월 16    화 17    수 18    목 19    금 20    토 21  일 22│

│                            결석     휴원     특강       │
└──────────────────────────────────────────────────────────┘
```

**특징:**
- 한 줄에 모든 날짜
- 공지 개수를 숫자로 표시
- 호버 시 상세 내용 표시 (Progressive Disclosure)
- 매우 컴팩트

**장점:**
- 대시보드에서 최소 공간 차지
- 한눈에 주간 전체 조망
- 클릭 시 상세 모달/패널

**단점:**
- 정보가 너무 압축됨
- 공지 내용 즉시 확인 불가

## 5. 추가 고려사항

### 5.1 색상 개선 제안

| 요소 | 현재 | 개선안 |
|------|------|--------|
| 오늘 배경 | `bg-blue-50` | `bg-blue-500/10` (더 은은) |
| 오늘 텍스트 | `text-blue-600` | `text-blue-600 font-bold` |
| 주말 텍스트 | `text-red-400` | `text-grey-400` (덜 강조) |
| 셀 구분선 | `border-grey-100` | 제거 또는 `border-grey-50` |

### 5.2 높이 옵션

| 옵션 | 셀 높이 | 용도 |
|------|---------|------|
| Compact | 48px | 공지 숫자만 표시 |
| Normal | 88px (현재) | 공지 2줄 |
| Large | 120px | 공지 3-4줄 |
| Full | 160px+ | 상세 정보 |

### 5.3 애니메이션

| 요소 | 제안 |
|------|------|
| 호버 | `transition-all duration-150` + 미세 scale |
| 선택 | `transition-colors duration-100` |
| 주 이동 | slide 애니메이션 |
