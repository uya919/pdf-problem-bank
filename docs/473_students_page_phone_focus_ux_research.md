# 학생 페이지 연락처 중심 UX 리디자인 연구

> Stage: 연구 리포트
> 작성일: 2025-01-05
> 목적: 강사용 앱 학생 페이지를 연락처 중심으로 재설계

---

## 1. 현재 상태 분석

### 1.1 현재 UI 구조 (StudentsPage.tsx)

```
┌─────────────────────────────────────┐
│ [검색바] [필터: 전체▼]              │
├─────────────────────────────────────┤
│ ┌─────────────────────────────────┐ │
│ │ 👤 홍길동    중2A               │ │
│ │    ↑ 5점 상승                   │ 85 │
│ │                          최근시험 │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 👤 김철수    고1B               │ │
│ │    ⚠️ 3회 연속 결석              │ 72 │
│ │                          최근시험 │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

### 1.2 현재 UI의 문제점

| 문제 | 설명 | 영향 |
|------|------|------|
| **연락처 접근성 부족** | 전화번호가 상세 화면에서만 표시 | 긴급 연락 시 3-4번 탭 필요 |
| **점수 중심 설계** | 최근 시험 점수가 가장 눈에 띄는 위치 | 실제 사용 빈도와 불일치 |
| **정보 우선순위 오류** | 트렌드(↑↓)가 연락처보다 상위 | 강사의 실제 니즈 미반영 |
| **빠른 액션 부재** | 전화 걸기가 숨겨져 있음 | 학부모 소통 지연 |

### 1.3 강사의 실제 사용 패턴 분석

**빈도순 액션**:
1. 🔴 **학부모에게 전화** - 결석/지각 알림, 상담 요청 (매일 다수)
2. 🔴 **학생에게 전화** - 숙제 독촉, 수업 리마인드 (매일)
3. 🟡 **출결 확인** - 오늘 누가 왔는지 (수업 전)
4. 🟢 **성적 확인** - 시험 후 분석 (주 1-2회)

> 💡 **핵심 인사이트**: 가장 자주 하는 액션(전화)이 가장 접근하기 어려움

## 2. 토스 UX 철학 적용

### 2.1 토스의 핵심 원칙

| 원칙 | 설명 | 적용 방안 |
|------|------|----------|
| **즉시성** | 원하는 것을 바로 할 수 있어야 함 | 전화 버튼 1탭 접근 |
| **단순성** | 한 화면에 하나의 목적 | 연락처 목록 = 전화하기 목적 |
| **계층화** | 중요한 정보만 먼저 | 이름+전화번호만 기본 노출 |
| **점진적 공개** | 필요할 때 상세 정보 | 점수/출결은 모달로 이동 |

### 2.2 토스 스타일 정보 계층

```
1순위 (항상 보임): 이름, 학년/반
2순위 (바로 접근): 📞 학생전화, 📞 학부모전화
3순위 (탭 시 모달): 성적, 출결, 숙제, 메모
```

### 2.3 토스 컬러 시스템

```css
/* Primary */

--toss-gray-100: #F2F4F6;

```

## 3. 새로운 UI 설계

### 3.1 모바일 (핸드폰)

**핵심 목표**: 한 손으로 빠르게 전화 걸기

```
┌─────────────────────────────────────┐
│ 학생 목록                      [검색] │
│ 총 24명                              │
├─────────────────────────────────────┤
│                                      │
│ ┌─────────────────────────────────┐ │
│ │ 👤 홍길동                        │ │
│ │    중2 · A반                     │ │
│ │                                  │ │
│ │  ┌──────────┐  ┌──────────┐    │ │
│ │  │ 📱 학생   │  │ 📞 학부모  │    │ │
│ │  │ 010-1234 │  │ 010-5678 │    │ │
│ │  └──────────┘  └──────────┘    │ │
│ └─────────────────────────────────┘ │
│                                      │
│ ┌─────────────────────────────────┐ │
│ │ 👤 김철수        ⚠️ 결석 3회     │ │
│ │    고1 · B반                     │ │
│ │                                  │ │
│ │  ┌──────────┐  ┌──────────┐    │ │
│ │  │ 📱 학생   │  │ 📞 학부모  │    │ │
│ │  │ 010-2345 │  │ 010-6789 │    │ │
│ │  └──────────┘  └──────────┘    │ │
│ └─────────────────────────────────┘ │
│                                      │
└─────────────────────────────────────┘
```

**모바일 특징**:
- 전화번호 버튼이 카드 내 바로 노출
- 탭 한 번으로 전화 앱 실행 (`tel:` 링크)
- 알림 뱃지(결석 등)는 이름 옆에 작게 표시
- 카드 전체 탭 → 상세 모달 열림
- 전화 버튼 탭 → 바로 전화

### 3.2 태블릿/PC

**핵심 목표**: 한눈에 여러 학생 연락처 파악 + 효율적 관리

```
┌────────────────────────────────────────────────────────────────┐
│ 학생 목록                                                       │
│ 총 24명 · 중등 12명 · 고등 12명                                  │
├────────────────────────────────────────────────────────────────┤
│ [🔍 학생 검색...]  [전체 ▼] [학년 ▼] [정렬: 이름순 ▼]          │
├────────────────────────────────────────────────────────────────┤
│                                                                 │
│  이름         학년/반     학생 연락처      학부모 연락처    상태  │
│ ─────────────────────────────────────────────────────────────── │
│  홍길동       중2 A반    📱 010-1234-5678  📞 010-9876-5432   ●  │
│  김철수       고1 B반    📱 010-2345-6789  📞 010-8765-4321  ⚠️  │
│  이영희       중3 A반    📱 010-3456-7890  📞 010-7654-3210   ●  │
│  박지민       고2 C반    📱 010-4567-8901  📞 010-6543-2109   ●  │
│  최수진       중1 B반    📱 010-5678-9012  📞 010-5432-1098  ⚠️  │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
```

**테이블 특징**:
- 전화번호 열이 별도로 존재
- 클릭 시 바로 복사 또는 전화 (데스크톱에서는 복사 우선)
- 호버 시 전화 아이콘 활성화
- 상태 열: ● 정상, ⚠️ 주의 필요
- 행 클릭 → 오른쪽에 상세 패널 또는 모달

## 5. 인터랙션 설계

### 5.1 모바일 제스처

| 액션 | 동작 | 결과 |
|------|------|------|
| 전화 버튼 탭 | 터치 | `tel:010-xxxx-xxxx` 실행 |
| 카드 탭 | 터치 (버튼 외 영역) | 상세 모달 열림 |
| 길게 누르기 | 500ms 홀드 | 빠른 액션 메뉴 (복사/문자/카톡) |
| 아래로 당기기 | Pull to refresh | 목록 새로고침 |

### 5.2 태블릿/PC 인터랙션

| 액션 | 동작 | 결과 |
|------|------|------|
| 전화번호 클릭 | 클릭 | 클립보드 복사 + 토스트 |
| 전화번호 호버 | 마우스오버 | 📞 아이콘 + "클릭하여 복사" |
| 행 클릭 | 클릭 | 상세 모달 열림 |
| 행 더블클릭 | 더블클릭 | (선택) 편집 모드 |

### 5.3 토스트 메시지

```
✓ 전화번호가 복사되었습니다
✓ 홍길동 학부모 (010-1234-5678)
```

## 6. 접근성 고려사항

### 6.1 시각적 접근성

- 전화 아이콘 크기: 최소 44x44px (터치 영역)
- 색상 대비: WCAG AA 기준 충족
- 폰트 크기: 전화번호 최소 16px

### 6.2 운동 접근성

- 버튼 간격: 최소 8px
- 길게 누르기 대안: 점 세 개(...) 메뉴 제공

## 7. 데이터 구조

### 7.1 필요한 필드

```typescript
interface StudentListItem {
  id: string;
  name: string;
  grade: string;        // "중2", "고1"
  className: string;    // "A반", "B반"

  // 1순위: 연락처
  studentPhone: string | null;
  parentPhone: string | null;

  // 2순위: 상태 뱃지용
  hasAlert: boolean;
  alertType?: 'absence' | 'homework' | 'score';
  alertMessage?: string;
}

interface StudentDetail extends StudentListItem {
  // 모달에서 표시
  recentScores: { score: number; date: string }[];
  attendanceThisMonth: {
    present: number;
    late: number;
    absent: number;
  };
  homeworkRate: number;  // 0-100
  notes: string;
}
```

## 10. 결론

현재 학생 페이지는 **성적 중심**으로 설계되어 있으나, 강사의 실제 사용 패턴은 **연락처 중심**입니다.

토스의 UX 철학에 따라:
1. **가장 자주 하는 액션(전화)을 가장 쉽게** 만들고
2. **덜 자주 보는 정보(성적)는 모달로 이동**시키면
3. 강사의 업무 효율이 크게 향상될 것으로 예상됩니다.
