# 학생 관리 테이블 & 필터 선택 상태 UX 연구 리포트

> 작성일: 2025-12-17
> 상태: 분석 완료

---

## 1. 문제 정의

### 1.1 사용자 피드백
> "학생이름 필드가 너무 커"
> "학생 필드 옆의 공간을 활용할 방법은 없을까?"
> "검은색으로 학부와 과목에서 선택된 것을 나타내는건 별로야"

### 1.2 현재 구현 문제점

**테이블 레이아웃:**
```
┌─────────────────┬──────────┬────────────────┬─────┬─────┐
│ 학생            │학년/학교 │ 수강 과목      │상태 │액션 │
├─────────────────┼──────────┼────────────────┼─────┼─────┤
│ (아바타) 김민준 │ 중1      │ 수 심화 국 정규│ 재원│ 상세│
│          010-xxx│ 혜윰중   │                │     │     │
└─────────────────┴──────────┴────────────────┴─────┴─────┘
     넓음 (~200px)   좁음       넓음           좁음  좁음
```

**문제:**
- 학생 컬럼에 아바타(40px) + 이름 + 전화번호 → 공간 낭비
- 학년/학교 컬럼은 정보 밀도 낮음
- 상태 컬럼도 좁은 뱃지 하나만 표시

**필터 선택 상태:**
```
현재: [전체] [초등부] [중등부] [고등부]
       ↑
       bg-grey-900 text-white (검은색)
```

**문제:**
- 검은색은 "비활성화/무거움" 느낌
- 토스/애플 디자인에서 검은색은 보통 텍스트에만 사용
- 선택 상태는 브랜드 컬러나 밝은 색상으로 표현하는 것이 일반적

## 2. 테이블 레이아웃 개선 방안

### 2.1 Option A: 컬럼 통합 (학생 + 학년/학교)

```
┌──────────────────────────────┬────────────────┬─────┬─────┐
│ 학생 정보                    │ 수강 과목      │상태 │액션 │
├──────────────────────────────┼────────────────┼─────┼─────┤
│ (아바타) 김민준  중1·혜윰중  │ 수 심화 국 정규│ 재원│ 상세│
│          010-1234-5678       │                │     │     │
└──────────────────────────────┴────────────────┴─────┴─────┘
```

**장점:**
- 한 줄에 핵심 정보(이름+학년+학교) 표시
- 컬럼 수 감소로 시각적 단순화
- 아바타 옆 공간 활용

**구현:**
```tsx
<td className="px-5 py-4">
  <div className="flex items-center gap-3">
    <div className="w-10 h-10 rounded-full bg-grey-200...">
      {student.name?.charAt(0)}
    </div>
    <div>
      <div className="flex items-center gap-2">
        <span className="font-semibold text-grey-900">{student.name}</span>
        <span className="text-sm text-grey-500">{grade}·{school}</span>
      </div>
      <div className="text-sm text-grey-500">{student.phone || '-'}</div>
    </div>
  </div>
</td>
```

---

### 2.2 Option B: 2줄 컴팩트 레이아웃

```
┌────────────────────────────────────────────────────┬─────┐
│ 김민준                           수 심화 국 정규   │ 상세│
│ 중1·혜윰중 · 010-1234-5678       재원             │     │
└────────────────────────────────────────────────────┴─────┘
```

**장점:**
- 아바타 제거로 더 많은 정보 표시
- 수평 공간 최대 활용
- 모바일 친화적

**단점:**
- 시각적 식별 요소(아바타) 제거
- 테이블 형식 벗어남

---

### 2.3 Option C: 아바타 축소 + 인라인 정보 (권장)

```
┌──────────────────────────────────┬────────────────┬─────┐
│ 학생                             │ 수강 과목      │액션 │
├──────────────────────────────────┼────────────────┼─────┤
│ (32px) 김민준 · 중1 · 혜윰중     │ 수 심화 국 정규│ 상세│
│        010-1234-5678   [재원]    │                │     │
└──────────────────────────────────┴────────────────┴─────┘
```

**변경사항:**
- 아바타: 40px → 32px
- 이름 옆에 학년·학교 인라인 표시
- 상태 뱃지를 학생 컬럼 내부로 이동
- 컬럼 3개로 축소: 학생 | 수강 과목 | 액션

**장점:**
- 가장 컴팩트한 구조
- 핵심 정보가 한눈에 보임
- 컬럼 수 최소화

---

### 2.4 Option D: 학년·학교를 뱃지 형태로

```
┌────────────────────────────────────┬────────────────┬─────┐
│ 학생                               │ 수강 과목      │액션 │
├────────────────────────────────────┼────────────────┼─────┤
│ 김민준  [중1] [혜윰중]  [재원]     │ 수 심화 국 정규│ 상세│
│ 010-1234-5678                      │                │     │
└────────────────────────────────────┴────────────────┴─────┘
```

**장점:**
- 구조화된 정보 표시
- 빠른 스캔 가능

**단점:**
- 뱃지가 많아지면 시각적 노이즈

## 3. 필터 선택 상태 색상 개선

### 3.1 현재 문제 분석

```
현재: bg-grey-900 text-white (검은색 배경)
```

| 문제 | 설명 |
|------|------|
| **무거운 느낌** | 검은색은 시각적으로 무겁고 딱딱함 |
| **브랜드 불일치** | 토스/애플은 검은색을 선택 상태로 거의 사용 안함 |
| **과목과 충돌** | 과목별 컬러(파랑/초록/보라/주황)와 어울리지 않음 |

### 3.2 토스/애플 선택 상태 색상 패턴

**토스:**
- 선택됨: `bg-blue-500 text-white` (브랜드 블루)
- 미선택: `bg-grey-100 text-grey-600`

**애플:**
- 선택됨: `bg-blue-500 text-white` (시스템 블루)
- 미선택: `bg-grey-200 text-grey-800`

**Segment Control 패턴:**
- 선택됨: `bg-white shadow-sm` (흰색 + 그림자)
- 미선택: 투명

---

### 3.3 Option A: 브랜드 블루 (권장)

```
선택됨:   bg-blue-500 text-white
미선택:   bg-transparent text-grey-600 hover:bg-grey-200
```

```
학부  [━━전체━━] [초등부] [중등부] [고등부]
              ↑ 파란색 배경
```

**장점:**
- 토스/애플 패턴과 일치
- 밝고 활기찬 느낌
- 선택 상태 명확

---

### 3.4 Option B: 흰색 카드 + 그림자 (iOS Segment)

```
선택됨:   bg-white shadow-sm text-grey-900
미선택:   bg-transparent text-grey-600
컨테이너: bg-grey-100 rounded-lg p-1
```

```
┌─────────────────────────────────────────┐
│ [  전체  ] [초등부] [중등부] [고등부]   │
│   ↑                                     │
│   흰색 카드 + 그림자                    │
└─────────────────────────────────────────┘
```

**장점:**
- iOS 네이티브 느낌
- 가장 세련된 디자인
- 어떤 컬러와도 어울림

---

### 3.5 Option C: 밑줄 강조 (Underline Tab)

```
선택됨:   text-blue-500 border-b-2 border-blue-500
미선택:   text-grey-500
```

```
학부   전체    초등부    중등부    고등부
       ━━━━
       ↑ 파란 밑줄
```

**장점:**
- 공간 효율적
- 탭 네비게이션 패턴

**단점:**
- 현재 토글 스타일과 불일치

---

### 3.6 Option D: 연한 파랑 배경 (Soft Blue)

```
선택됨:   bg-blue-50 text-blue-600 ring-1 ring-blue-200
미선택:   bg-transparent text-grey-600 hover:bg-grey-100
```

```
학부  [  전체  ] [초등부] [중등부] [고등부]
        ↑ 연한 파란 배경 + 테두리
```

**장점:**
- 부드러운 느낌
- 시각적 강조 적당함
- 다른 요소와 조화

## 4. 권장 구현

### 4.1 테이블: Option C (아바타 축소 + 인라인)

```tsx
// StudentRow 변경
<tr className="hover:bg-grey-50 cursor-pointer" onClick={onClick}>
  <td className="px-5 py-3">
    <div className="flex items-center gap-3">
      {/* 아바타 축소 */}
      <div className="w-8 h-8 rounded-full bg-grey-200 flex items-center justify-center text-grey-600 text-sm font-medium flex-shrink-0">
        {student.name?.charAt(0) || '?'}
      </div>
      <div className="min-w-0">
        {/* 이름 + 학년 + 학교 인라인 */}
        <div className="flex items-center gap-2 flex-wrap">
          <span className="font-semibold text-grey-900">{student.name}</span>
          <span className="text-sm text-grey-400">·</span>
          <span className="text-sm text-grey-500">{grade}</span>
          <span className="text-sm text-grey-400">·</span>
          <span className="text-sm text-grey-500">{school}</span>
          {/* 상태 뱃지 인라인 */}
          <span className={`px-2 py-0.5 text-xs font-medium rounded ${statusColor}`}>
            {statusLabel}
          </span>
        </div>
        <div className="text-sm text-grey-400">{student.phone || '-'}</div>
      </div>
    </div>
  </td>
  <td className="px-5 py-3">
    <SubjectBadges subjectEnrollments={subjectEnrollments} />
  </td>
  <td className="px-5 py-3 text-center">
    <button className="...">상세</button>
  </td>
</tr>
```

### 4.2 필터: Option B (흰색 카드 + 그림자)

```tsx
// 필터 토글 버튼 스타일 변경
<button
  className={`px-4 py-2 rounded-md text-sm font-medium transition-all ${
    isSelected
      ? 'bg-white shadow-sm text-grey-900'  // 선택됨: 흰색 + 그림자
      : 'text-grey-600 hover:bg-grey-200'   // 미선택
  }`}
>
  {label}
</button>
```
