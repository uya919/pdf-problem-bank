**문서 번호**: 408

---

## 1. 요구사항 분석

### 1.1 사용자 요청

> "과목별로 한 타임에 일반적으로 3개, 최대 4개. 카드뷰로 보고싶어"

```
14:00     중3심화    중3정규     중3기초
          지난진도   지난진도    지난진도
          지난숙제   지난숙제    지난숙제
          진도       진도        진도
          숙제       숙제        숙제
          메모       메모        메모
```

### 1.2 핵심 포인트

| 항목 | 내용 |
|------|------|
| **과목 분리** | 수학/영어/국어 각각 별도 대시보드 |
| **카드 수** | 시간대당 3~4개 (최대 4개) |
| **표시 정보** | 지난진도, 지난숙제, 오늘진도, 오늘숙제, 메모 |
| **캘린더 유지** | 현재 WeeklyCalendar 디자인 그대로 사용 |

## 2. 현재 캘린더 디자인 분석

### 2.1 WeeklyCalendar 특징

```
┌───────────────────────────────────────────────────────────────────┐
│  ◀  12월 16일 ~ 12월 22일  ▶                            [오늘]  │
├─────────┬─────────┬─────────┬─────────┬─────────┬─────────┬─────────┤
│   월    │   화    │   수    │   목    │   금    │   토    │   일    │
│   16    │   17    │   18    │   19    │  (20)   │   21    │   22    │
│         │         │         │         │  ●오늘  │         │         │
│         │ 🟣순환  │         │ 🟣순환  │         │         │         │
└─────────┴─────────┴─────────┴─────────┴─────────┴─────────┴─────────┘
```

**디자인 요소**:
- `rounded-3xl` 둥근 모서리
- `gap-2` 셀 간격 (border 없음)
- 오늘: 파란 원형 배경 + pulse 애니메이션
- 선택: `ring-2 ring-toss-blue`
- 공지/순환수업: 뱃지 스타일

### 2.2 적용할 디자인 원칙

1. **둥근 카드**: `rounded-2xl` ~ `rounded-3xl`
2. **Gap 기반 구분**: border 대신 gap으로 분리
3. **Active 피드백**: `active:scale-[0.98]`
4. **호버 효과**: `hover:bg-grey-50`
5. **색상 체계**: toss-blue, grey 톤

## 4. 정보 표시 규칙

### 4.1 지난 진도/숙제

| 항목 | 표시 형식 | 예시 |
|------|----------|------|
| 진도 (페이지) | p.시작-끝 주제 | p.42-45 이차함수 |
| 진도 (단원) | N과 주제 | 3과 현대시 |
| 숙제 완료율 | N/M 완료 | 4/5 완료 |
| 숙제 상세 | 범위 | p.42 1~10번 |

### 4.2 오늘 진도/숙제

| 상태 | 표시 |
|------|------|
| 입력됨 | 실제 내용 |
| 미입력 | "미정" (grey-400) |
| 수업 전 | "예정" (grey-400) |

### 4.3 메모 (특이사항)

- **최대 1줄** 표시 (ellipsis)
- 없으면 영역 숨김
- 예시:
  - "홍길동 숙제 미제출"
  - "보충수업 예정"
  - "학부모 상담 예정"

## 7. 데이터 요구사항

### 7.1 ClassCard 데이터 타입

```typescript
interface ClassCardData {
  id: string;
  name: string;              // "중3 심화"
  teacher: string;           // "김선생"
  studentCount: number;      // 5

  // 지난 수업
  lastProgress: {
    date: string;            // "2025-12-18"
    content: string;         // "p.42-45 이차함수"
  } | null;

  lastHomework: {
    description: string;     // "p.42 1~10번"
    submitted: number;       // 4
    total: number;           // 5
    notSubmitted: string[];  // ["홍길동"]
  } | null;

  // 오늘 수업
  todayProgress: {
    content: string;         // "p.46-50 최댓값"
  } | null;

  todayHomework: {
    description: string;     // "p.46 1~5번"
  } | null;

  // 메모
  note: string | null;       // "보충수업 예정"

  // 상태
  status: 'normal' | 'warning' | 'error' | 'current';
}
```

### 7.2 API 쿼리

```typescript
// 지난 수업 진도 (해당 반의 가장 최근)
const { data: lastProgress } = await supabase
  .from('progress')
  .select('date, textbook, start_page, end_page, topic')
  .eq('class_id', classId)
  .lt('date', today)
  .order('date', { ascending: false })
  .limit(1);

// 지난 숙제 제출 현황
const { data: lastHomework } = await supabase
  .from('homework')
  .select(`
    id, description, page_range,
    submissions(status, student:students(name))
  `)
  .eq('class_id', classId)
  .lt('due_date', today)
  .order('due_date', { ascending: false })
  .limit(1);
```
