## 2. 현재 구현 vs 목업 비교 분석

### 2.1 구조적 차이

| 요소 | v5 목업 | 현재 구현 | 차이점 |
|------|---------|----------|--------|
| **컨테이너** | `rounded-2xl` | `rounded-2xl` | 동일 |
| **헤더 높이** | `py-3` (약 48px) | `py-3` | 동일 |
| **셀 높이** | `min-h-[88px]` | `min-h-[88px]` | 동일 |
| **그리드** | 7열 고정 | 7열 고정 | 동일 |

### 2.2 시각적 차이 (핵심 이슈)

#### A. 날짜 표시 방식
| 항목 | v5 목업 | 현재 구현 | 문제점 |
|------|---------|----------|--------|
| 요일 위치 | 좌측 상단 | 좌측 상단 | - |
| 날짜 위치 | 우측 상단 | 우측 상단 | - |
| 날짜 크기 | `text-base` (16px) | `text-base` | 동일 |
| **요일 폰트** | `text-xs text-grey-400` | `text-xs text-grey-400` | 동일 |

#### B. 공지사항 표시
| 항목 | v5 목업 | 현재 구현 | 문제점 |
|------|---------|----------|--------|
| 최대 표시 개수 | 2개 | 2개 | 동일 |
| 초과 표시 | 없음 | `+N개 더` | **목업에 없는 요소 추가됨** |
| warning 아이콘 | `⚠` 이모지 | `⚠ ` 공백 포함 | 동일 |
| 텍스트 truncate | O | O | 동일 |

#### C. 상태별 스타일
| 상태 | v5 목업 | 현재 구현 | 문제점 |
|------|---------|----------|--------|
| 오늘 | `bg-blue-50` | `bg-blue-50` | 동일 |
| **선택됨** | 없음 (hover만) | `bg-grey-100` | **목업에 없는 상태** |
| 주말 hover | `bg-red-50/50` | `bg-red-50/50` | 동일 |
| 평일 hover | `bg-grey-50` | `bg-grey-50` | 동일 |

### 2.3 디자인 차이 분석

**가장 큰 차이점:**

1. **선택 상태 추가**: v5 목업에는 날짜 "선택" 개념이 없음 (hover만 있음)
   - 현재 구현은 `isSelected` 상태로 `bg-grey-100` 배경 적용
   - 날짜 클릭 시 해당 날짜 데이터를 필터링하는 기능이 추가되어 있음

2. **+N개 더 표시**: 목업에 없는 요소
   - 3개 이상 공지가 있을 때 표시
   - 정보 과잉으로 보일 수 있음

3. **테두리/그림자**:
   - 목업: 셀 간 `border-r border-grey-100`만 있음
   - 현재: 동일하지만 실제 렌더링 시 미묘한 차이 가능

## 3. 디자인 개선 방향 연구

### 3.1 옵션 A: 목업과 100% 일치하도록 수정

**변경 사항:**
- 선택 상태(`isSelected`) 시각적 표현 제거 또는 최소화
- "+N개 더" 표시 제거
- hover 효과만 유지

**장점:**
- 목업과 완벽 일치
- 시각적 단순함

**단점:**
- 날짜 선택 기능이 있다면 시각적 피드백 부재
- 공지 수 파악 어려움

### 3.2 옵션 B: 토스 스타일 선택 상태 개선

**변경 사항:**
```css
/* 현재: bg-grey-100 (너무 강한 배경) */
/* 개선: 미세한 테두리 또는 그림자 */

선택됨 {
  box-shadow: inset 0 0 0 2px #3182F6; /* 토스 블루 테두리 */
  background: transparent; /* 배경 제거 */
}

/* 또는 */
선택됨 {
  border-bottom: 2px solid #3182F6; /* 하단 액센트 */
}
```

**장점:**
- 선택 상태가 명확하면서도 깔끔
- 토스의 "최소한의 강조" 철학 준수

**단점:**
- 목업과 약간 다름

### 3.3 옵션 C: 전체적인 비율 및 여백 조정

**분석:** 캘린더가 "답답해 보이는" 이유가 있다면:

| 요소 | 현재 | 개선안 |
|------|------|--------|
| 셀 패딩 | `p-3` (12px) | `p-4` (16px) 또는 `px-4 py-3` |
| 셀 높이 | `min-h-[88px]` | `min-h-[100px]` 또는 `min-h-[96px]` |
| 공지 간격 | `space-y-1` (4px) | `space-y-1.5` (6px) |
| 날짜 숫자 크기 | `text-base` | `text-lg` |

### 3.4 옵션 D: 컬러 및 대비 조정

**문제 가능성:** 색상 대비가 약해서 밋밋해 보일 수 있음

| 요소 | 현재 | 개선안 |
|------|------|--------|
| 요일 색상 | `text-grey-400` | `text-grey-500` (더 진하게) |
| 날짜 색상 | `text-grey-600` | `text-grey-700` (더 진하게) |
| 오늘 배경 | `bg-blue-50` | `bg-blue-100` (더 강조) |
| 오늘 날짜 | `text-blue-600` | `text-blue-700 font-bold` |

## 4. UX 베스트 프랙티스 연구

### 4.1 토스 캘린더 UX 특징

1. **극단적 단순화**: 불필요한 요소 제거
2. **호버 피드백**: 클릭 전 미리 반응
3. **색상 절제**: 강조색은 1-2개만
4. **애니메이션**: 미세한 전환 효과

### 4.2 Apple 캘린더 스타일

1. **둥근 선택 표시**: 선택된 날짜에 원형 배경
2. **오늘 강조**: 빨간색 원 또는 강한 배경
3. **이벤트 점 표시**: 날짜 아래 작은 점

### 4.3 Google Calendar 스타일

1. **요일 헤더 분리**: 날짜 그리드와 요일 헤더 분리
2. **선택 시 테두리**: 파란 테두리로 선택 표시
3. **시간대 표시**: 시간 정보 포함

## 5. 구체적 개선 제안

### 5.1 우선순위 높음 (시각적 영향 큼)

#### 제안 1: 선택 상태 스타일 개선
```tsx
// 현재
const stateStyles = isSelected ? 'bg-grey-100' : ...

// 개선안 A: 테두리 방식 (토스 스타일)
const stateStyles = isSelected
  ? 'ring-2 ring-inset ring-blue-500 bg-white'
  : ...

// 개선안 B: 배경 + 미세 그림자 (Apple 스타일)
const stateStyles = isSelected
  ? 'bg-blue-50 shadow-sm'
  : ...
```

#### 제안 2: "+N개 더" 표시 제거
```tsx
// 현재: 3개 이상 공지 시 "+N개 더" 표시
// 개선: 제거하여 목업과 일치
{/* +N개 더 제거 */}
```

### 5.2 우선순위 중간 (미세 조정)

#### 제안 3: 오늘 날짜 강조 강화
```tsx
// 현재
<span className="text-[10px] text-blue-500 font-medium">오늘</span>

// 개선: 배지 스타일
<span className="text-[10px] px-1.5 py-0.5 bg-blue-500 text-white rounded-full font-medium">
  오늘
</span>
```

#### 제안 4: 여백 및 높이 증가
```tsx
// 현재
const baseStyles = `p-3 ... min-h-[88px]`

// 개선
const baseStyles = `p-4 ... min-h-[100px]`
```

### 5.3 우선순위 낮음 (선택적)

#### 제안 5: 호버 애니메이션 추가
```tsx
// 현재: transition-colors만
// 개선: scale 효과 추가
className="... transition-all hover:scale-[1.02]"
```

#### 제안 6: 공지사항 아이콘 개선
```tsx
// 현재: ⚠ 이모지
// 개선: SVG 아이콘 또는 컬러 점으로 대체
<span className="w-1.5 h-1.5 rounded-full bg-orange-500 mr-1.5" />
```

## 6. 권장 개선 방안

### 6.1 Phase 1: 즉시 적용 (목업 일치)

1. **선택 상태 스타일 변경**: `bg-grey-100` → `ring-2 ring-inset ring-blue-400`
2. **"+N개 더" 제거**: 목업과 일치
3. 예상 작업량: 30분

### 6.2 Phase 2: 추가 개선 (선택적)

1. **오늘 배지 스타일**: 텍스트 → 라운드 배지
2. **여백 조정**: 셀 패딩 및 높이 증가
3. **호버 피드백 강화**: 미세 스케일 효과
4. 예상 작업량: 1시간
