---

## 1. 토스 디자인 철학 분석

### 1.1 토스의 핵심 디자인 원칙

| 원칙 | 설명 | 적용 방법 |
|------|------|----------|
| **Simple Over Complex** | 복잡함을 숨기고 단순함을 보여줌 | 정보 계층화, Progressive Disclosure |
| **White Space is King** | 여백이 곧 고급스러움 | 넉넉한 패딩, 섹션 간 충분한 간격 |
| **One Action Per Screen** | 한 화면에서 하나의 핵심 행동 | 가장 중요한 정보만 강조 |
| **Motion with Purpose** | 의미 있는 애니메이션 | 상태 변화를 부드럽게 표현 |
| **Conversational UI** | 대화하듯 자연스러운 문구 | "오늘 수업이 5개 있어요" |

### 1.2 토스 PC 버전 특징 (토스증권, 토스페이먼츠 참고)

```

├────────────┬────────────────────────────────────────────────────┤
│            │                                                    │
│  사이드바   │              메인 컨텐츠 영역                       │
│  (좁은 폭)  │              (넓은 여백)                           │
│            │                                                    │
│  · 대시보드 │    ┌─────────────────────────────────────────┐    │
│  · 반 관리  │    │                                         │    │
│  · 학생관리 │    │      핵심 정보 카드                       │    │
│  · 설정    │    │      (큰 숫자, 명확한 레이블)              │    │
│            │    │                                         │    │
│            │    └─────────────────────────────────────────┘    │
│            │                                                    │
│            │    ┌─────────────────────────────────────────┐    │
│            │    │                                         │    │
│            │    │      상세 정보 테이블                     │    │

│            │    └─────────────────────────────────────────┘    │

## 2. 현재 디자인 vs 토스 스타일 비교

### 2.1 현재 디자인의 문제점

| 문제 | 현재 상태 | 토스라면? |
|------|----------|----------|
| **정보 과밀** | 테이블에 6개 컬럼 | 핵심 3개만 표시, 나머지는 클릭 시 |
| **여백 부족** | 빽빽한 레이아웃 | 넉넉한 패딩 (24px+) |
| **시각적 계층** | 모든 정보가 동등 | 큰 숫자 → 작은 텍스트 계층 |
| **감정적 연결** | 딱딱한 표현 | "오늘 수업 잘 마무리하세요" |

### 2.2 토스 스타일 핵심 차별점

```
현재:
┌────────────────────────────────────────────────────────────┐
│ 반 │ 강사 │ 진도 │ 숙제 │ 출결 │ 메모 │  ← 정보 나열형  │
├────┼──────┼──────┼──────┼──────┼──────┤
│ ... │ ... │ ... │ ... │ ... │ ... │
└────────────────────────────────────────────────────────────┘

토스 스타일:

## 4. 핵심 디자인 요소

### 4.1 타이포그래피

| 요소 | 크기 | 굵기 | 색상 |
|------|------|------|------|
| 인사말 | 28px | Bold | #191F28 |
| 섹션 제목 | 18px | SemiBold | #191F28 |
| 카드 제목 (반 이름) | 16px | SemiBold | #191F28 |
| 본문 | 14px | Regular | #4E5968 |
| 보조 텍스트 | 13px | Regular | #8B95A1 |
| 숫자 (큰) | 32px | Bold | #191F28 |
| 숫자 (작은) | 18px | SemiBold | #191F28 |

### 4.2 간격 시스템

| 요소 | 값 |
|------|-----|
| 사이드바 너비 | 72px (아이콘만) 또는 240px (확장) |
| 메인 컨텐츠 패딩 | 40px |
| 카드 패딩 | 24px |
| 카드 간격 | 16px |
| 요소 간격 (작은) | 8px |
| 요소 간격 (중간) | 16px |
| 요소 간격 (큰) | 24px |

### 4.3 그림자 및 테두리

| 요소 | 스타일 |
|------|--------|
| 카드 그림자 | `0 1px 3px rgba(0,0,0,0.04)` |
| 카드 테두리 | `1px solid #E5E8EB` |
| 카드 호버 | `0 4px 12px rgba(0,0,0,0.08)` |
| 버튼 호버 | 배경색 10% 어두워짐 |

### 4.4 애니메이션

| 요소 | 애니메이션 |
|------|------------|
| 카드 호버 | `transform: translateY(-2px)` 200ms |
| 버튼 클릭 | `transform: scale(0.98)` 100ms |
| 패널 열기 | `height: auto` 300ms ease-out |
| 숫자 변경 | 카운트업 애니메이션 |

## 5. 상호작용 패턴

### 5.1 카드 클릭 시 확장

```
기본 상태:
┌─────────────────────────────────────────────────┐
│  ●  중1A 수학                        김선생    │
│  p.42 → p.46 · 숙제 4/5 ⚠️                     │
└─────────────────────────────────────────────────┘
                      ↓ 클릭
확장 상태:
┌─────────────────────────────────────────────────┐
│  ●  중1A 수학                        김선생    │
│                                                 │
│  지난 수업  p.42-45 이차함수의 정의             │
│  오늘 수업  p.46-50 이차함수의 최댓값           │
│                                                 │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│  │ 숙제 4/5 │  │ 출결 5/5 │  │ 메모 1  │         │
│  └─────────┘  └─────────┘  └─────────┘         │
│                                                 │
│  [출결 입력]  [진도 입력]  [숙제 배정]           │
└─────────────────────────────────────────────────┘
```

### 5.2 상태 표시 방법

```
정상 (모두 완료):
┌─────────┐
│  ✓      │  ← 체크 아이콘만, 숫자 없음
│  숙제   │
│  완료   │
└─────────┘

주의 (1~2명 미완료):
┌─────────┐
│  4/5    │  ← 숫자 표시
│  숙제   │
│  ⚠️     │  ← 주황색 점
└─────────┘

경고 (3명+ 미완료):
┌─────────┐
│  3/7    │  ← 빨간 숫자
│  숙제   │
│  🔴     │  ← 빨간 점
└─────────┘
```

## 6. 반응형 고려사항

### 6.1 화면 크기별 레이아웃

| 화면 크기 | 사이드바 | 카드 열 | 특징 |
|-----------|----------|---------|------|
| > 1440px | 240px 확장 | 1열 | 넓은 카드 |
| 1024-1440px | 72px 축소 | 1열 | 표준 |
| 768-1024px | 숨김 (햄버거) | 1열 | 태블릿 |
| < 768px | 모바일 전용 페이지로 리다이렉트 |

## 7. 토스 스타일 문구 예시

### 7.1 인사말

```
아침 (06:00-12:00): "좋은 아침이에요, 원장님"
점심 (12:00-18:00): "오늘도 수고 많으셨어요"
저녁 (18:00-22:00): "오늘 하루 마무리 잘 하세요"
밤   (22:00-06:00): "늦은 시간까지 수고하세요"
```

### 7.2 상태 메시지

```
수업 없는 날: "오늘은 쉬는 날이에요 ☀️"
모든 수업 완료: "오늘 수업 모두 잘 마쳤어요 👏"
숙제 미제출 있음: "확인이 필요한 수업이 있어요"
```

### 7.3 빈 상태

```
진도 미입력: "아직 입력된 진도가 없어요"
숙제 없음: "배정된 숙제가 없어요"
메모 없음: "특이사항이 없어요"
```

## 8. 개발 계획

### Phase 1: 레이아웃 변경 (30분)
- 사이드바 추가 (좁은 아이콘형)
- 메인 컨텐츠 영역 확장
- 여백 시스템 적용

### Phase 2: 상단 요약 카드 (20분)
- 오늘 수업 수
- 숙제 미제출 수
- 출결 미입력 수
- 인사말 추가

### Phase 3: 수업 카드 리디자인 (40분)
- 새로운 카드 컴포넌트
- 확장/축소 기능
- 상태 배지

### Phase 4: 상호작용 (20분)
- 호버 효과
- 클릭 확장 애니메이션
- 버튼 스타일

### Phase 5: 폴리싱 (20분)
- 그림자, 테두리 조정
- 애니메이션 추가
- 반응형 조정

## 9. 예상 결과 비교

### Before (현재)
- 테이블 기반, 정보 밀도 높음
- 여백 부족
- 딱딱한 느낌

### After (토스 스타일)
- 카드 기반, 정보 계층화
- 넉넉한 여백
- 친근하고 현대적인 느낌
- 문제 상황 명확히 강조
