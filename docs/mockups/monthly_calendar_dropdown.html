📢 학부모 상담 주간

월간 캘린더 드롭다운 목업

동작: "월간" 버튼 클릭 시 주간 캘린더 아래로 월간 캘린더가 슬라이드 다운

반응형 공지:

  • PC: 공지 제목 일부 텍스트로 표시 (예: "학부모상..", "시험일정..")
  • 모바일: 공지 개수를 점(●)으로 표시 (최대 3개)

날짜 선택: 날짜 클릭 시 월간 캘린더가 닫히고 주간 캘린더가 해당 주로 이동

마커: 순환수업일(보라색 점), 오늘(파란색 원), 휴원(빨간색)
