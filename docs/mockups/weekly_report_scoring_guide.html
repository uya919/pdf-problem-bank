1. 수업 태도

수업 중 집중도, 자세, 예절

점수 구체적 행동 기준 예시 시나리오
5점
  • • 수업 시작 전 미리 준비 완료
  • • 선생님 눈을 보며 경청
  • • 자발적으로 질문하고 답변
  • • 다른 학생에게 방해가 전혀 없음
 "민지는 항상 수업 5분 전에 교재를 펴놓고 기다려요. 모르는 부분은 바로 질문하고, 설명할 때 고개를 끄덕이며 집중해요."
4점
  • • 수업 시작과 동시에 준비
  • • 대체로 집중하며 듣음
  • • 질문하면 성실히 답변
  • • 가끔 주의 산만하나 금방 복귀
 "서준이는 수업에 잘 따라와요. 가끔 옆 친구와 이야기하지만, 주의를 주면 바로 집중해요."
3점
  • • 수업 시작 후 교재 찾음
  • • 듣다가 멍하니 있는 경우 있음
  • • 질문하면 답하나 소극적
  • • 1-2회 주의 필요
 "수현이는 평균적인 태도예요. 설명 중 가끔 딴 생각을 하고, 질문하면 대답은 하지만 먼저 질문하진 않아요."
2점
  • • 지각 또는 준비물 미비
  • • 자주 딴짓 (낙서, 핸드폰)
  • • 질문해도 대충 답변
  • • 3회 이상 주의 필요
 "다은이는 이번 주 2번 지각했고, 수업 중 책상에 낙서하거나 멍하니 있는 시간이 많았어요. 여러 번 주의를 줬어요."
1점
  • • 상습 지각 또는 조퇴
  • • 수업 방해 (떠들기, 장난)
  • • 교재 안 가져옴
  • • 선생님 말에 반항적 태도
 "준호가 이번 주 수업에서 계속 옆 친구에게 말을 걸어 수업 진행이 어려웠어요. 주의를 줘도 금방 다시 떠들었어요. 학부모 상담이 필요해요."

2. 이해도

수업 내용 파악 수준, 개념 이해력

점수 구체적 행동 기준 예시 시나리오
5점
  • • 새 개념을 한 번에 이해
  • • 응용 문제까지 스스로 해결
  • • 왜 그런지 설명할 수 있음
  • • 심화 문제에도 도전
 "민지는 일차함수 개념을 바로 이해하고, 응용 문제도 혼자 풀었어요. '기울기가 변화율이죠?'라고 스스로 정리하더라고요."
4점
  • • 1-2번 설명으로 이해
  • • 유사 문제는 혼자 해결
  • • 가끔 힌트 필요
  • • 전체적으로 따라옴
 "서준이는 개념 설명을 두 번 듣고 이해했어요. 비슷한 유형은 잘 풀지만, 변형된 문제에서 살짝 막히더라고요."
3점
  • • 3-4번 설명 필요
  • • 기본 문제는 해결
  • • 응용에서 어려움
  • • 비슷한 실수 반복
 "수현이는 개념을 여러 번 설명해야 이해해요. 기본 문제는 풀지만, 응용 문제에서 막히면 어디서부터 접근해야 할지 몰라해요."
2점
  • • 많이 설명해도 헷갈려함
  • • 기본 문제도 힌트 필요
  • • 이전 개념 복습 필요
  • • 자신감 부족
 "다은이는 이번 단원이 어려운 것 같아요. 기본 문제도 제가 옆에서 도와줘야 풀어요. 이전 단원 복습이 필요해 보여요."
1점
  • • 기초 개념부터 모름
  • • 수업을 따라오기 어려움
  • • 개별 보충 수업 필요
  • • 학습 격차 심각
 "준호는 이번 단원의 선행 개념(분수 계산)이 안 되어 있어서 수업 진행이 어려워요. 개별 보충 수업이나 레벨 조정이 필요해요."

3. 숙제 완료도

과제 제출율, 성실도, 정확도

점수 구체적 행동 기준 예시 시나리오
5점
  • • 숙제 100% 완료 + 오답 정리까지
  • • 모르는 문제 표시 후 질문
  • • 추가 문제까지 스스로 풀어옴
  • • 깔끔한 풀이 과정
 "민지는 숙제를 다 하고, 틀린 문제는 왜 틀렸는지 적어왔어요. 모르는 건 표시해서 수업 시작할 때 바로 질문해요."
4점
  • • 숙제 100% 완료
  • • 성실하게 풀이 작성
  • • 오답 정리는 안 함
  • • 가끔 계산 실수 있음
 "서준이는 숙제를 빠짐없이 해왔어요. 풀이도 성실하게 적었고요. 다만 틀린 문제 복습은 안 했네요."
3점
  • • 숙제 70-90% 완료
  • • 어려운 문제 건너뜀
  • • 풀이 과정 생략 있음
  • • 대충 한 흔적 보임
 "수현이는 숙제를 거의 했는데, 뒷부분 어려운 문제 3개를 안 풀어왔어요. '몰라서요'라고 했는데, 시도한 흔적이 없었어요."
2점
  • • 숙제 50-70% 완료
  • • 답만 적고 풀이 없음
  • • 베낀 흔적 있음
  • • 급하게 한 티가 남
 "다은이는 숙제 절반만 했고, 답만 적혀있어요. 수업 직전에 급하게 한 것 같아요. 이번 주 두 번 다 이랬어요."
1점
  • • 숙제 50% 미만 또는 안 함
  • • 교재를 안 가져옴
  • • 핑계를 댐 ("잊어버렸어요")
  • • 반복적으로 미완료
 "준호가 이번 주 숙제를 아예 안 해왔어요. '교재를 학교에 두고 왔어요'라고 했는데, 지난주에도 같은 핑계였어요. 학부모님께 연락드려야 할 것 같아요."

4. 참여도

수업 활동 참여, 질문/발표, 적극성

점수 구체적 행동 기준 예시 시나리오
5점
  • • 자발적으로 질문 3회 이상
  • • 문제 풀이 발표 자원
  • • 모둠 활동에서 리더 역할
  • • 수업 분위기를 끌어올림
 "민지는 '선생님, 이 방법도 되나요?'라고 먼저 질문하고, 칠판에 나와서 풀이도 설명해줬어요. 수업 분위기가 좋아져요."
4점
  • • 가끔 질문 (1-2회)
  • • 시키면 발표함
  • • 활동에 성실히 참여
  • • 반응이 좋음 (끄덕끄덕)
 "서준이는 질문하면 잘 대답하고, 모르면 손을 들어 물어봐요. 적극적이진 않지만 성실하게 참여해요."
3점
  • • 질문 안 하고 듣기만 함
  • • 시키면 마지못해 답함
  • • 활동은 하지만 수동적
  • • 표정이 무덤덤
 "수현이는 조용히 듣기만 해요. 발표시키면 작은 목소리로 대답하긴 하는데, 스스로 질문하거나 의견을 말하진 않아요."
2점
  • • 질문해도 "모르겠어요"만
  • • 발표 시키면 거부
  • • 활동에 소극적/무관심
  • • 의욕 없어 보임
 "다은이는 발표시키면 '저 말고요' 하고, 질문해도 '몰라요'만 해요. 의욕이 없어 보여서 걱정이에요."
1점
  • • 수업 참여 거부
  • • 책상에 엎드려 있음
  • • 대화가 안 됨
  • • 정서적 문제 의심
 "준호가 이번 주 내내 책상에 엎드려 있었어요. 말을 걸어도 대답을 안 하고요. 가정에서 무슨 일이 있는 건 아닌지 확인이 필요해요."

학부모 전달 문구 예시

긍정적 피드백 (4-5점)

수업 태도 5점

"○○이가 항상 수업 준비를 미리 하고, 집중해서 듣는 모습이 인상적이에요. 다른 친구들에게도 좋은 본보기가 되고 있어요."

이해도 4점

"이번 주 배운 일차함수 개념을 잘 이해하고 있어요. 응용 문제까지 도전해보면 더 좋을 것 같아요!"

개선 필요 피드백 (2-3점)

숙제 완료도 2점

"이번 주 숙제가 절반만 되어 있었어요. 어려운 문제는 풀이 시도라도 해보면 다음 수업에서 같이 해결할 수 있어요. 가정에서도 숙제 확인 부탁드려요."

참여도 3점

"수업은 잘 따라오는데, 조금 더 적극적으로 질문하면 좋겠어요. 틀려도 괜찮으니 자신감을 가지고 도전해봤으면 해요."

1점 시 필수 포함 문구

"최근 ○○이의 수업 참여/숙제/이해도에 대해 걱정이 됩니다. 학부모님과 상담을 통해 함께 방법을 찾고 싶습니다. 편하신 시간에 연락 부탁드립니다."
