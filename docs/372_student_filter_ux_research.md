## 1. 현재 구현 분석

### 1.1 현재 UI 구조
```
┌──────────────────────────────────────────────────────────┐
│ 학생 관리                                    [반배정] [+학생등록] │
├──────────────────────────────────────────────────────────┤
│ ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐         │
│ │ 전체학생 │ │ 재원생  │ │ 휴원생  │ │ 졸업생  │  ← KPI 카드 │
│ │   24명  │ │  20명   │ │   2명   │ │   2명   │         │
│ └─────────┘ └─────────┘ └─────────┘ └─────────┘         │
├──────────────────────────────────────────────────────────┤
│ [검색창___________] [전체상태▼] [전체학년▼] [이름순▼]   │  ← 드롭다운 필터
├──────────────────────────────────────────────────────────┤
│ 학생 목록 테이블...                                       │
└──────────────────────────────────────────────────────────┘
```

### 1.2 문제점

| 문제 | 설명 | 심각도 |
|------|------|--------|
| **KPI 카드 중복** | 상태별 카드가 필터 역할을 하지 않음, 단순 표시 | ⚠️ 중간 |
| **드롭다운 UX** | 클릭 → 열기 → 선택 3단계, 현재 선택 상태 불명확 | ⚠️ 중간 |
| **학년 필터 부족** | 학부(초/중/고)별 빠른 전환 불가 | ⚠️ 중간 |
| **과목 필터 없음** | 수강 과목별 필터링 불가 | ❌ 기능 부재 |
| **일관성 부족** | 반배정 페이지와 필터 UI 스타일 불일치 | ⚠️ 중간 |

## 2. 토스 디자인 철학 적용

### 2.1 "한눈에" 원칙
> 현재 선택 상태가 **즉시 보여야** 함

```
❌ 드롭다운: [전체 학년 ▼]
   → 클릭해야 선택 가능한 항목 확인 가능

✅ 토글 버튼: [전체] [초등] [중등] [고등]
   → 현재 선택과 가능한 옵션이 모두 보임
```

### 2.2 "최소 클릭" 원칙
> 원하는 결과까지 **클릭 수 최소화**

| 방식 | 필터 변경 클릭 수 |
|------|-------------------|
| 드롭다운 | 3회 (클릭 → 선택 → 닫기) |
| 토글 버튼 | 1회 |

### 2.3 "맥락 유지" 원칙
> 필터 변경 시 **현재 위치/상태 유지**

- 필터 변경해도 스크롤 위치 유지
- 검색어 유지하면서 필터 조합

## 3. 반배정 페이지 필터 UI 분석

### 3.1 현재 반배정 페이지 필터
```
┌──────────────────────────────────────────┐
│ 학생 목록                                 │
├──────────────────────────────────────────┤
│ [수학] [국어] [영어]    ← 과목 토글 (컬러) │
├──────────────────────────────────────────┤
│ [초등] [중등] [고등]    ← 학부 토글       │
├──────────────────────────────────────────┤
│ [검색창________________]                  │
└──────────────────────────────────────────┘
```

### 3.2 장점
- **즉시 인식**: 현재 선택된 필터가 컬러로 강조
- **빠른 전환**: 1클릭으로 필터 변경
- **계층 구조**: 과목 → 학부 순서로 자연스러운 드릴다운

## 4. 요청된 필터 구조

```
1. 학부: 전체, 초등부, 중등부, 고등부
2. 학년: 중1, 중2, 중3 (학부 선택 시 표시)
```

## 5. 세부 디자인

### 5.1 학부 필터 (Division Filter)

```tsx
// 토글 버튼 스타일
[전체]     → bg-grey-900 text-white (선택됨)
[초등부]   → bg-grey-100 text-grey-600 hover:bg-grey-200 (미선택)
[중등부]   → bg-grey-100 text-grey-600 hover:bg-grey-200
[고등부]   → bg-grey-100 text-grey-600 hover:bg-grey-200
```

### 5.2 학년 필터 (Grade Filter)

학부별 학년 목록:
| 학부 | 학년 옵션 |
|------|-----------|
| 전체 | 숨김 또는 전체 학년 |
| 초등부 | 초3, 초4, 초5, 초6 |
| 중등부 | 중1, 중2, 중3 |
| 고등부 | 고1, 고2, 고3 |

```tsx
// 동적 학년 필터
{activeDivision !== 'all' && (
  <div className="flex items-center gap-2">
    <span className="text-sm text-grey-500">학년</span>
    <div className="flex gap-1">
      <button className={selected ? 'bg-grey-900' : 'bg-grey-100'}>전체</button>
      {GRADES[activeDivision].map(grade => (
        <button key={grade}>{grade}</button>
      ))}
    </div>
  </div>
)}
```

### 5.3 과목 필터 (Subject Filter)

```tsx
// 과목별 컬러 토글
[전체]   → bg-grey-900 text-white (선택됨)
[수학]   → bg-blue-500 text-white (선택됨) / bg-blue-50 text-blue-600 (미선택)
[국어]   → bg-green-500 text-white / bg-green-50 text-green-600
[영어]   → bg-purple-500 text-white / bg-purple-50 text-purple-600
[과학]   → bg-orange-500 text-white / bg-orange-50 text-orange-600
```

### 5.4 과목 필터 로직

과목 필터 선택 시 해당 과목에 **배정된 학생만** 표시:

```tsx
// 과목 필터 적용
if (filterSubject !== 'all') {
  result = result.filter(student => {
    const enrollments = getSubjectEnrollments(student);
    return enrollments?.[filterSubject] !== undefined;
  });
}
```

## 6. 상호작용 설계

### 6.1 필터 선택 시 동작

```
[중등부] 클릭
  → activeDivision = 'middle'
  → 학년 필터 표시: [전체] [중1] [중2] [중3]
  → activeGrade = 'all' (리셋)
  → 테이블 필터링 적용
```

### 6.2 필터 조합

```
학부: 중등부 + 학년: 중2 + 과목: 수학
→ "중2 + 수학 수강 중인 학생만 표시"
```

### 6.3 검색과 필터 조합

```
검색: "김" + 학부: 중등부 + 과목: 수학
→ "중등부에서 수학 수강 중인 '김' 포함 학생"
```

### 8.1 새로운 State

```tsx

```

### 8.2 Division 타입

```tsx
type Division = 'elementary' | 'middle' | 'high';

const DIVISION_GRADES: Record<Division, string[]> = {
  elementary: ['초3', '초4', '초5', '초6'],
  middle: ['중1', '중2', '중3'],
  high: ['고1', '고2', '고3'],
};
```

### 8.3 필터 컴포넌트

```tsx
function FilterToggle({
  options,
  value,
  onChange,
  colorMap
}: FilterToggleProps) {
  return (
    <div className="flex gap-1 p-1 bg-grey-100 rounded-lg">
      {options.map(opt => (
        <button
          key={opt.value}
          onClick={() => onChange(opt.value)}
          className={`px-4 py-2 rounded-md text-sm font-medium transition-all
            ${value === opt.value
              ? colorMap?.[opt.value] || 'bg-grey-900 text-white'
              : 'text-grey-600 hover:bg-grey-200'
            }`}
        >
          {opt.label}
        </button>
      ))}
    </div>
  );
}
```
